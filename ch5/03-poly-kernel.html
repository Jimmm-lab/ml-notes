多項式特徵與多項式核：
把資料搬到更高的維度

兩類的分界如果本來就是彎的，直線再怎麼調都不夠。這篇先用最直接的辦法：加上多項式特徵，把資料搬到更高的維度，讓它變得可以用直線分開。但次數一高，特徵數會爆炸。SVM 的核技巧可以得到同樣的結果，卻完全不用真的算出這些特徵。

  • 多項式核的三個超參數 degree、coef0、C 各自的作用。

加一個特徵，資料就分開了

投影片 7

前兩篇的 SVM 都畫直線。如果兩類的分界本來就是彎的，直線再怎麼調都不會好。投影片 7 的辦法很直接：加特徵。

例子只有一個特徵 ，9 筆資料排在一條線上：。中間五筆（ 到 ）是類別 1，兩側四筆是類別 0。

  • 只有一個特徵時，線性分類器能做的只有「設一個門檻」：左邊一類、右邊一類。
  • 但類別 1 夾在類別 0 中間，一個門檻怎麼放都分不開。
  • 加上第二個特徵 ：兩側的資料被抬到很高（9、16），中間的只到 0 到 4。這時一條水平線就能分開了。

實驗：把資料抬起來

類別 0類別 1支援向量

  • 在新的二維空間裡，最寬的街道是水平的，決策邊界是 （正好在 4 和 9 中間）。
  • 回到原本的一維： 對應兩個門檻 ，中間判成類別 1，兩側判成類別 0。
  • 新空間裡的直線，回到原本的空間就變成彎的（非線性）邊界。這就是用線性模型做非線性分類的訣竅。

投影片 7 列出三種「加特徵」的做法，本篇講前兩種，第三種在下一篇：

  1. 多項式特徵：真的把 、、……算出來加進去。
  2. 多項式核：效果一樣，但不用真的算出這些特徵（核技巧）。
  3. 相似度特徵（高斯 RBF 核）：用「和某些地標有多像」當作新特徵（第 4 篇）。

多項式特徵 + LinearSVC

投影片 8–9

投影片的例子是 make_moons 產生的兩個交錯的半月形，100 筆資料，加了一點雜訊。做法是一條 Pipeline：先加多項式特徵，再標準化，最後用線性 SVM：

from sklearn.datasets import make_moons
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.svm import LinearSVC

X, y = make_moons(n_samples=100, noise=0.15, random_state=42)
polynomial_svm_clf = make_pipeline(
    PolynomialFeatures(degree=3),
    StandardScaler(),
    LinearSVC(C=10, loss="hinge", max_iter=10_000, random_state=42))
polynomial_svm_clf.fit(X, y)

polynomial_svm_clf.score(X, y)                  # 0.97
polynomial_svm_clf[0].get_feature_names_out()
# array(['1', 'x0', 'x1', 'x0^2', 'x0 x1', 'x1^2', 'x0^3', 'x0^2 x1',
#        'x0 x1^2', 'x1^3'], dtype=object)
  • PolynomialFeatures(degree=3) 把 2 個特徵變成 10 個：所有次數不超過 3 的組合。投影片 8 標出這裡有兩個超參數：多項式的次數 degree 和 SVM 的 C。
  • 照投影片的寫法（沒有 max_iter），scikit-learn 1.9 會出現 ConvergenceWarning：預設最多只迭代 1,000 次，還沒收斂。加上 max_iter=10_000 就好了。
  • 在 10 個特徵的空間裡，邊界是一個平面（超平面）；畫回原本的 ，就是下圖彎彎曲曲的邊界（投影片 9），訓練準確率 97%。

多項式核 SVC

投影片 10–11

scikit-learn 的多項式核是：

  • 是次數，參數 degree； 是參數 coef0； 是參數 gamma，會把內積先放大或縮小。
  • 它相當於加了所有次數不超過 的多項式特徵（ 時），但從來不用把它們算出來。

投影片 10 的程式，在同一份半月形資料上：

from sklearn.svm import SVC

poly_kernel_svm_clf = make_pipeline(StandardScaler(),
                                    SVC(kernel="poly", degree=3, coef0=1, C=5))
poly_kernel_svm_clf.fit(X, y)
poly_kernel_svm_clf.score(X, y)                 # 0.98

這次有三個超參數：degree、coef0、C（投影片 10）。gamma 用預設的 "scale"，在標準化後的兩個特徵上等於 0.5。調調看：

coef0 在做什麼

投影片 11

投影片 11 說：超參數 coef0 控制模型受高次項和低次項影響的比例。把核函數用二項式定理展開就看得出來，以 、記 為例：

  • 對應三次的特徵， 對應二次的特徵， 對應原本的一次特徵， 是常數。
  • ：只剩 ，也就是只有最高次的特徵，連原本的 、 都沒有。
  • 越大，低次項前面的係數（、）越大，低次特徵的份量就越重。

在實驗裡把 coef0 設成 0、次數調成 2 試試：準確率掉到 51%，邊界還會對中心點對稱：只有二次特徵時，模型連「 越大，越可能是類別 1」這種最簡單的一次趨勢都表達不了。這也是為什麼 coef0 通常要設成大於 0，而 SVC 的預設值偏偏是 0。

反過來， 很大（例如投影片右圖的 100）時，核函數的數值會變得非常大（），訓練也要花更多計算。實驗裡右圖那組直接載入 scikit-learn 算好的結果，就是這個原因。

Python 實作

用程式驗證這篇的三件事。第一，特徵數的公式：

from math import comb

comb(2 + 3, 3)         # 10：半月形，3 次
comb(784 + 3, 3)       # 80931145：MNIST，3 次

第二，核技巧： 和 相等：

import numpy as np

a, b = np.array([1, 2]), np.array([3, 4])
phi = lambda v: np.array([v[0]**2, np.sqrt(2) * v[0] * v[1], v[1]**2])
phi(a) @ phi(b), (a @ b) ** 2        # (np.float64(121.0), np.int64(121))

第三，SVC 的預測真的只用了「新資料和支援向量之間的核函數」。自己用核函數算一次決策函數，和 decision_function 比較：

svc = poly_kernel_svm_clf[-1]
scaler = poly_kernel_svm_clf[0]
X_scaled = scaler.transform(X)
gamma = 1 / (X_scaled.shape[1] * X_scaled.var())   # gamma="scale" 的定義：0.5

X_new = [[0.5, 0.25], [1.5, 0.0]]
K = (gamma * scaler.transform(X_new) @ svc.support_vectors_.T + 1) ** 3   # coef0=1, degree=3
K.shape                                          # (2, 19)：2 筆新資料 × 19 個支援向量
K @ svc.dual_coef_[0] + svc.intercept_[0]       # array([0.12237315, 0.06947041])
poly_kernel_svm_clf.decision_function(X_new)    # array([0.12237315, 0.06947041])
  • dual_coef_ 就是 ，只有 19 個支援向量才有。
  • 整個計算只用到核函數 ，沒有任何地方算出 10 個（或更多）多項式特徵。

常見陷阱與自我檢查

多項式核忘了設 coef0SVC 的 coef0 預設是 0，只剩最高次的項。半月形資料用 degree=3、coef0=0，訓練準確率只有 90%；設成 1 就有 98%。
以為 SVC 預設是線性的SVC() 預設 kernel="rbf"。要線性就寫 kernel="linear"，或直接用 LinearSVC。
以為 LinearSVC 也能用核技巧核技巧只有 SVC 有。LinearSVC 要非線性，只能自己加特徵（例如 PolynomialFeatures）。
次數越高越好次數越高，邊界越能彎，也越容易過擬合。用交叉驗證挑 degree，不要只看訓練準確率。
沒先標準化多項式特徵和多項式核都會把數值相乘、取次方，特徵的尺度差很多時，大的特徵會被放大得更嚴重。

為什麼說核技巧「不會有特徵數爆炸的問題」？

SVM 只需要內積，而核函數直接用原本的資料算出轉換後的內積。不管轉換後有幾個特徵，算一次核函數的成本都差不多：一次原本的內積，再加一個次方。

多項式核 SVM 在訓練集上準確率 100%，驗證集卻只有 85%。可以怎麼調？

這是過擬合。可以降低 degree、調小 C（正則化變強），或調整 coef0 讓低次項的份量重一點。用交叉驗證比較。

讀者提問

「核」這個名字是什麼意思？為什麼叫核技巧？

  • 核函數（kernel function）就是一個函數 ：輸入兩筆原本的資料，輸出它們「轉換到某個新空間之後的內積」。
  • 「kernel」原本是數學（積分方程）裡的用語，指積分式裡那個兩個變數的函數，沒有特別的生活意義，當成專有名詞記就好。
  • 內積可以看成兩筆資料有多像：方向越接近，內積越大。所以核函數也常被理解成「相似度」，下一篇的高斯 RBF 核會更明顯。
  • 技巧指的是「不用真的轉換，就能得到轉換後的結果」這個省事的作法。

一句話核函數 = 在原本的空間裡，算出新空間的內積。
