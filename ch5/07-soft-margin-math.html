硬間隔的弱點：離群值

投影片 42

上一篇推導的硬間隔 SVM 有個前提：資料要能被一條直線完全分開。但真實資料常有雜訊。第 2 篇用鳶尾花看過離群值的影響，投影片 42 用上一篇的 14 筆資料再看一次，各多加一顆星星，標籤是 ：

  • 加在 (7, 8)：分不開了。它落在一群三角形中間，沒有任何直線能把兩類完全分開。限制式 不可能全部成立，硬間隔 SVM 沒有解。

一筆資料就能讓模型變差，甚至根本訓練不出來。解法是放寬限制：允許少數資料違規，但要付出代價。

用 scikit-learn 驗算「加一顆 (7, 8)」的情況。 不用另外求：給定 、，最小的 就是 ，原因在後面「從鬆弛變數到 hinge loss」：

import numpy as np
from sklearn.svm import SVC

X = np.array([[8, 7], [4, 10], [9, 7], [7, 10], [9, 6], [4, 8], [10, 10],   # 三角形 +1
              [2, 7], [8, 3], [7, 5], [4, 4], [4, 6], [1, 3], [2, 5]])      # 星星 −1
y = np.array([1] * 7 + [-1] * 7)
X_out = np.vstack([X, [7, 8]])             # 加一顆星星 (7, 8)：分不開了
y_out = np.r_[y, -1]

for C in [100, 1, 0.1]:
    svm_clf = SVC(kernel="linear", C=C).fit(X_out, y_out)
    w = svm_clf.coef_[0]
    zeta = np.maximum(0, 1 - y_out * svm_clf.decision_function(X_out))
    print(f"C={C:<4} 街道寬 {2 / np.linalg.norm(w):.2f}  總違規量 {zeta.sum():.2f}")
# C=100  街道寬 1.67  總違規量 3.33
# C=1    街道寬 2.23  總違規量 3.50
# C=0.1  街道寬 3.61  總違規量 4.15

C 從 100 降到 0.1，街道從 1.67 變寬到 3.61，總違規量從 3.33 增加到 4.15。三種 C 都把 (7, 8) 分錯，這是分不開的資料一定要付的代價。

二次規劃與對偶問題

投影片 44

硬間隔和軟間隔 SVM 都是凸的二次最佳化問題，而且限制式都是線性的：目標函數是二次式，限制式是 、、 的一次式。這類問題叫二次規劃（Quadratic Programming，QP），有很多現成的求解器，用各種技巧都能可靠地解出來。

投影片列了幾個想深入的話可以讀的主題，它們都是最佳化理論的基礎：

  • 有限制的最佳化、凸最佳化：在限制式圍出的區域裡找最低點；凸的問題沒有會卡住的局部最低點。
  • 線性規劃（LP）、二次規劃（QP）：目標函數是一次式的叫 LP，二次式的叫 QP；兩者的限制式都是一次式。
  • 拉格朗日乘數（Lagrange multipliers）：把限制式乘上係數加進目標函數，用來處理有限制的問題。
  • 對偶（duality）：原本的問題叫原始問題（primal），換個角度寫出的等價問題叫對偶問題（dual）。
  • KKT 條件（Karush–Kuhn–Tucker）：最佳解一定要滿足的條件，可以看出哪些資料是支援向量。
補充筆記拉格朗日乘數的直覺
  • 把「限制式」改成「罰款」：每個限制式配一個價格 ，違反限制就要付錢，問題就變成沒有限制的最小化。
  • 到了最佳解，沒有碰到的限制式（資料在街道外）價格是 0：拿掉這筆資料，答案也不會變。
  • 碰到的限制式（資料在街道邊緣上或違規）價格大於 0：它真的在影響答案。
  • 所以 衡量的是「這筆資料對答案有多重要」。

一句話 是限制式的價格；只有撐住街道的支援向量，價格才不是 0。

補充筆記次導數的「次」和批次的「次」無關
  • 次導數（sub-derivative）用在一個變數；次梯度（subgradient）用在多個變數，把每個方向的次導數排成向量。這裡的「次」是英文的 sub，意思是「在下面」：次切線都貼在曲線下方。
  • 批次梯度下降的「批次」是 batch，指每一步都用全部的資料（第 4 章第 2 篇），和 sub 無關，只是剛好都有「次」這個字。
  • 下一節的梯度下降，其實是「批次的次梯度下降」：每一步用全部 14 筆資料，在折角取次導數。

一句話次導數的「次」是 sub（在下面），批次的「次」是 batch，兩者無關。

補充筆記折角讓固定學習率停不下來
  • MSE 這種平滑的碗，越靠近最低點梯度越小，步伐會自動變小（第 4 章第 2 篇）。
  • hinge loss 的斜率只有 和 0 兩種，不會慢慢變小。到了最低點附近，有些資料在「違規」和「不違規」之間來回切換，梯度忽大忽小，每一步都走得一樣遠，於是一再跨過最低點。
  • 解法是讓學習率隨著步數變小（第 4 章第 3 篇的學習時程），或者直接用 QP 的方法解。

一句話折角讓梯度不會自己變小，所以學習率要自己慢慢變小。

用 NumPy 寫一次學習率慢慢變小的版本（X、y 是原本的 14 筆）：

def svm_cost(w, b, C=1):
    return 0.5 * w @ w + C * np.maximum(0, 1 - y * (X @ w + b)).sum()

def svm_gd(n_steps, eta0=0.05, C=1):
    w, b = np.zeros(2), 0.0
    for k in range(n_steps):
        v = y * (X @ w + b) < 1                   # 違規（t < 1）的資料
        grad_w = w - C * y[v] @ X[v]
        grad_b = -C * y[v].sum()
        eta = eta0 / (1 + k / 100)                # 學習率慢慢變小
        w, b = w - eta * grad_w, b - eta * grad_b
    return w, b

for n in [1_000, 10_000, 100_000]:
    w, b = svm_gd(n)
    print(f"{n:>7} 步：w = {w.round(3)}, b = {b:.3f}, J = {svm_cost(w, b):.4f}")
#    1000 步：w = [0.508 1.122], b = -10.148, J = 0.9147
#   10000 步：w = [0.456 1.134], b = -9.827, J = 0.8076
#  100000 步：w = [0.445 1.113], b = -9.683, J = 0.7188

svm_cost(np.array([4 / 9, 10 / 9]), -29 / 3)    # 最低點：上一篇的最佳超平面
# np.float64(0.7160493827160512)
svm_clf.n_iter_                                 # SVC（QP 的解法）的迭代次數
# array([18], dtype=int32)

梯度下降走了 10 萬步，成本 0.7188 還沒降到 0.7160；SVC 只迭代了 18 次就得到答案。這就是投影片 46 說的「梯度下降收斂慢很多」。梯度下降的好處是不用一次處理所有資料，可以一批一批、甚至一筆一筆地學，資料多到放不進記憶體時很有用。

邏輯迴歸：大間隔，但不是最大間隔

投影片 51

第 4 章的邏輯迴歸也是線性分類器，決策邊界也是一條直線。它和 SVM 差在哪裡？投影片 51 從間隔的角度比較。邏輯迴歸把分數 轉成機率 （注意：這裡的 是分數，沒有乘上標籤），每一筆的成本是 log loss（第 4 章第 6 篇，標籤用 1／0）：

  • 正類： 越大， 越接近 1，成本越小。例如 時 ，成本 ； 時 ，成本只剩 。投影片的圖把 0.55 標在 附近，精確地說是 、，不影響結論。
  • 負類：反過來， 越大，成本越小。
  • 所以梯度下降會盡量把每一筆資料推離決策邊界：邏輯迴歸是一種大間隔（large margin）分類器。

但它不是最大間隔（max-margin）分類器：

SVM：hinge loss

資料在街道外時，loss 剛好是 0，離得再遠也沒有好處。只有靠近邊界的支援向量決定答案，結果是最近的資料離得最遠的那條線。

邏輯迴歸：log loss

log loss 永遠大於 0，離得再遠也還能再小一點。每一筆資料都在拉邊界，結果是所有資料一起妥協出來的線，最近的資料不一定離得最遠。

實驗：拖曳資料，比較兩條邊界

SVM 的決策邊界SVM 的街道邊緣邏輯迴歸的決策邊界支援向量
SVM：最近的資料有多遠
邏輯迴歸：最近的資料有多遠

讀數是兩條邊界各自的最小幾何間隔：最近的資料到邊界的距離。拖曳一筆不是支援向量、而且不進入街道的資料，SVM 的邊界完全不動，邏輯迴歸的邊界卻每次都會跟著動。用 scikit-learn 計算原本 14 筆的最小幾何間隔：

from sklearn.linear_model import LogisticRegression

def geometric_margin(w, b):                     # 最近的資料到邊界的距離
    return np.min(y * (X @ w + b)) / np.linalg.norm(w)

for C in [1, 100, 10_000]:                      # tol 調小，C 很大時才解得準
    log_reg = LogisticRegression(C=C, tol=1e-10, max_iter=10_000).fit(X, y)
    print(C, geometric_margin(log_reg.coef_[0], log_reg.intercept_[0]).round(3))
# 1 0.56
# 100 0.775
# 10000 0.81
geometric_margin(svm_clf.coef_[0], svm_clf.intercept_[0]).round(3)
# np.float64(0.836)
  • 預設的 C = 1：邏輯迴歸的最小幾何間隔只有 0.56，SVM 是 0.836。
  • C 越大（正則化越弱），邏輯迴歸越接近 SVM，但 C = 10000 也只有 0.81。它在乎的是所有資料的總成本，不是最近的那幾筆。

One-class SVM：異常偵測

投影片 52–53

異常偵測（anomaly detection，也叫新奇偵測 novelty detection、離群值偵測 outlier detection）要找出很少發生的事件，例如信用卡盜刷、機器故障。難處在於異常的樣本很少，甚至一筆都沒有，一般的分類器訓練不起來。那要怎麼判斷什麼是「異常」？

  • 估計機率密度：很多方法先估計資料的機率分布，密度「很低」的地方就是異常，多低才算低由應用決定。課本第 9 章的高斯混合模型（GMM）就是這種方法。
  • One-class SVM：SVM 是最大間隔的方法，不去估計機率分布。它只用一個類別（正常的資料，叫目標類別）訓練，找一條把目標類別圍起來的邊界，同時盡量不把離群值或新奇的資料包進來（投影片 53）。
補充筆記One-class SVM 的最佳化問題
  • 只有一類資料，沒有「另一類」可以分。scikit-learn 用的是 Schölkopf 的做法：在核函數的特徵空間裡，把資料和原點分開，而且間隔越大越好。
  • 和軟間隔 SVM 很像： 一樣是鬆弛變數， 扮演 C 的角色。
  • 預測時算 （decision_function）：大於 0 是正常，小於 0 是異常。

一句話把正常資料和原點用最寬的街道分開；配上 RBF 核，邊界就變成圍住資料的曲線。

scikit-learn 的 OneClassSVM 通常配高斯 RBF 核（第 4 篇），兩個主要的超參數：

  • （nu，0 到 1）：大約是訓練資料被當成異常的比例。它扮演 C 的角色：允許多少訓練資料落在邊界外。
  • ：和第 4 篇一樣。 大，邊界緊貼著資料、比較曲折； 小，邊界比較圓滑、寬鬆。
補充筆記 的精確意思
  • 理論上 同時是兩個比例的界線：落在邊界外（被當成異常）的訓練資料比例 ；支援向量的比例 。
  • 資料夠多時，這兩個比例都會很接近 。
  • 剛好落在邊界上的資料，可能因為計算誤差被判成異常，所以實際的比例偶爾會比 多一兩筆。

一句話 是「願意把多少比例的訓練資料當成異常」。

rng = np.random.default_rng(42)
