SVM 能做什麼

投影片 2

支援向量機（Support Vector Machine，簡稱 SVM）是機器學習裡最常用的模型之一，用途很廣：

  • 線性分類：用一條直線把兩類分開（本篇、第 2 篇）。
  • 非線性分類：分界線可以是彎的（第 3、4 篇）。
  • 迴歸：預測一個數值，例如房價（第 5 篇）。
  • 異常偵測：找出和其他資料都不像的資料，叫做 One-class SVM（第 7 篇最後）。

SVM 特別適合規模不大、但分界很複雜的分類問題，大約幾百到幾千筆資料。資料一多，訓練時間會增加得非常快，第 4 篇會比較各種做法的計算量。

其實你已經用過 SVM 了

第 3 章辨識數字 5 的 SGDClassifier，預設參數是 loss="hinge"、penalty="l2"，訓練出來的就是一個線性 SVM（見第 3 章第 1 篇的 hinge loss）。當時說過：光是猜對還不夠，還要猜得「夠有把握」。這一章會解釋這句話背後的想法。

能把兩類分開的線，有無限多條

投影片 3

投影片的例子是第 4 章用過的鳶尾花資料，只取兩種花：setosa 和 versicolor 各 50 朵，每朵花只看兩個特徵：花瓣長度和花瓣寬度。

畫在圖上，兩種花分得很開：可以畫一條直線，讓 setosa 全在一邊、versicolor 全在另一邊。這種情況叫做線性可分（linearly separable）。

補充筆記三個以上的特徵：平面與超平面
  • 兩個特徵：每筆資料是平面上的一個點，用一條直線分開。
  • 三個特徵：每筆資料是空間中的一個點，要用一個平面（像一張紙）分開。
  • 四個以上：畫不出來了，但數學上一樣成立。

這種「比空間少一維」的分界統稱超平面（hyperplane），二維的直線、三維的平面也都是超平面。不管幾維，寫成式子都長一樣：。所以這一章說的「直線」「街道」，換成高維也完全適用，第 6 篇會用這個一般的寫法。

一句話直線、平面、超平面是同一件事在不同維度的樣子。

問題是：能把它們分開的直線有無限多條，該選哪一條？下面是投影片左圖的三條線，加上 SVM 選的線。每條線周圍的色帶，是「以這條線為中心、一路擴張到碰到最近的花為止」的區域，它的寬度代表這條線離資料還有多少空間。

最寬的街道：大間隔分類

投影片 3

SVM 的想法可以想像成在兩類之間鋪一條街道：

  • 街道兩邊的虛線是街道的邊緣，街道裡面不能有任何資料。
  • 在所有鋪得下的街道裡，挑最寬的那一條。
  • 街道正中央的實線就是 SVM 的決策邊界。
決策邊界街道的中線。一邊預測 setosa，另一邊預測 versicolor。
間隔（margin）決策邊界到最近資料的距離，也就是街道寬度的一半。
大間隔分類large margin classification：讓間隔（街道）越大越好，這就是 SVM 的核心想法。

鳶尾花的例子裡，最寬的街道寬 1.30 cm，所以間隔是 0.65 cm。

補充筆記有些書的 margin 指整條街道的寬度
  • 這一章的間隔是街道寬度的一半，也就是決策邊界到最近資料的距離。第 6 篇的「幾何間隔」也是這個意思：所有資料到邊界的距離裡，最小的那一個。
  • 有些書或網站會把整條街道的寬度叫做 margin。看到公式時注意：全寬是 ，一半是 。

一句話不管用哪一種說法，「間隔越大」和「街道越寬」是同一件事。

為什麼街道越寬越好？

  • 訓練資料只是一部分樣本，之後要預測的新花，和訓練資料多少會有差異。
  • 決策邊界離兩類都遠，新的花就算比訓練資料偏一點，也還在正確的那一邊。
  • 就像在兩排停好的車中間開車：走在正中間，離兩邊都最遠，最不容易擦撞。

支援向量：只有街道邊緣的資料說了算

投影片 4

仔細看最寬的那條街道：它的兩個邊緣各碰到一朵花（紅圈）。這個例子裡，整條街道只由兩朵花決定：setosa 的 (1.9, 0.4) 和 versicolor 的 (3.0, 1.1)。這些剛好落在街道邊緣上的資料，叫做支援向量（support vectors）。

補充筆記「支援向量」名稱的由來
  • 向量：每一筆資料都是一串特徵組成的向量，例如 (1.9, 0.4)，也就是平面上的一個點。
  • 支援：英文 support 是「支撐」的意思。街道邊緣靠在這幾筆資料上，就像帳篷靠幾根柱子撐住：抽掉別的東西沒關係，動到柱子，帳篷就跟著變形。
  • 中文也常翻成「支持向量」，指的是同一件事。
  • 整個模型就以它們命名：支援向量機。

一句話撐起街道的那幾筆資料。

投影片指出一個重要的性質：在街道外面加再多資料，決策邊界都不會動。決策邊界完全由支援向量決定（「支撐」住）。在下面的圖上試試看：

  • 街道外的資料：增加、刪除、移動（只要不進街道），街道完全不變。按「只留下支援向量」，只剩 2 個點，街道還是一模一樣。
  • 支援向量：只要移動其中一個，街道就跟著改變。
  • 有資料跑進街道：原本的街道不成立了，SVM 會重新找，新的街道比較窄，支援向量也換人了。
  • 兩類交錯、分不開：這時找不到任何一條「裡面沒有資料」的街道。這是下一篇要解決的問題。

SVM 很怕單位不一致

投影片 4

投影片 4 的下半部提醒：SVM 對特徵的尺度很敏感。例子只有 4 筆資料，兩個特徵的數值範圍差很多： 在 1 到 5 之間， 在 20 到 80 之間。

  • SVM 用一般的直線距離來量街道有多寬。
  • 的數字大，距離幾乎都由 決定：在 方向差 10，就比在 方向差 4 還遠。

用 scikit-learn 找出最寬的街道

投影片 3

用 SVC（Support Vector Classifier）並指定 kernel="linear"（線性核；「核」是什麼，第 3 篇會解釋），就是線性 SVM：

from sklearn.datasets import load_iris
from sklearn.svm import SVC

iris = load_iris(as_frame=True)
X = iris.data[["petal length (cm)", "petal width (cm)"]].values
y = iris.target.values
setosa_or_versicolor = (y == 0) | (y == 1)      # 只留 setosa（0）和 versicolor（1）
X = X[setosa_or_versicolor]
y = y[setosa_or_versicolor]

svm_clf = SVC(kernel="linear", C=1e100)         # C 設得極大：不允許任何資料進街道
svm_clf.fit(X, y)

svm_clf.support_vectors_
# array([[1.9, 0.4],
#        [3. , 1.1]])
svm_clf.coef_, svm_clf.intercept_
# (array([[1.29411744, 0.82352928]]), array([-3.78823471]))
  • support_vectors_：找到的支援向量，就是實驗裡畫紅圈的兩朵花。
  • coef_ 是 ，intercept_ 是 。
  • C=1e100：SVC 預設允許少數資料跑進街道（下一篇的軟間隔）。把 C 設成 這種極大的數，等於完全不允許，也就是本篇講的「街道裡不能有資料」，叫做硬間隔。

拿三朵新的花來預測，順便看決策函數 的值：

new_flowers = [[2.0, 0.5], [4.0, 1.2], [2.5, 0.8]]
svm_clf.predict(new_flowers)                       # array([0, 1, 1])
svm_clf.decision_function(new_flowers).round(2)    # array([-0.79,  2.38,  0.11])
  • decision_function 就是 。正的預測 versicolor，負的預測 setosa。
  • (4.0, 1.2)：，在街道外很遠的地方，很有把握是 versicolor。
  • (2.0, 0.5)：，預測 setosa，但 ，落在街道裡，比所有訓練資料都更靠近邊界。
  • (2.5, 0.8)：，幾乎就在決策邊界上，模型只能勉強判斷是 versicolor。

SVC 預設不輸出機率，只有 decision_function 的分數。這和邏輯迴歸不同，svm_clf.predict_proba 甚至不存在。

Python 實作

接著上面的程式，用程式驗證這篇的三個說法：街道寬度是 、只有支援向量說了算、單位會改變答案。

import numpy as np

w, b = svm_clf.coef_[0], svm_clf.intercept_[0]
2 / np.linalg.norm(w)                    # 街道寬度：np.float64(1.3038406932217397)
svm_clf.decision_function(svm_clf.support_vectors_).round(3)
# array([-1.,  1.])：支援向量剛好在街道邊緣 h = ±1

# 1) 只用兩個支援向量訓練，得到一模一樣的街道
only_sv = SVC(kernel="linear", C=1e100).fit(svm_clf.support_vectors_, [0, 1])
only_sv.coef_, only_sv.intercept_
# (array([[1.29411744, 0.82352928]]), array([-3.78823473]))

# 2) 在街道外多加三朵花，街道不變
X_new = [[5.5, 2.0], [1.0, 0.1], [4.0, 0.9]]
svm_clf.decision_function(X_new).round(2)   # array([ 4.98, -2.41,  2.13])：都在街道外
more = SVC(kernel="linear", C=1e100).fit(np.r_[X, X_new], np.r_[y, [1, 0, 1]])
more.coef_                                   # array([[1.29411744, 0.82352928]])

# 3) 一朵 versicolor 跑進街道，街道就變了
inside = SVC(kernel="linear", C=1e100).fit(np.r_[X, [[2.6, 0.9]]], np.r_[y, [1]])
inside.support_vectors_
# array([[1.9, 0.4],
#        [2.6, 0.9]])
2 / np.linalg.norm(inside.coef_[0])          # np.float64(0.8602321512655937)

98 朵花對結果完全沒有影響。第 3 個實驗加進去的 (2.6, 0.9) 原本在街道裡（），它變成新的支援向量，街道從 1.30 cm 縮成 0.86 cm。

投影片 4 的尺度例子，比較原始資料和先標準化的結果。用 make_pipeline 把 StandardScaler 和 SVM 串起來（第 2 章第 4 篇的 Pipeline），之後預測新資料時也會自動先標準化：

from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

Xs = np.array([[1, 50], [5, 20], [3, 80], [5, 60]], dtype=float)
ys = np.array([0, 0, 1, 1])

raw = SVC(kernel="linear", C=100).fit(Xs, ys)
raw.coef_, raw.support_
# (array([[0.06896552, 0.17241379]]), array([0, 3], dtype=int32))

scaled = make_pipeline(StandardScaler(), SVC(kernel="linear", C=100)).fit(Xs, ys)
scaled[-1].coef_, scaled[-1].support_
# (array([[0.62225468, 1.0825318 ]]), array([0, 1, 3], dtype=int32))

常見陷阱與自我檢查

忘了把特徵標準化數值範圍大的特徵會主宰距離，SVM 等於只看那一個特徵。先用 StandardScaler，最好和 SVM 一起放進 Pipeline。
以為每一筆訓練資料都會影響 SVM決策邊界只由支援向量決定。街道外的資料再多，對結果都沒有影響。
把間隔和街道寬度混為一談本章的間隔（margin）是邊界到最近資料的距離，是街道寬度的一半： 對上 。
以為 SVC 會輸出機率SVC 預設只有 decision_function 的分數，分數的大小代表離邊界多遠，不是機率。
以為硬間隔一定有解「街道裡不能有任何資料」只在資料線性可分時做得到。只要有一筆資料混進對方的地盤，就找不到這樣的街道，這是下一篇的主題。
在街道外再加 1,000 筆分類正確的資料，決策邊界會改變嗎？

不會。決策邊界只由支援向量決定，街道外的資料不是支援向量，加再多都一樣（實驗和 Python 實作的第 2 個例子）。

某個線性 SVM 的 ，街道多寬？間隔是多少？

，街道寬 ，間隔是一半：。

一筆新資料的 decision_function 是 0.4。模型預測哪一類？它在街道裡還是街道外？

，預測類別 1（正類）。，它在街道裡面，比所有支援向量都更靠近決策邊界，模型對它比較沒有把握。

用「年收入（元）」和「年齡（歲）」兩個特徵訓練線性 SVM，沒有先標準化，會發生什麼事？

年收入的數字是幾十萬，年齡只有幾十，距離幾乎完全由年收入決定，SVM 會幾乎只看年收入，年齡幾乎沒有作用。先標準化，兩個特徵才會被公平地考慮。

支援向量最少有幾個？可能只來自同一類嗎？

最少 2 個，而且兩類都至少有一個：街道的兩個邊緣各自要碰到一筆資料，否則街道還能再加寬。鳶尾花的例子剛好是最少的情況，兩類各 1 個；投影片 4 標準化後的例子有 3 個。
