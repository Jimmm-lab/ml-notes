5. Support Vector Machines，第 5 篇／共 7 篇（投影片 21–23）

SVM 迴歸：
讓資料盡量落在街道上

SVM 也能做迴歸，只要把目標反過來：分類時要讓資料都待在街道外，迴歸時要讓資料盡量落在街道上。街道的寬度由超參數 ε 控制，街道裡的資料完全不影響模型。這篇用線性和多項式核兩個例子，看 ε 和 C 怎麼影響預測。

這篇讀完你會知道
  • SVM 迴歸和 SVM 分類的目標為什麼剛好相反，以及街道（ε 管子）代表什麼。
  • 超參數 ε 怎麼控制街道寬度，以及為什麼模型是「ε 不敏感」的：街道裡的資料不影響預測。
  • ε 不敏感損失 和第 4 章的 MSE 有什麼不同。
  • 用 LinearSVR 做線性迴歸、用 SVR 加多項式核做非線性迴歸，以及 C 在這裡的作用。

把目標反過來

投影片 21

前四篇都在做分類。投影片 21 說，SVM 也能做迴歸（預測一個數值），訣竅是把目標反過來：

SVM 分類

在兩類之間鋪一條最寬的街道，讓資料都待在街道外。跑進街道的資料是違規。

SVM 迴歸

沿著資料鋪一條街道，讓資料盡量落在街道上。落在街道外的資料是違規。

  • 街道：以預測值 為中心，上下各 （epsilon）的帶狀區域，也常叫做 ε 管子（ε-tube）。街道寬度由超參數 控制。
  • 違規：真正的 和預測值相差超過 ，也就是資料落在街道外。
  • ε 不敏感（ε-insensitive）：在街道裡面再加多少訓練資料，模型的預測都不會變。
補充筆記街道裡的資料「不算數」
  • SVM 迴歸只處罰落在街道外的資料：預測差距在 以內，代價就是 0（下面的 ε 不敏感損失）。
  • 街道裡的資料代價是 0，而且模型稍微動一點點，它還是在街道裡，代價還是 0。所以它對「怎麼移動模型」沒有任何意見。
  • 這和第 1 篇的支援向量剛好對稱：分類時，街道外的資料不影響邊界；迴歸時，街道裡的資料不影響預測。
  • 真正決定模型的，是落在街道邊緣上或街道外的資料，它們就是 SVM 迴歸的支援向量。

一句話誤差小於 ε 就當作沒誤差，所以街道裡的資料「不算數」。

scikit-learn 裡，SVR 是 SVC 的迴歸版，LinearSVR 是 LinearSVC 的迴歸版（投影片 21）。

投影片 22 的資料是 50 筆接近一條直線的點（ 加上雜訊），用 LinearSVR 分別設 和 。拉動 ε 看看：

預測
街道寬度 2ε
在街道外

  • ε = 1.5：街道寬 3，50 筆裡只有 7 筆在街道外。預測是 。
  • ε = 0.5：街道寬 1，有 25 筆在街道外，另外還有兩筆剛好壓在街道邊緣上。預測是 。
  • 兩條直線很接近：ε 主要決定「多大的誤差可以忽略」，而不是直線的方向。
  • 按「在街道裡加一筆資料」：預測完全不變，這就是 ε 不敏感。按「在街道外加一筆」：直線會被拉過去一點。

投影片 22 對 ε 的定義：在 ε 管子裡，也就是預測值和真正的值相差不到 ε 的資料，在訓練的損失函數裡沒有任何懲罰。

ε 不敏感損失

投影片 22（和第 2 篇的成本函數對照）

把投影片 22 的定義寫成式子，每一筆資料的損失是：

  • 誤差 在 以內：損失是 0。
  • 超過 ：超出多少，就罰多少（直線上升）。
ε 不敏感損失（ε = 0.5）平方誤差（第 4 章的 MSE 用的）

橫軸是誤差 。中間那一段平平的就是「街道」：誤差小於 ε 都不罰。

和第 2 篇的軟間隔分類一樣，SVM 迴歸要最小化的成本函數，是「讓 小」加上「C 倍的總違規量」：

  • 第一項讓模型盡量平緩（權重小），作用就是正則化。
  • C 越大，違規越貴，模型越努力貼近每一筆資料；C 越小，正則化越強，預測越平緩。
  • 和平方誤差比起來，ε 不敏感損失對小誤差完全不在乎，對大誤差也只是線性增加，所以比較不怕離群值。
補充筆記ε 不敏感損失和 MSE 的比較
  • MSE（平方誤差）：每一點誤差都要罰，而且越大罰得越重（平方）。一筆離群值的誤差是 10，就要付 100，會把整條線拉過去。
  • ε 不敏感損失：誤差小於 完全不罰；超過之後只線性增加。誤差 10 只要付 。
  • 所以 SVM 迴歸比較不怕離群值，而且只由街道邊緣和街道外的資料決定（稀疏）。
  • 代價是多了一個要調的超參數 ，而且沒有像正規方程式那樣一步算出答案的公式。
  • 沒有哪一個一定比較好。資料有不少離群值、或小誤差本來就無所謂時，ε 不敏感損失比較合適。

一句話MSE 在意每一點誤差；SVM 迴歸只在意超出 ε 的部分。

加上核：非線性迴歸

投影片 23

要處理非線性的資料，一樣可以用核技巧。投影片 23 的資料是 100 筆接近拋物線的點（ 加上雜訊），用二次的多項式核：

import numpy as np
from sklearn.svm import SVR

np.random.seed(42)
m = 100
X = 2 * np.random.rand(m, 1) - 1
y = (0.2 + 0.1 * X + 0.5 * X ** 2 + np.random.randn(m, 1) / 10).ravel()

svm_poly_reg = SVR(kernel="poly", degree=2, C=100, epsilon=0.1)
svm_poly_reg.fit(X, y)

投影片比較了 C = 100 和 C = 0.01（ε 都是 0.1）：

  • C = 100（正則化很弱）：曲線兩端翹得比較高， 的預測是 0.74，盡量把資料放進街道。
  • C = 0.01（正則化很強）：曲線比較平， 的預測只有 0.65，中間是 0.22，有更多資料在街道外。
  • 把 C 從 0.01 慢慢拉大，曲線越來越彎；但 C 大約超過 0.3 之後就不再變化（C = 1、10、100 的預測都一樣）：這個模型能畫的形狀有限，已經貼到極限了，原因見下一點。
  • 真正的規律在 、、 分別是 0.6、0.2、0.8。兩個模型的曲線都左右對稱，抓不到 這一項：SVR 的 coef0 預設是 0，二次核只剩 項（第 3 篇的陷阱）。想要一次項，可以設 coef0=1。

Python 實作

投影片 22 的資料和 LinearSVR：

import numpy as np
from sklearn.svm import LinearSVR, SVR

np.random.seed(42)
m = 50
X = 2 * np.random.rand(m, 1)
y = (4 + 3 * X + np.random.randn(m, 1)).ravel()

svm_reg = LinearSVR(epsilon=1.5, random_state=42)
svm_reg.fit(X, y)
svm_reg.coef_, svm_reg.intercept_          # (array([2.99278375]), array([3.53362371]))
(np.abs(y - svm_reg.predict(X)) > 1.5).sum()   # np.int64(7)：7 筆在街道外

驗證 ε 不敏感：在 加一筆在街道裡的資料（比預測高 0.8 < 1.5），重新訓練，係數一模一樣；改成比預測高 4（在街道外），係數就變了：

y_hat = svm_reg.predict([[1.0]])[0]        # 6.526...
inside = LinearSVR(epsilon=1.5, random_state=42).fit(np.r_[X, [[1.0]]], np.r_[y, [y_hat + 0.8]])
inside.coef_, inside.intercept_           # (array([2.99278375]), array([3.53362371]))：完全沒變
outside = LinearSVR(epsilon=1.5, random_state=42).fit(np.r_[X, [[1.0]]], np.r_[y, [y_hat + 4]])
outside.coef_, outside.intercept_         # (array([3.00787574]), array([3.54347866]))

同一份資料改用 SVR(kernel="linear")，結果卻差很多：

lin_svr = SVR(kernel="linear", epsilon=1.5, C=1).fit(X, y)
lin_svr.coef_, lin_svr.intercept_         # (array([[2.07686895]]), array([4.87372826]))
svm_reg10 = LinearSVR(epsilon=1.5, intercept_scaling=10, random_state=42).fit(X, y)
svm_reg10.coef_, svm_reg10.intercept_     # (array([2.15272527]), array([4.69177179]))

LinearSVR 和 SVR(kernel="linear") 不一樣

LinearSVR 把截距也當成一個權重一起正則化（第 2 篇），把它往 0 拉；這份資料的截距又大（約 4），所以 LinearSVR 得到 ，SVR 得到 。設 intercept_scaling=10，截距受到的正則化只剩原本的 1/100，LinearSVR 就變成 ，接近 SVR 了。

只做 StandardScaler 解決不了這件事：它縮放的是 ，截距反映的是 的高低，照樣會被往 0 拉。

另外，ε 的單位和 一樣： 是房價（萬元）時，ε = 1.5 代表誤差 1.5 萬元以內都不罰。

投影片 23 的資料和多項式核 SVR：

from sklearn.svm import SVR

np.random.seed(42)
m = 100
X = 2 * np.random.rand(m, 1) - 1
y = (0.2 + 0.1 * X + 0.5 * X ** 2 + np.random.randn(m, 1) / 10).ravel()

for C in [100, 0.01]:
    svm_poly_reg = SVR(kernel="poly", degree=2, C=C, epsilon=0.1).fit(X, y)
    print(C, svm_poly_reg.predict([[-1], [0], [1]]).round(3), len(svm_poly_reg.support_))
# 100 [0.74  0.168 0.74 ] 30
# 0.01 [0.646 0.222 0.646] 36

support_ 是支援向量的編號：C = 100 時有 30 筆，C = 0.01 時有 36 筆，都是在街道邊緣上或街道外的資料。

常見陷阱與自我檢查

把 ε 和 C 的角色搞混ε 決定「多小的誤差可以不管」（街道寬度）；C 決定「超出街道的誤差有多貴」（正則化強度）。
忘了 ε 有單位ε 和 同單位。 換了單位（例如元換成萬元），ε 也要跟著換。
以為街道裡的資料也會影響模型街道裡的資料損失是 0，不是支援向量；加再多，預測都不變。
以為 LinearSVR 和 SVR(kernel="linear") 一樣LinearSVR 連截距也正則化， 的高低離 0 很遠時兩者差很多。想接近 SVR，把 intercept_scaling 調大。
多項式核 SVR 沒設 coef0預設 0 只保留最高次項，二次核的預測一定左右對稱。
SVM 分類和 SVM 迴歸，「違規」的意思有什麼不同？

分類：資料跑進街道（或分錯邊）是違規，目標是讓資料都在街道外。迴歸：資料落在街道外（誤差超過 ε）是違規，目標是讓資料盡量在街道上。

ε = 0.5。某筆資料的 ，預測 ，損失是多少？如果 呢？

，在街道裡，損失 0。，超出 ，損失 0.5。

把 ε 調大，在街道外的資料會變多還是變少？支援向量呢？

街道變寬，落在街道外的資料變少，支援向量（街道邊緣上或街道外的資料）通常也變少，模型由更少的資料決定。

SVM 迴歸模型過擬合，可以怎麼調？

調小 C（正則化變強，預測更平緩）；用核的話，也可以降低 degree 或調小 γ。調大 ε 也會讓模型忽略更多小誤差，變得比較不貼著資料。
