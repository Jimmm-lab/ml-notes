為什麼要辛苦改寫成這樣？投影片 40 說原本的問題很難解。改寫之後，目標函數是二次的「碗形」，限制式都是線性的，這種問題叫凸二次規劃（convex quadratic programming）。兩種寫法的答案一樣，但凸二次規劃有現成、可靠的演算法可以解。

補充筆記什麼是凸二次規劃？為什麼比較好解？
  • 二次規劃（QP）：目標函數是二次式（例如 ），限制式都是一次式（例如 ）的最佳化問題。
  • 凸：目標函數是碗形，而所有限制式一起圍出的「可行區域」也是凸的（沒有凹進去的地方）。
  • 好處：只有一個最低點，沒有會卡住的局部最小值（第 4 章第 2 篇講過凸函數的好處），而且數學家已經有很多成熟、可靠的演算法可以解。

Python 實作

投影片的 14 筆資料，先算幾個超平面的函數間隔和幾何間隔：

import numpy as np

X = np.array([[8, 7], [4, 10], [9, 7], [7, 10], [9, 6], [4, 8], [10, 10],   # 三角形 +1
              [2, 7], [8, 3], [7, 5], [4, 4], [4, 6], [1, 3], [2, 5]])      # 星星 −1
y = np.array([1] * 7 + [-1] * 7)

def functional_margin(w, b):
    return np.min(y * (X @ w + b))

def geometric_margin(w, b):
    return np.min(y * (X @ w + b) / np.linalg.norm(w))

w = np.array([0.4, 1])
functional_margin(w, -8.5), geometric_margin(w, -8.5)
# (np.float64(0.7000000000000002), np.float64(0.6499336836196816))
functional_margin(10 * w, -85), geometric_margin(10 * w, -85)
# (np.float64(7.0), np.float64(0.6499336836196815))：F 變 10 倍，M 不變

接著直接解投影片 40 的最佳化問題。SciPy 的 minimize 可以處理「目標函數 + 不等式限制」，把參數排成 ：

from scipy.optimize import minimize

objective = lambda p: 0.5 * p[:2] @ p[:2]                    # ½‖w‖²
constraints = {"type": "ineq",                               # 每一筆都要 ≥ 0
               "fun": lambda p: y * (X @ p[:2] + p[2]) - 1}
res = minimize(objective, x0=[0, 0, 0], constraints=[constraints])
res.x                            # array([ 0.44444444,  1.11111111, -9.66666667])
1 / np.linalg.norm(res.x[:2])    # np.float64(0.8356290217966512)：最大的幾何間隔 M

from sklearn.svm import SVC

svm_clf = SVC(kernel="linear", C=1e10).fit(X, y)
svm_clf.coef_, svm_clf.intercept_
