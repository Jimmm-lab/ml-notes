每個類別一個分數

投影片 54

邏輯迴歸可以推廣成直接處理多個類別，不必訓練好幾個二元分類器再組合起來（例如第 3 章的「一對其餘」OvR）。這叫做 Softmax 迴歸，也叫多項邏輯迴歸（Multinomial Logistic Regression）。

給一筆資料 ，softmax 迴歸先替每個類別 算一個分數，算法和線性迴歸一樣是加權總和：

注意每個類別都有自己專屬的參數向量 。這些向量通常一列一列地疊成一個參數矩陣 （第 列就是 ）。有 個類別、 個特徵時， 是 的矩陣（多的 1 是偏差項）。

接著用 softmax 函數（也叫正規化指數函數，normalized exponential）把這 個分數變成每一類的機率。

softmax 函數

  • 是類別數； 是這筆資料的 個分數組成的向量。
  • 是「已知每一類的分數時，這筆資料屬於類別 」的估計機率。（這裡的 是 softmax，不是上一篇的 sigmoid，投影片沿用了同一個符號。）

做法分兩步：先對每個分數取指數 ，讓它們都變成正數；再除以總和，讓它們加起來等於 1。調整下面三個分數看看（鳶尾花的類別沿用 scikit-learn 的編號 0、1、2：setosa、versicolor、virginica，所以 、 這些下標從 0 開始；公式裡的 則從 1 數到 ）：

幾個重要性質：

  • 分數越高，機率越高，而且因為取了指數，差距會被放大：分數差 1，機率差約 倍；差 3，就差約 20 倍。最高分的類別拿走大部分機率，但其他類別也分得到一點，所以叫「軟」的最大值（soft max）。
  • 三個分數同時加上同一個數，機率完全不變（按「都加 2」試試）：分子分母都乘上同一個 ，約掉了。只有分數之間的差有意義。
  • 三個分數同時乘 2，差距變大，最高分的類別機率更接近 1；同時乘一個很小的數，機率會越來越平均。

預測：argmax

投影片 56

預測時，選估計機率最高的類別：

argmax 運算回傳「讓函數最大的那個變數值」，這裡就是讓估計機率最大的 。第二個等號成立，是因為所有類別的分母都一樣，而 是遞增函數：分數最高的類別，機率也最高。所以只要預測類別、不需要機率時，比分數就好，不必真的算 softmax（和上一篇「看加權總和的正負就好」是同一個道理）。

只能用在互斥的類別

softmax 迴歸一次只預測一個類別：它是多類別（multiclass）分類器，不是多輸出（multioutput）分類器。所以只能用在彼此互斥的類別，例如植物的不同品種（一朵花只會是一種）。不能用它在一張照片裡辨認出好幾個人，因為那需要同時回答好幾個「是不是某人」。

邏輯迴歸 vs. softmax 迴歸

投影片 58

投影片把兩個模型畫成「網路」來比較：

  • 邏輯迴歸： 個特徵各乘一個權重，加上偏差 ，經過一個加總 Σ 和 sigmoid，再用 0.5 切成 0 或 1（投影片稱為 quantizer）。訓練時用誤差回頭調整權重。
  • softmax 迴歸：每個類別各有一個 Σ（各自的權重和偏差）， 個分數一起送進 softmax，得到 個機率，再用 argmax 選出類別。訓練時用交叉熵比較這些機率和 one-hot 的正確答案。

投影片的問題：各有幾個參數（權重）？

個特徵時，邏輯迴歸有 個權重加 1 個偏差，共 個參數。softmax 迴歸有 組，每組 個，共 個。

例如下面的鳶尾花模型：2 個特徵、3 個類別，共 個參數（scikit-learn 存成 3×2 的 coef_ 加上 3 個 intercept_）。

用 scikit-learn 分三種鳶尾花

投影片 59–60

scikit-learn 的 LogisticRegression 在訓練資料超過兩類（三類以上）時，會自動使用 softmax 迴歸（使用預設的 solver="lbfgs" 時）。它同樣預設加 ℓ2 正則化，用超參數 C 控制（上一篇講過，C 越小限制越強）。這次用花瓣長度、寬度兩個特徵，分三種鳶尾花：

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

iris = load_iris(as_frame=True)
X = iris.data[["petal length (cm)", "petal width (cm)"]].values
y = iris["target"].values                  # 0 setosa、1 versicolor、2 virginica
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

softmax_reg = LogisticRegression(C=30, random_state=42)
softmax_reg.fit(X_train, y_train)

softmax_reg.predict([[5, 2]])               # array([2])
softmax_reg.predict_proba([[5, 2]]).round(2)    # array([[0.  , 0.04, 0.96]])

花瓣長 5 公分、寬 2 公分的花，模型認為是 virginica（類別 2）的機率是 96%，versicolor 4%，setosa 幾乎是 0（約 ）。這個模型在 112 筆訓練資料上的準確率是 94.6%，38 筆測試資料全部分對（100%）。

投影片 60 的舊寫法（已淘汰）

很舊的 scikit-learn 版本裡，LogisticRegression 遇到多類別時預設用「一對其餘」（OvR），要設定 multi_class="multinomial" 才會切換成 softmax 迴歸，所以投影片 60 的程式寫成 LogisticRegression(multi_class="multinomial", solver="lbfgs", C=10)。這個參數後來被標為淘汰，在本頁使用的 1.8 版已經移除，照抄會出錯。現在 lbfgs 等求解器遇到多類別一律直接用 softmax（只有 liblinear 只能做二元分類）。

投影片 60 用全部 150 筆資料、C=10 訓練，所以機率（94.2%）和上面（96%）略有不同。

投影片的問題：softmax 迴歸是線性模型嗎？看任意兩類 、 的機率比，分母約掉：

右邊對 是線性的。類別 和 的分界是兩者機率相等的地方：，也就是 ，這是一條直線（特徵更多時是平面、超平面）。所以：

  • 任兩類之間的決策邊界都是直線；每一類的區域是由幾條直線圍出來的凸多邊形（可能延伸到無限遠）。投影片 62 吳恩達（Andrew Ng）課程的例子，3 到 6 類都是這樣被直線切開。
  • 和邏輯迴歸一樣，「對數勝算」是特徵的線性函數，所以它也是一種廣義線性模型。
  • 但機率的等高線不一定是直線：versicolor 的 0.45 等高線是彎的，因為 同時和另外兩類比較（分母有三項）。只有兩類時，等高線才全部是直線（上一篇的圖）。
  • 三個區域交會的那一點，三類的分數相等，機率都是 1/3。

Python 實作

接著上面的程式，看分數和 softmax 的計算，並確認參數的形狀：

import numpy as np

softmax_reg.coef_.shape, softmax_reg.intercept_.shape   # ((3, 2), (3,))：共 9 個參數
scores = softmax_reg.decision_function([[5, 2]])      # 三類的分數 s_k(x)
scores.round(2)                 # array([[-10.39,   3.61,   6.77]])
np.exp(scores) / np.exp(scores).sum()    # 和 predict_proba 一樣，約 [[3.4e-08, 0.041, 0.959]]
softmax_reg.score(X_train, y_train), softmax_reg.score(X_test, y_test)
# (0.9464285714285714, 1.0)

不用 scikit-learn，直接用投影片 57 的梯度做批次梯度下降（沒有正則化）：

X_b = np.c_[np.ones(len(X_train)), X_train]   # 加上 x0 = 1
Y = np.eye(3)[y_train]                         # one-hot：類別 2 → [0, 0, 1]

def softmax(S):
    S = S - S.max(axis=1, keepdims=True)       # 先減掉最大分數，避免 exp 溢位；機率不變
    E = np.exp(S)
    return E / E.sum(axis=1, keepdims=True)

Theta = np.zeros((3, 3))                       # 第 k 列是 θ(k)
for iteration in range(50_000):
    P = softmax(X_b @ Theta.T)                 # 每筆資料三類的機率
    gradients = (P - Y).T @ X_b / len(X_b)     # 三個類別的梯度一次算完
    Theta -= 0.1 * gradients

(softmax(X_b @ Theta.T).argmax(axis=1) == y_train).mean()   # np.float64(0.9464285714285714)

從全部是 0 的 出發，三類的機率一開始都是 1/3，交叉熵是 ；走 50,000 步後降到約 0.096，訓練準確率和 scikit-learn 一樣是 94.6%。softmax() 裡先減掉最大分數，正是利用「分數都加同一個數，機率不變」的性質，避免 大到超出電腦能表示的範圍。

常見陷阱與自我檢查

用 softmax 做多標籤分類softmax 的機率加起來是 1，一次只選一個類別，只適合互斥的類別。一張照片裡有好幾個人，要用多個獨立的二元分類器（多輸出）。
照抄舊程式的 multi_classscikit-learn 1.8 已移除這個參數；直接用 LogisticRegression()，多類別時自動是 softmax。
直接算 exp(分數)分數很大時 會溢位變成 inf。先減掉最大分數再取指數，結果完全一樣。
以為機率等高線也是直線決策邊界（兩類機率相等的地方）是直線，但三類以上時，某一類機率的等高線一般是曲線。

都是 。分數只有差距有意義，同時加 100 不影響機率。

有 4 個特徵、10 個類別的 softmax 迴歸，有幾個參數？

個。

某筆資料的正確類別是 versicolor，模型估的機率是 。這筆資料的交叉熵是多少？versicolor 參數向量的梯度方向會怎樣調整？

交叉熵只看正確類別：。對 versicolor，，梯度下降往反方向走，會讓這筆資料的 versicolor 分數變高；另外兩類的 是正的，它們的分數會被調低。

為什麼說邏輯迴歸是 softmax 迴歸的特例？

兩類時令 ，softmax 的 就化成 sigmoid ，而兩類的交叉熵就是 log loss。假設函數和成本函數都相同。
