為什麼要正則化

投影片 34–35

上一篇的學習曲線告訴我們：過擬合時，可以多給訓練資料，直到驗證誤差接近訓練誤差。但資料不一定拿得到，所以投影片提出第二條路：正則化（regularization），也就是限制模型。模型的自由度越少，就越難把雜訊背起來。

  • 對多項式模型，最簡單的限制是降低次數。
  • 對線性模型，通常是限制權重：在成本函數裡多加一項，權重越大，成本越高。這一篇介紹三種加法：Ridge 迴歸、Lasso 迴歸、Elastic Net。

Ridge 迴歸

投影片 36

Ridge 迴歸（也叫 Tikhonov 正則化）在 MSE 後面加上「權重平方和」：

多出來的這一項叫正則化項。它讓學習演算法除了要把資料擬合好，還要盡量讓權重小。這裡的 就是權重向量的長度（ℓ2 範數）的平方，所以 Ridge 又叫 ℓ2 正則化。

  • 超參數 控制要限制多少。 時就是普通的線性迴歸； 非常大時，所有權重都被壓到幾乎是 0，模型變成一條穿過資料平均值的水平線 。
  • 偏差項 不懲罰：注意加總從 開始。 只是把整條線上下平移，和線「彎不彎、陡不陡」無關；懲罰它只會把預測值無緣無故拉向 0。
  • 一定要先縮放特徵：懲罰項對每個權重一視同仁。如果某個特徵用公尺、另一個用毫米，同樣的影響力需要的權重差 1000 倍，懲罰就不公平了。所以做 Ridge 前要先標準化（例如 StandardScaler），大部分正則化模型都是如此。

訓練用的成本，不等於評估用的指標

投影片 38

注意上面實驗的讀數：訓練、測試都用普通的 RMSE，沒有加正則化項。投影片強調：

  • 正則化項只在訓練時加進成本函數。模型訓練好之後，要用沒有正則化項的指標來評估它。正則化項是給學習演算法的限制，不是模型好壞的一部分。
  • 更一般地說，訓練用的成本函數常常和測試用的評估指標不同。好的訓練成本函數要容易最佳化（導數好算、性質好）；評估指標則要盡量貼近最終目標。例如分類器常用 log loss（第 6 篇會看到）訓練，卻用 precision、recall 評估。

Lasso 是 Least Absolute Shrinkage and Selection Operator 的縮寫。它把 Ridge 的「平方」換成「絕對值」（ℓ1 範數），而且不再乘 ：

Lasso 最重要的特性：它傾向把最不重要的特徵的權重直接設成 0。也就是說，Lasso 會自動做特徵選擇，輸出一個稀疏模型（sparse model，只有少數權重不是 0）。

只看懲罰項（投影片左邊兩張），從 (2, 0.5) 出發：

  • ℓ1：次梯度是 ，兩個方向每步都減少一樣多。所以路徑先斜斜地走，比較小的 先到 0，接著沿著 軸走到原點。到了 0 附近，次梯度的大小不會變小（不是 +1 就是 −1），所以會在 0 的兩邊來回彈跳。
  • ℓ2：梯度是 ；梯度下降往反方向走，所以每一步都直直朝向原點，而且離原點越近，梯度越小，步伐自然越來越小，不會彈跳。

MSE 加上懲罰項（投影片右邊兩張），從 (0.25, −1) 出發：

  • Lasso：拉大 α，最低點（紅色方塊）先往左下移動，α 約 0.87 時碰到 軸，之後就沿著 軸往左走（投影片上的黃色虛線）；α = 0.9 時，最低點的 已經剛好是 0。梯度下降很快走到 附近，然後在 0 附近鋸齒狀地跳動（每次跳的大小和「學習率 × α」同一個數量級）。要讓它真正收斂，訓練時要逐步降低學習率。
  • Ridge：梯度在接近最低點時越來越小，所以梯度下降自然慢下來，不會彈跳。α 越大，最低點越靠近原點，但永遠不會剛好有一個座標變成 0。

換個角度： 的「邊際懲罰」在 很小時仍然是 α； 的邊際懲罰是 ，在 0 附近幾乎是 0。所以對一個「沒什麼用」的特徵，Ridge 會讓它保留一點點權重，Lasso 會讓它直接歸零。

Elastic Net 與怎麼選

投影片 42–43

Elastic Net 把 Ridge 和 Lasso 的正則化項混在一起，再用混合比例 （另一個超參數）控制比例：

時就是 Ridge， 時就是 Lasso。scikit-learn 的 ElasticNet 用 l1_ratio 表示 。

該用哪一個？投影片的建議：

  • 幾乎都應該加一點正則化，所以一般要避免完全不加限制的線性迴歸。
  • Ridge 是不錯的預設選擇。但如果你懷疑只有少數幾個特徵有用，就選 Lasso 或 Elastic Net，因為它們會把沒用的特徵的權重壓成 0。
  • 一般來說，Elastic Net 比 Lasso 好。因為當特徵數比訓練筆數多，或好幾個特徵高度相關時，Lasso 可能表現得很不穩定：例如兩個幾乎一樣的特徵，Lasso 常常只留其中一個，而資料稍微變一下，留下的可能就換成另一個。Elastic Net 裡的 ℓ2 部分會讓相關的特徵傾向一起保留、分攤權重，比較穩定。

提前停止

投影片 44

對梯度下降這類一步一步學的演算法，還有一種完全不同的正則化方法：驗證誤差一到最低點就停止訓練，叫做提前停止（early stopping）。

下面重現投影片的實驗：100 筆二次資料（上一篇的那一份），一半訓練、一半驗證；模型是 90 次多項式（先標準化），用 SGDRegressor 一個 epoch 一個 epoch 地訓練 500 個 epoch，每個 epoch 結束都記錄兩個 RMSE。（投影片的圖數字不同：那裡最低約 1.15，而且標示是用批次梯度下降訓練；這裡最低約 1.41。但「先降、到最低點、再回升」的形狀一樣。這裡的學習率很小，又只在每個 epoch 結束時量一次，所以曲線看起來很平滑。）

驗證 RMSE訓練 RMSE縱軸只畫到 4，最前面幾個 epoch 的誤差更大
訓練 RMSE這個 epoch 結束時
驗證 RMSE這個 epoch 結束時
目前最好的模型

  • 一開始，兩個 RMSE 都快速下降：模型正在學習。
  • 大約第 250 個 epoch，驗證 RMSE 降到最低（約 1.41）。
  • 之後訓練 RMSE 還在慢慢下降，驗證 RMSE 卻開始回升：模型開始過擬合。提前停止就是在最低點停下來（實務上是記住最低點的模型，最後拿它來用）。

這個方法簡單又有效，課本引用 Geoffrey Hinton 的話，稱它是「美好的免費午餐」（beautiful free lunch）。

隨機和小批次梯度下降：曲線不平滑怎麼辦？

投影片提醒，用 SGD 或小批次時，曲線會上下抖動，很難判斷到底是不是已經到最低點。常見做法：驗證誤差超過最低值一段時間（例如連續 10 個 epoch 都沒有更好）才停止，然後把模型退回到驗證誤差最低的那一刻。scikit-learn 的 SGDRegressor(early_stopping=True) 會自動切出一部分訓練資料當驗證資料，驗證分數連續 n_iter_no_change 個 epoch 都沒有進步就停止。不過它停下後留下的是最後一個 epoch 的模型，不會自動退回到最好的那一刻；要退回，就得像下面的程式那樣自己用 deepcopy 保存。

Python 實作

課本的 20 筆資料，用三種方式做 Ridge，都在 預測：

import numpy as np
from sklearn.linear_model import Ridge, SGDRegressor

np.random.seed(42)
m = 20
X = 3 * np.random.rand(m, 1)
y = 1 + 0.5 * X + np.random.randn(m, 1) / 1.5

ridge_reg = Ridge(alpha=0.1, solver="cholesky")   # 相當於投影片的 α = 2×0.1/20 = 0.01
ridge_reg.fit(X, y)
ridge_reg.predict([[1.5]])      # array([1.55325833])

sgd_reg = SGDRegressor(penalty="l2", alpha=0.1 / m, tol=None,
                       max_iter=1000, eta0=0.01, random_state=42)
sgd_reg.fit(X, y.ravel())       # SGD 要一維的 y
sgd_reg.predict([[1.5]])        # array([1.55302613])：SGD 的結果很接近

X_b = np.c_[np.ones((m, 1)), X]
A = np.diag([0.0, 1.0])         # 左上角是 0：不懲罰 θ0
alpha = 0.01                    # 投影片公式的 α
theta = np.linalg.solve(X_b.T @ X_b + m * alpha / 2 * A, X_b.T @ y)
theta.ravel()                   # array([0.97898394, 0.3828496 ])
ridge_reg.intercept_, ridge_reg.coef_   # (array([0.97898394]), array([0.3828496]))：一樣

Lasso 與 Elastic Net（Lasso 也可以改用 SGDRegressor(penalty="l1")）：

from sklearn.linear_model import Lasso, ElasticNet

lasso_reg = Lasso(alpha=0.1)
lasso_reg.fit(X, y)
lasso_reg.predict([[1.5]])      # array([1.53788174])

elastic_net = ElasticNet(alpha=0.1, l1_ratio=0.5)
elastic_net.fit(X, y)
elastic_net.predict([[1.5]])    # array([1.54333232])

實驗裡的「Lasso、10 次多項式、α = 0.01」：

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler

model = make_pipeline(PolynomialFeatures(degree=10, include_bias=False),
                      StandardScaler(), Lasso(alpha=0.01))
model.fit(X, y.ravel())
(model[-1].coef_ != 0).sum()    # np.int64(2)：只剩 2 個權重不是 0

y = 0.5 * X ** 2 + X + 2 + np.random.randn(m, 1)
X_train, y_train = X[: m // 2], y[: m // 2, 0]
X_valid, y_valid = X[m // 2 :], y[m // 2 :, 0]

preprocessing = make_pipeline(PolynomialFeatures(degree=90, include_bias=False),
                              StandardScaler())
X_train_prep = preprocessing.fit_transform(X_train)
X_valid_prep = preprocessing.transform(X_valid)
sgd_reg = SGDRegressor(penalty=None, eta0=0.002, random_state=42)
best_valid_rmse = float("inf")

for epoch in range(500):
    sgd_reg.partial_fit(X_train_prep, y_train)     # 再訓練一個 epoch
    y_valid_predict = sgd_reg.predict(X_valid_prep)
    val_error = root_mean_squared_error(y_valid, y_valid_predict)
    if val_error < best_valid_rmse:
        best_valid_rmse = val_error
        best_model = deepcopy(sgd_reg)            # 複製一份目前最好的模型

best_valid_rmse                 # 1.4099...（第 250 個 epoch）

partial_fit() 每呼叫一次，就把訓練資料走一遍（一個 epoch），而且接著上一次的結果繼續，不會從頭開始。deepcopy() 會把模型連同學到的參數整個複製，之後繼續訓練也不會改到這份複本。

常見陷阱與自我檢查

沒有先縮放特徵正則化項對每個權重一視同仁。特徵的單位不同，懲罰就不公平。用 Ridge、Lasso、Elastic Net 前，先用 StandardScaler（放在 pipeline 裡）。
用加了正則化項的成本來評估模型正則化項只是訓練時的限制。比較模型時用 RMSE 這類不含正則化項的指標。
直接沿用公式裡的 α投影片、課本和 scikit-learn 對 α 的寫法差了常數倍。α 要用驗證資料或交叉驗證去挑（scikit-learn 有 RidgeCV、LassoCV），不要用測試資料挑。
以為正則化越多越好α 太大會欠擬合。上面的線性模型本來就沒有過擬合，加正則化只讓測試誤差變大。
Ridge 的 α 調到非常大，模型會變成什麼？

所有權重 都趨近 0，但 沒有被懲罰，所以模型變成水平線 。只剩 時，讓 MSE 最小的 是資料的平均值 （實驗裡 α = 10000 的截距 1.504，和 幾乎一樣）。

想從 1000 個特徵中找出真正有用的幾個，該用 Ridge 還是 Lasso？

Lasso（或 Elastic Net）。它會把不重要的特徵權重壓成剛好 0，等於自動挑出特徵；Ridge 只會讓權重變小，每個特徵都還留著一點。如果特徵之間高度相關，或特徵比資料筆數多，選 Elastic Net 比較穩定。

為什麼用 Lasso 時，固定學習率的梯度下降最後會在 0 附近彈跳？

的次梯度大小永遠是 1（ 時），不會因為接近 0 而變小。權重剛越過 0，就被以同樣的力氣推回來，所以在 0 的兩邊來回。逐步降低學習率，彈跳的幅度才會跟著變小。

用小批次梯度下降做提前停止，驗證誤差第一次回升就立刻停下，可能有什麼問題？

小批次的曲線會抖動，第一次回升可能只是雜訊，真正的最低點還在後面。應該等驗證誤差「一段時間都沒有更好」才停，並把模型退回到驗證誤差最低時的版本。
