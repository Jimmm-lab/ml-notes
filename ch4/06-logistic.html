用迴歸做分類

投影片 45

投影片的第一句話：迴歸演算法也可以拿來分類。邏輯迴歸（Logistic Regression，也叫 Logit Regression）常用來估計「一筆資料屬於某個類別的機率」，例如「這封信是垃圾郵件的機率是多少？」

  • 它是二元分類器：估計的機率大於 50%，就預測這筆資料屬於這一類，稱為正類（positive class），標記為 1；否則預測不屬於，稱為負類（negative class），標記為 0。
  • 計算方式：和線性迴歸一樣，先算輸入特徵的加權總和（再加上偏差項）；但不直接輸出這個數字，而是輸出它經過邏輯函數（logistic function）之後的結果。

為什麼不能直接用線性迴歸的輸出當機率？因為加權總和可以是任何實數，例如 −3.2 或 7.5，但機率必須在 0 到 1 之間。邏輯函數就是負責把任何實數「壓」進 0 到 1 的那一步。

成本函數：log loss

投影片 47

訓練的目標：讓模型對正類（）估出高機率，對負類（）估出低機率。單一筆資料的成本這樣定義（ 是自然對數）：

y = 1 時的成本 −log(p̂)y = 0 時的成本 −log(1 − p̂)
如果真的是正類（y = 1）−log(p̂)
如果其實是負類（y = 0）−log(1 − p̂)

為什麼這樣定義很合理：

  • 在 接近 0 時變得非常大，在 時是 0（投影片右上的對數圖：， 小於 1 時 是負的）。
  • 所以正類的資料，模型若估 接近 0（很有信心地答錯），成本會非常大；估 接近 1，成本接近 0。負類反過來。

整個訓練集的成本是所有資料成本的平均，叫做 log loss（對數損失）：

這只是把兩種情況寫成一行的技巧： 不是 0 就是 1，所以括號裡的兩項每筆資料只會留下一項（投影片的紅字 Only one term per instance）。

  • 壞消息：沒有像正規方程式那樣的封閉解可以直接算出最好的 。
  • 好消息：這個成本函數是凸函數，所以梯度下降（或其他最佳化演算法）只要學習率不太大、跑得夠久，一定找得到全域最低點（第 2 篇講過凸函數的這個好處）。前提是最低點存在：如果兩類資料可以被一條直線完全分開，權重會一直變大、log loss 越來越接近 0 卻永遠到不了，這也是實務上會加正則化的原因之一；本頁的鳶尾花例子兩類有重疊，沒有這個問題。

鳶尾花資料

投影片 49–51

課本用著名的鳶尾花資料集（iris）：150 朵鳶尾花，三個品種各 50 朵（Iris setosa、Iris versicolor、Iris virginica），每朵量了 4 個數字：萼片（sepal）的長和寬、花瓣（petal）的長和寬，單位是公分。

先做一個簡單的二元分類器：只看花瓣寬度，判斷是不是 Iris virginica。virginica 標記為 1，另外兩種都是 0（150 朵中有 50 朵是 1）。

import numpy as np
from sklearn import datasets
from sklearn.linear_model import LogisticRegression

iris = datasets.load_iris()
X = iris["data"][:, 3:]                    # 只取第 4 欄：花瓣寬度
y = (iris["target"] == 2).astype(int)      # virginica 是 1，其他是 0

log_reg = LogisticRegression()
log_reg.fit(X, y)

投影片的程式寫 astype(np.int)，但 np.int 從 NumPy 1.24 起已經移除，執行會出錯，直接寫 int 就好。iris["data"][:, 3:] 寫成 3: 而不是 3，是為了讓 X 保持二維（150 列 × 1 欄），scikit-learn 要求 X 是二維的。

scikit-learn 預設會加 ℓ2 正則化（投影片 50–51）

LogisticRegression 預設會加上 ℓ2 懲罰（上一篇的 Ridge 那一種），強度由超參數 C 控制。注意 C 是正則化強度的倒數：C 越大，正則化越弱；C 越小，限制越強。預設 C=1.0、solver="lbfgs"。

投影片 51 列的是 scikit-learn 1.7.2 的參數表。在本頁使用的 1.8 版：multi_class 參數已經移除；penalty 參數也被標為即將淘汰，改用 l1_ratio 決定懲罰的種類（預設 0，也就是 ℓ2）。多類別時，lbfgs 等求解器一律直接最小化多類別（softmax）的 log loss，下一篇會講；liblinear 只能做二元分類，多類別要用 OneVsRestClassifier 包起來。

另一種做法是 SGDClassifier(loss="log_loss")：同樣是最小化 log loss 的線性模型，但用隨機梯度下降訓練，適合資料很大的情況。它也是 sklearn.linear_model 裡的類別，預設同樣加一點 ℓ2 懲罰。多類別時，它用「一對其餘」（OvR，每一類訓練一個二元分類器）的方式，再把這幾個機率各自除以它們的總和，讓加起來等於 1；如果改用預設的 loss="hinge"，得到的就是線性 SVM，不會輸出機率。

投影片 53 的圖用的是 C 非常大（，幾乎沒有正則化）的模型。比較不同的 C：

  • C 越大（正則化越弱）：權重越大，機率的等高線擠得越緊，模型對自己的判斷越「有把握」，訓練資料上的 log loss 越低。
  • C 越小（正則化越強）：權重被壓小，等高線散開，機率都比較接近 0.5；C = 0.01 時，邊界明顯偏掉，準確率降到 88.7%。
  • 和上一篇一樣，C 要用驗證資料來挑，不能只看訓練資料。

Python 實作

接著上面的 log_reg，找出決策邊界並預測兩朵花：

log_reg.intercept_, log_reg.coef_    # (array([-7.19342106]), array([[4.33251974]]))

X_new = np.linspace(0, 3, 1000).reshape(-1, 1)      # 0 到 3 公分
y_proba = log_reg.predict_proba(X_new)               # 每一列是 [P(y=0), P(y=1)]
decision_boundary = X_new[y_proba[:, 1] >= 0.5][0]
decision_boundary                    # array([1.66066066])

log_reg.predict([[1.7], [1.5]])      # array([1, 0])
log_reg.predict_proba([[1.7], [1.5]]).round(3)
# array([[0.457, 0.543],
#        [0.667, 0.333]])

predict_proba() 每一列有兩個機率，依序是「類別 0」和「類別 1」，加起來是 1。寬 1.7 公分的花，是 virginica 的機率 0.543，超過 0.5，所以預測 1。

不用 scikit-learn，直接用投影片 48 的梯度做批次梯度下降（沒有正則化）：

X_b = np.c_[np.ones((150, 1)), X]           # 加上 x0 = 1
sigmoid = lambda t: 1 / (1 + np.exp(-t))

theta = np.zeros((2, 1))
eta = 0.5
for iteration in range(100_000):
    gradients = X_b.T @ (sigmoid(X_b @ theta) - y.reshape(-1, 1)) / 150
    theta -= eta * gradients

theta.ravel()      # array([-21.12557104,  12.94746462])

結果就是上面實驗一直按梯度下降最後停下的地方。兩個特徵（投影片 53）：

X = iris["data"][:, 2:]                     # 花瓣長度、花瓣寬度
log_reg2 = LogisticRegression(C=1e10, max_iter=10_000)   # C 很大：幾乎不正則化
log_reg2.fit(X, y)
log_reg2.score(X, y)                        # 0.96：150 朵分對 144 朵

常見陷阱與自我檢查

把邏輯迴歸當成迴歸問題名字裡有「迴歸」，但它是分類模型：輸出的是「屬於正類的機率」，再用 0.5 切成 0 或 1。
以為 C 越大正則化越強C 是正則化強度的倒數，和上一篇 Ridge 的 alpha 方向相反。
沿用舊程式的 np.intNumPy 1.24 起 np.int 已移除，用 int。

為什麼邏輯迴歸不用像正規方程式那樣的公式直接算出 θ？

因為 log loss 的梯度 = 0 這個方程式裡有 ，解不出封閉形式的答案。但 log loss 是凸函數，只要最低點存在（兩類資料不能被一條直線完全分開），用梯度下降一定找得到全域最低點。

只用花瓣寬度時，決策邊界 。如果 和 都乘以 2，邊界和機率曲線會怎樣變？

邊界不變（比值一樣），但曲線變得更陡：離邊界同樣距離的地方，機率更接近 0 或 1。這就是上面梯度下降一直走、權重一直變大時看到的現象。
