線性迴歸有兩種訓練方法，這是本章前半段的主軸：

方法一：直接算（本篇）

用一個公式一步算出最好的參數，叫做封閉解（closed-form solution），也就是正規方程式。

方法二：一步一步試（第 2、3 篇）

從隨便一組參數出發，每次往「誤差變小」的方向走一小步，叫做梯度下降（gradient descent）。

第一種方法又快又準，為什麼還需要第二種？讀到後面的〈計算量〉一節就會知道。

線性迴歸模型

投影片 3

線性迴歸的預測方式很單純：把每個特徵乘上一個權重，全部加起來，再加上一個常數。

  • （讀作 y-hat）：模型的預測值。沒有帽子的 是真正的答案。
  • ：這一筆資料的 個特徵。
  • ：每個特徵的權重（feature weights），代表這個特徵每增加 1，預測值變多少。
  • ：偏差項（bias term），也就是所有特徵都是 0 時的預測值，相當於直線的截距。

怎麼判斷一條線好不好：MSE

投影片 4

每一筆資料的答案和預測值之間都有一段差距 ，叫做殘差（residual），正值代表點在線的上方。把每段殘差平方、再取平均，就是均方誤差（Mean Squared Error，MSE）：

是資料筆數，右上角的 代表「第 筆」（不是次方）。為什麼要平方？一是正負不會互相抵銷；二是差得越多罰得越重（差 2 罰 4，差 10 罰 100）；三是平方函數很平滑，後面要微分時很方便。

MSE、RMSE、RSS：要最小化哪一個？

第 2 章（端到端專案）評估房價模型時用的是 RMSE（MSE 開根號），投影片說訓練時改用 MSE，「比較簡單，而且結果一樣」。原因是開根號是遞增的：MSE 越小，RMSE 一定越小，所以讓 MSE 最小的 ，也會讓 RMSE 最小。同樣地，RSS（殘差平方和，Residual Sum of Squares）就是 ，乘上一個固定的正數也不會改變最小值的位置。所以三者找到的最佳 完全相同；MSE 沒有根號，微分最乾淨。

試完會發現三件事：

  1. MSE 的地形是一個碗，只有一個最低點，沒有其他的坑。線性迴歸的 MSE 永遠是碗形（數學上叫凸函數），不會有其他的坑；只要 可逆，最低點就只有一個（不可逆的情況，〈三個點〉那一節會看到）。第 2 篇會用到這個性質。
  2. 碗是斜的、細長的：截距調大時，斜率要調小才能維持差不多的 MSE，因為兩者都在決定直線的高度。這個「細長」會讓梯度下降走得很辛苦，第 2 篇會再看到它。
  3. 最佳解不是 (4, 3)，而是 (4.215, 2.770)。按「用真正的規律」，MSE 反而比最佳解高（0.825 對 0.807）。因為最佳解是「對這 100 個點」最好，連這批雜訊也一起遷就了。按「換一批雜訊」，最佳解每次都在 (4, 3) 附近跳動，但幾乎不會剛好等於 (4, 3)。

用 NumPy 實作

投影片 6

投影片直接把公式翻成程式。投影片的程式沒有設定亂數種子，這裡加上 np.random.seed(42)，就能得到和投影片一模一樣的數字：

import numpy as np

np.random.seed(42)                            # 加這行才能重現投影片的數字
m = 100
X = 2 * np.random.rand(m, 1)                  # 100 個介於 0 到 2 的 x1
y = 4 + 3 * X + np.random.randn(m, 1)         # 真正的規律 y = 4 + 3x1，加上標準常態雜訊

X_b = np.c_[np.ones((m, 1)), X]               # 每一列前面補一個 x0 = 1
theta_best = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
theta_best                                    # array([[4.21509616], [2.77011339]])

X_new = np.array([[0], [2]])
X_new_b = np.c_[np.ones((2, 1)), X_new]
X_new_b @ theta_best                          # array([[4.21509616], [9.75532293]])

注意：公式裡的 （含 那一行 1）在程式裡是 X_b；程式裡的 X 只有 那一行。

np.c_[...] 是把幾個陣列「左右並排」，這裡用來在最左邊補上一整行 1。@ 是矩陣乘法，和投影片的 .dot() 一樣。預測 和 兩個點，就能畫出投影片上那條紅色直線（4.215 到 9.755）。

SVD 把 拆成「旋轉 × 伸縮 × 旋轉」，中間的 是對角矩陣，對角線上的數字叫奇異值，代表每個方向被拉長多少。 的做法是：把不是 0 的奇異值取倒數，太接近 0 的直接當成 0，再轉置。旋轉矩陣的反運算就是轉置，所以整個反過來就是 。（實際上 scikit-learn 會先把資料減去平均值，再呼叫 SciPy 的 lstsq，底層是以 SVD 為基礎的 LAPACK 程式 gelsd。因為先減掉平均，截距不參與下面說的「挑最短」：例如三個 x 都一樣時，LinearRegression 會給 、，和 np.linalg.pinv(X_b) 的結果不同。）

當 的每一行線性獨立時，虛反矩陣就等於 ，兩種方法答案一樣。差別出現在 不可逆的時候，投影片舉了兩種情況：

  • 資料比特徵少（投影片寫 ；加上 後有 個未知數，所以嚴格說 就會發生）：方程式比未知數少，解不唯一。
  • 有重複或多餘的特徵：例如同時放「坪數」和「平方公尺」，後者只是前者乘上 3.3058。

實測：同時放兩個單位不同的同一個特徵

把上面的資料多加一行 X * 3.3058（假裝是換了單位的同一個特徵）：

X2_b = np.c_[np.ones((m, 1)), X, X * 3.3058]
np.linalg.inv(X2_b.T @ X2_b)                  # LinAlgError: Singular matrix
np.linalg.pinv(X2_b) @ y                      # array([[4.21509616], [0.23223009], [0.76770624]])

正規方程式直接報錯；虛反矩陣照樣給出答案。兩個權重 0.232 和 0.768 看起來很奇怪，但換算回來 0.232 + 3.3058 × 0.768 = 2.770，和原本的斜率一樣，預測值完全相同。能做到同樣預測的權重組合有無限多組，虛反矩陣挑的是「權重長度最短」的那一組，這是它的固定規則。

計算量：什麼時候會太慢

投影片 8

正規方程式要算 的反矩陣，這是一個 的方陣（ 是特徵數）。反矩陣的計算量大約是 到 ，視實作而定；scikit-learn 用的 SVD 方法，以特徵數來看大約是 。換成具體的感覺：

情況正規方程式SVD（LinearRegression）
特徵數變 2 倍時間約變 到 倍約變 倍
資料筆數變 2 倍約變 2 倍（和筆數成正比）約變 2 倍

所以這兩種方法在資料筆數很多時還撐得住，但特徵數很多（例如十萬個）時會非常慢；另外，它們需要把整個 放進記憶體。資料大到放不下、或特徵非常多時，就要換成第 2 篇的梯度下降。

Python 實作

把本篇的程式整理在一起，可以直接執行：

import numpy as np
from sklearn.linear_model import LinearRegression

np.random.seed(42)
m = 100
X = 2 * np.random.rand(m, 1)
y = 4 + 3 * X + np.random.randn(m, 1)
X_b = np.c_[np.ones((m, 1)), X]

# 方法 1：正規方程式
theta_best = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y            # [[4.21509616], [2.77011339]]

# 方法 2：虛反矩陣（SVD）
theta_pinv = np.linalg.pinv(X_b) @ y                            # 同上

# 方法 3：最小平方法函式（也是 SVD）
theta_lstsq, residuals, rank, s = np.linalg.lstsq(X_b, y, rcond=None)
# theta_lstsq 同上；residuals = [80.658...]（RSS）；rank = 2；s = 奇異值 [14.370..., 4.119...]

# 方法 4：scikit-learn
lin_reg = LinearRegression().fit(X, y)
lin_reg.intercept_, lin_reg.coef_                               # (array([4.21509616]), array([[2.77011339]]))

# 驗證「垂直」：殘差和每一行的內積都是 0
residual = y - X_b @ theta_best
X_b.T @ residual                                                # 兩個都約是 1e-13
((X_b @ theta_best - y) ** 2).mean()                            # MSE = 0.80658...

lstsq 回傳的 residuals 是 RSS（80.658），除以 100 筆就是 MSE（0.807），和上面互動圖裡的數字一樣。

常見陷阱與自我檢查

自己算正規方程式時忘了補 沒有那一行 1，模型就沒有截距，直線被迫通過原點。反過來，用 LinearRegression 時不要自己補，它會自己處理截距。
用 np.linalg.inv 當首選只要特徵重複、或資料比特徵少， 就不可逆或非常接近不可逆，結果會報錯或數字爆炸。實務上用 LinearRegression、np.linalg.lstsq 或 pinv。
以為訓練 MSE 越低，模型越接近真相最佳解 (4.215, 2.770) 在這 100 筆資料上的 MSE 比真正的規律 (4, 3) 還低，因為它連雜訊也一起擬合了。訓練資料上的分數只能代表「對這批資料」有多好。
有 1,000 筆資料、3 個特徵。（含 ）和 各是什麼形狀？

是 1000 × 4（多了 那一行）。 是 (4 × 1000)(1000 × 4) = 4 × 4，大小只和特徵數有關，和資料筆數無關。這也是為什麼正規方程式的計算量主要卡在特徵數。

某個資料集只有 500 筆，卻有 20,000 個特徵。正規方程式會怎樣？

是 20,001 × 20,001，但它的秩（rank）最多只有 500，所以一定不可逆，inv 會失敗。虛反矩陣還是能給出一組解，但能完美擬合訓練資料的解有無限多組，幾乎一定會過擬合。第 5 篇的正則化就是處理這種情況的辦法。

為什麼讓 MSE 最小的參數，也一定讓 RMSE 最小？

RMSE = √MSE，而開根號是遞增函數：MSE 越小，RMSE 一定越小。所以兩者的最低點在同一組 。同理 RSS = m × MSE，也是同一個最低點。

用正規方程式之前，需要先把特徵標準化嗎？

不需要。正規方程式一步就算出精確解，特徵的單位改變時，權重會自動等比例調整（例如坪數換成平方公尺，權重就除以 3.3058），預測結果不變。第 2 篇的梯度下降就不一樣了，特徵的尺度差很多時會走得非常慢，所以一定要先標準化。
