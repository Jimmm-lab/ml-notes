7. Ensemble Learning and Random Forests，第 7 篇／共 9 篇（投影片 36–39、42–44）

Gradient Boosting：
一棵接一棵修正殘差

Gradient Boosting 和 AdaBoost 一樣一個接一個訓練模型，但做法不同：它不調整資料的權重，而是讓每一棵新的樹去學「前面所有樹加起來還差多少」，也就是殘差。預測時，把所有樹的輸出加起來。

這篇讀完你會知道
  • Gradient Boosting 怎麼訓練：每一棵樹學前面留下的殘差 （期末考題）。
  • 怎麼預測：把每一棵樹的預測加起來。
  • 完整的演算法：初始預測、學習率 、一步一步加樹。
  • 為什麼叫「梯度」：殘差剛好是均方誤差的負梯度，加一棵樹就像走一步梯度下降。

想法：下一棵樹學前面剩下的誤差

投影片 36

Gradient Boosting 和 AdaBoost 一樣，依序把模型一個一個加進集成裡，每一個都修正前一個的錯。差別在於怎麼修正（投影片 36）：

AdaBoost

每一輪調整資料的權重：分錯的資料變重，下一個模型更在意它們。

Gradient Boosting

每一輪讓新模型去學殘差：前面的模型預測完還差多少，新模型就學那個差距。

這裡的殘差（residual）是正確答案減去目前的預測：。新的模型學的是「從特徵 對應到殘差」，把它加進去，預測就往正確答案靠近一點。

可以想成打高爾夫：第一桿朝洞口打，球停在某個地方；第二桿不用從頭打，只要打「球到洞口還差的那一段」；第三桿再修正剩下的一點點。每一桿只負責上一桿留下的誤差，全部加起來就把球送進洞。

例子：三棵迴歸樹

投影片 37–39

投影片 37–39 用一個簡單的迴歸問題示範，每棵樹都是深度 2 的迴歸樹（第 6 章第 6 篇）。資料是 100 筆加了雜訊的二次曲線 ：

  1. 第 1 棵樹直接學 ：tree_reg1.fit(X, y)。它只有 4 片葉子，畫出 4 段水平線，離資料還很遠。
  2. 第 2 棵樹學第 1 棵留下的殘差：y2 = y - tree_reg1.predict(X)，再 tree_reg2.fit(X, y2)。
  3. 第 3 棵樹學前兩棵留下的殘差：y3 = y2 - tree_reg2.predict(X)，再 tree_reg3.fit(X, y3)。
  4. 預測時把三棵樹加起來：sum(tree.predict(X_new) for tree in (tree_reg1, tree_reg2, tree_reg3))。

這正是 Gradient Boosting 在做的事：新的樹 學的是殘差 ，也就是負梯度；加上 就是沿著負梯度走一步（投影片 43）。不同的是，梯度下降調整的是模型的參數，Gradient Boosting 調整的是預測值本身：因為新資料沒有現成的梯度，所以用一棵樹去學「每個 該往哪裡走多少」。

換成別的損失函數，新的樹就改學那個損失的負梯度，叫做偽殘差（pseudo-residual）：

損失函數新的樹要學的負梯度
均方誤差 ：殘差本身
絕對誤差 ：只看方向，不怕離群值
分類的 log loss：真實類別（0 或 1）減掉預測機率

所以 Gradient Boosting 不只能做迴歸，也能做分類（GradientBoostingClassifier）：它還是一棵一棵地加迴歸樹，只是學的東西換成分類損失的負梯度。

補充筆記Gradient Boosting 做分類時，迴歸樹加起來的是什麼？
  • 兩類分類時，所有樹加起來的 不是機率，而是對數勝算（log-odds），和第 4 章的邏輯迴歸一樣。機率是 ， 是 S 形的 sigmoid 函數。
  • 初始預測 是訓練資料裡類別 1 比例的對數勝算。
  • 每一輪的偽殘差是 ：真實類別是 1、預測機率只有 0.3 的資料，偽殘差是 0.7，下一棵樹會把它的 往上推。
  • 多類別時，每一輪對每一類各訓練一棵迴歸樹（ 類就 棵），再用 softmax 換成機率。

一句話分類版的 Gradient Boosting 加總的是對數勝算，每一棵樹學的是「真實類別減預測機率」。

Python 實作

投影片 37–39 的三棵樹，以及對三個新資料的預測：

import numpy as np
from sklearn.tree import DecisionTreeRegressor

np.random.seed(42)
X = np.random.rand(100, 1) - 0.5
y = 3 * X[:, 0] ** 2 + 0.05 * np.random.randn(100)       # 加了雜訊的二次曲線

tree_reg1 = DecisionTreeRegressor(max_depth=2, random_state=42)
tree_reg1.fit(X, y)
y2 = y - tree_reg1.predict(X)                           # 第 1 棵樹留下的殘差
tree_reg2 = DecisionTreeRegressor(max_depth=2, random_state=42)
tree_reg2.fit(X, y2)
y3 = y2 - tree_reg2.predict(X)                          # 前 2 棵樹留下的殘差
tree_reg3 = DecisionTreeRegressor(max_depth=2, random_state=42)
tree_reg3.fit(X, y3)

X_new = np.array([[-0.4], [0.], [0.5]])
print(sum(tree.predict(X_new) for tree in (tree_reg1, tree_reg2, tree_reg3)))
# [0.49484029 0.04021166 0.75026781]

用 scikit-learn 的 GradientBoostingRegressor，3 棵深度 2 的樹、學習率 1.0，預測完全一樣。它的初始預測 init_ 是 的平均：

from sklearn.ensemble import GradientBoostingRegressor

gbrt = GradientBoostingRegressor(max_depth=2, n_estimators=3,
                                 learning_rate=1.0, random_state=42)
gbrt.fit(X, y)
print(gbrt.predict(X_new))
print(gbrt.init_.constant_, round(y.mean(), 4))

常見陷阱與自我檢查

以為每一棵樹都去學 y只有第一棵學 （或 scikit-learn 從平均值開始）；之後每一棵學的都是前面所有樹加起來還差多少。
以為預測時要投票或平均Gradient Boosting 是把所有樹的輸出加起來（乘上學習率），不是投票，也不是平均。
以為樹越多越好樹越多，訓練誤差越小，但後面的樹會開始學雜訊而過擬合。要用驗證集決定棵數（下一篇）。
（2023 期末考）舉例說明 Gradient Boosting 在迴歸問題上怎麼訓練、怎麼預測。

訓練：依序訓練迴歸樹。第一棵學 ；第二棵學第一棵留下的殘差 ；第三棵學前兩棵留下的殘差 ，依此類推。預測：把所有樹的輸出加起來。例如資料 、每棵樹只切一刀：第一棵切在 ，預測 2 和 6.5，殘差 ；第二棵切在 ，預測 和 0.5；第三棵再切 ，預測 0.25 和 。預測 時，。

Gradient Boosting 和 AdaBoost 都是依序訓練，最大的差別在哪裡？

AdaBoost 調整每筆資料的權重，讓下一個模型更在意分錯的資料，預測時加權投票；Gradient Boosting 不調整權重，而是讓下一個模型去學前面留下的殘差（負梯度），預測時把所有模型的輸出加起來。

為什麼它叫「梯度」提升？

用均方誤差 時，對預測值的負梯度剛好是殘差 。每加一棵學殘差的樹，就等於沿著負梯度方向把預測值移動一步，和梯度下降一樣，只是移動的是預測值，不是模型參數。換成其他損失函數，新的樹就改學那個損失的負梯度。
