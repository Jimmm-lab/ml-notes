Boosting：一個接一個，修正前一個的錯

投影片 29

Boosting（最早叫 hypothesis boosting）泛指任何「把好幾個弱學習器合成一個強學習器」的集成方法。大部分 boosting 方法的共同點是：依序訓練模型，每個新模型都試著修正前一個的錯（投影片 29）。

這和 bagging 正好相反。Bagging 讓很多個模型同時、各自訓練，再平均，主要降低變異；boosting 一個接一個訓練，後面的模型針對前面的弱點加強，主要降低偏差。所以 boosting 特別適合欠擬合的模型：偏差大、變異小，例如只切一刀的決策樹。

最常用的兩種是 AdaBoost（這篇）和 Gradient Boosting（下一篇）。

AdaBoost 的想法：加重分錯的資料

投影片 30–31

新模型要怎麼修正前一個的錯？AdaBoost（Adaptive Boosting）的做法是：前一個模型分錯的資料，提高它們的權重，讓下一個模型訓練時更在意這些資料。這樣一來，後面的模型會越來越專注在難分的資料上（投影片 30）。

AdaBoost 的基礎模型通常是決策樹樁（decision stump）：深度只有 1、只切一刀的決策樹。單一個樹樁很弱，只能畫一條水平或垂直的線；但 AdaBoost 會把很多個樹樁的票加權合起來。

按幾次「下一個」：每一步分錯的資料（紅圈）在下一步會變大，下一個樹樁就會優先把它們分對，切的位置因此一直換。單一個樹樁只有 82% 的準確率，但 20 個樹樁合起來，邊界已經能繞過半月形的轉彎（η = 1 時訓練準確率 96%）。

投影片 31 的圖 7-8 是同樣的過程，只是每個模型換成正則化很強的 RBF 核 SVM：連續 5 個模型的邊界，一個比一個更照顧前面分錯的資料。學習率 時，每一步的權重調整比較溫和，邊界移動得比較慢。

這有點像梯度下降：梯度下降是一步步調整同一個模型的參數，讓損失變小；AdaBoost 則是一步步加入新的模型，讓整體越來越好（投影片 31）。

  • 所以正規化之後，兩邊各佔一半：對新的權重來說，剛剛那個模型的加權錯誤率變成 0.5，和亂猜一樣。
  • 這逼著下一個模型一定要和前一個不一樣：如果它切得和前一個一模一樣，錯誤率就是 0.5，完全沒有用。上面實驗的 Python 實作也印出了這個 0.5。

一句話 時，每次更新都剛好讓上一個模型「退化成亂猜」，下一個模型只能從別的地方下手。

用 scikit-learn 做 AdaBoost

投影片 30、34

課本的例子：在 moons 資料（375 筆訓練、125 筆測試）上，用 30 個樹樁、學習率 0.5：

ada_clf = AdaBoostClassifier(DecisionTreeClassifier(max_depth=1), n_estimators=30,
                             learning_rate=0.5, random_state=42)
ada_clf.fit(X_train, y_train)

測試準確率 88%。幾個要注意的地方：

  • AdaBoostClassifier 預設的基礎模型就是樹樁（DecisionTreeClassifier(max_depth=1)），預設 50 個、學習率 1.0。
  • 如果 AdaBoost 過擬合，可以減少模型數量，或把基礎模型的正則化加強。
  • 因為每個模型都要等前一個訓練完、權重更新後才能開始，AdaBoost 沒辦法平行訓練，不像 bagging 那樣容易擴展到大量資料。
  • 投影片 34 的程式碼有 algorithm="SAMME.R"，新版的 scikit-learn 已經不能這樣寫。
補充筆記投影片 34 的 algorithm="SAMME.R" 在新版 scikit-learn 還能用嗎？
  • 不能。SAMME.R 是用每個模型輸出的機率來加權的版本（R 代表 Real），以前是預設值，通常收斂得比較快。
  • scikit-learn 1.4 起不建議使用，1.6 版移除了 SAMME.R，只留下本篇介紹的 SAMME；1.8 版再把 algorithm 這個參數拿掉。
  • 在 1.9 版寫 AdaBoostClassifier(algorithm="SAMME.R") 會直接出錯（TypeError：不認得這個參數）。把這個參數整個刪掉就可以了。

一句話新版只有 SAMME，algorithm 參數不用寫，寫了反而會出錯。

Python 實作

照三個公式自己寫一次 AdaBoost（用實驗裡的 100 筆資料、），印出前 5 個樹樁的 、，以及更新後分錯的資料佔多少權重：

import numpy as np
from sklearn.datasets import make_moons
from sklearn.tree import DecisionTreeClassifier

X, y = make_moons(n_samples=100, noise=0.25, random_state=42)
m = len(X)
w = np.ones(m) / m                                  # 一開始每筆資料的權重都是 1/m
eta = 1.0
for j in range(1, 6):
    stump = DecisionTreeClassifier(max_depth=1, random_state=42)
    stump.fit(X, y, sample_weight=w)
    wrong = stump.predict(X) != y
    r = w[wrong].sum() / w.sum()                    # ① 加權錯誤率
    alpha = eta * np.log((1 - r) / r)               # ② 模型權重
    w[wrong] *= np.exp(alpha)                       # ③ 分錯的資料變重
    w /= w.sum()                                    #    再正規化
    print(j, round(r, 3), round(alpha, 3), round(w[wrong].sum(), 3))
# 1 0.18 1.516 0.5
# 2 0.22 1.265 0.5
# 3 0.25 1.097 0.5
# 4 0.253 1.085 0.5
# 5 0.381 0.485 0.5

最後一欄都是 0.5：每次更新後，剛剛分錯的資料剛好佔一半的權重。scikit-learn 的 AdaBoostClassifier 算出來完全一樣，記錄在 estimator_errors_ 和 estimator_weights_：

from sklearn.ensemble import AdaBoostClassifier

ada_clf = AdaBoostClassifier(DecisionTreeClassifier(max_depth=1), n_estimators=5,
                             learning_rate=1.0, random_state=42)
ada_clf.fit(X, y)
print(ada_clf.estimator_errors_.round(3))
print(ada_clf.estimator_weights_.round(3))
# [0.18  0.22  0.25  0.253 0.381]
# [1.516 1.265 1.097 1.085 0.485]

課本的設定，換回 500 筆的 moons 資料：

from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=500, noise=0.30, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)
ada_clf = AdaBoostClassifier(DecisionTreeClassifier(max_depth=1), n_estimators=30,
                             learning_rate=0.5, random_state=42)
ada_clf.fit(X_train, y_train)
print(ada_clf.score(X_test, y_test))
# 0.88

常見陷阱與自我檢查

以為 AdaBoost 是把分錯的資料「再抽一次」AdaBoost 是調整每筆資料的權重，用加權的方式訓練下一個模型；不是 bagging 那種重新抽樣。
以為每個模型的票都一樣重每個模型的票要乘上它的 ：越準的模型票越重，和亂猜一樣準的模型（）票是 0。
想用 n_jobs 讓 AdaBoost 跑快一點AdaBoost 必須依序訓練，沒有平行化的選項；能平行的是 bagging 和隨機森林。
Boosting 和 Bagging 最大的差別是什麼？各自主要降低偏差還是變異？

Bagging 同時、各自訓練很多個模型再平均，主要降低變異，適合變異大的模型（深的決策樹）。Boosting 依序訓練，每個新模型修正前一個的錯，主要降低偏差，適合偏差大的弱學習器（樹樁）。

某個模型的加權錯誤率是 0.25，學習率 。它的權重 是多少？分錯的資料權重會乘上幾倍？

，分錯的資料權重乘上 倍（再正規化）。

如果某個模型的加權錯誤率剛好是 0.5，會發生什麼事？

：這個模型的票在預測時完全不算，分錯的資料權重乘上 ，也就是不變。它和亂猜一樣，對集成沒有任何貢獻。

AdaBoost 什麼時候停止？

模型數量達到設定值（n_estimators），或者某個模型完全沒有分錯（加權錯誤率是 0）。scikit-learn 遇到比亂猜還差的模型時，也會丟掉它並停止。
