分群與 K-Means：
把相近的資料分成一群

前面八章學的幾乎都是監督式學習：每一筆訓練資料都附有答案（標籤）。但現實中大部分的資料沒有標籤，要請人標記又貴又慢。非監督式學習就是在沒有答案的情況下，從資料本身找出結構。第 9 章從最常用的分群演算法 K-Means 開始。

非監督式學習的三種任務

投影片 2

監督式學習的訓練資料有特徵 ，也有答案 ；非監督式學習（unsupervised learning）只有 。投影片 2 列出三種常見的任務：

分群

clustering。把相似的資料分在同一群。

例如依購買行為把顧客分群、推薦系統、搜尋引擎、影像分割，也能幫助半監督式學習和降維。第 1～5 篇。

異常偵測

anomaly detection。先學「正常」的資料長什麼樣子，再找出不正常的。

例如生產線上的瑕疵品、時間序列裡突然出現的新趨勢。第 8 篇。

密度估計

density estimation。估計產生這份資料的機率密度函數（pdf）。

密度很低的地方的資料可能就是異常；也能用來分析和視覺化資料。第 6～10 篇。

三者互相有關：密度估計做得好，就能拿來偵測異常（落在密度很低的地方的資料，很可能是異常）。第 7 篇的高斯混合模型，三件事都能做。

分類和分群差在哪

投影片 3

投影片 3（課本圖 9-1）把鳶尾花的花瓣長度和寬度畫成兩張圖，資料一樣，差別在有沒有標籤：

  • 分類（classification）：每一點都標了品種。模型學的是「看到花瓣大小，猜出品種」。
  • 分群（clustering）：沒有品種，演算法只看得到點的位置，要自己把聚在一起的點分成一群。

沒有標籤時，左下角那一團很明顯是一群；右上那一大片能不能分成兩群，就不好說了。投影片 3 強調：「群」沒有統一的定義，要看情境。不同的演算法會找出不同樣子的群：K-Means 找圍繞著中心的群，DBSCAN（第 5 篇）找連成一片的高密度區域。切換看看同一份資料的三種樣子：

實驗：同一份鳶尾花資料，三種看法

實驗裡 K-Means 的結果是這樣算出來的。每一群數一數裡面各有幾朵 setosa、versicolor、virginica：

import numpy as np
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

iris = load_iris()
X_iris = iris.data[:, 2:]                 # 只用花瓣長度、花瓣寬度
km3 = KMeans(n_clusters=3, n_init=10, random_state=42).fit(X_iris)
for c in range(3):
    print(c, np.bincount(iris.target[km3.labels_ == c], minlength=3))
# 0 [ 0  2 46]
# 1 [50  0  0]
# 2 [ 0 48  4]

第 1 群剛好是全部 50 朵 setosa。另外兩群大致對應 versicolor 和 virginica，但有 6 朵不一致：2 朵 versicolor 分進了以 virginica 為主的第 0 群，4 朵 virginica 分進了以 versicolor 為主的第 2 群。K-Means 完全不知道品種，能分得這麼接近，是因為三個品種的花瓣大小本來就不太一樣。

補充筆記分群得到的 0、1、2 有什麼意義？
  • 只是群的編號，沒有順序，也不代表任何品種。上面的第 1 群剛好是 setosa，純屬巧合；換一個 random_state 重跑，同一群可能變成別的編號。
  • 在分群的情境裡，一筆資料的「標籤」就是演算法分給它的群編號（投影片 5）。
  • 想和真正的品種比較，只能像上面那樣，看每一群裡哪個品種最多。實際的分群問題通常根本沒有正確答案可以比。

一句話群的編號只是名字，不是答案。

用 scikit-learn 跑 K-Means

投影片 4–5

投影片 4（課本圖 9-2）是一份沒有標籤的資料，看得出有 5 團：左邊三團很集中，右邊兩團比較散。用課本的程式產生它，再交給 KMeans⁠：

from sklearn.datasets import make_blobs

blob_centers = np.array([[ 0.2, 2.3], [-1.5, 2.3], [-2.8, 1.8],
                         [-2.8, 2.8], [-2.8, 1.3]])
blob_std = np.array([0.4, 0.3, 0.1, 0.1, 0.1])     # 每一團散開的程度
X, y = make_blobs(n_samples=2000, centers=blob_centers,
                  cluster_std=blob_std, random_state=7)

kmeans = KMeans(n_clusters=5, n_init=10, random_state=0)
y_pred = kmeans.fit_predict(X)
print(y_pred)
print(y_pred is kmeans.labels_)
# [4 1 2 ... 3 2 1]
# True
  • n_clusters=5⁠：群數 要事先指定，這是 K-Means 的一大限制（投影片 5）。第 3 篇會介紹怎麼選 。
  • fit_predict() 訓練完，直接回傳每一筆資料分到的群編號，它和 labels_ 是同一個陣列。
  • y 是每一點真正來自哪一團，只有自己產生資料時才知道。K-Means 完全用不到它，下面只拿來檢查。
  • n_init=10 是重複跑 10 次、留下最好的一次，第 2 篇會說明為什麼需要。

找到的 5 個中心點（centroid）在 cluster_centers_⁠：

print(kmeans.cluster_centers_.round(2))
# [[-1.47  2.29]
#  [-2.8   1.8 ]
#  [ 0.21  2.26]
#  [-2.79  2.8 ]
#  [-2.8   1.3 ]]

和產生資料時設定的 5 個中心幾乎一樣，只是順序不同：第 0 群是中間那團，第 2 群是右邊那團，第 1、3、4 群是左邊三團。新的資料就看它離哪個中心最近：

X_new = np.array([[0, 2], [3, 2], [-3, 3], [-3, 2.5]])
print(kmeans.predict(X_new))
# [2 2 3 3]

(0, 2) 和 (3, 2) 分到右邊的第 2 群，(−3, 3) 和 (−3, 2.5) 分到左上的第 3 群。

決策邊界：每一點都歸最近的中心

投影片 6

每一點都分給最近的中心，所以整個平面會被切成 塊，每一塊裡的點都離同一個中心最近（這種切法叫 Voronoi 圖）。兩塊之間的邊界，是兩個中心連線的垂直平分線，所以都是直線。點一下圖或拖動黑色的菱形，看看新資料會分到哪一群：

實驗：新資料離哪個中心最近

新資料到 5 個中心的距離（框起來的最近）

投影片 6 指出，邊界附近有幾筆資料可能被分錯了，特別是左上那群和中間那群之間。勾選實驗裡的選項看看，和資料真正來自的那一團相比，一共有 18 筆不一致：

  • 中間那團有 9 筆被分到別群，其中 5 筆跑進左上那群。
  • 右邊那團有 5 筆被分到中間那群。
  • 左邊下面兩團互相交換了 4 筆。

原因是 K-Means 分群時只看「離哪個中心近」，不管每一團散得多開。中間那團比較散（標準差 0.3），左上那團很緊（標準差 0.1），邊界卻畫在兩個中心的正中間。散的那團邊緣的點，離緊的那團的中心反而比較近，就被分過去了。所以各團的大小（直徑）差很多時，K-Means 的效果不好。第 4 篇會再看到它的其他限制。

補充筆記邊界為什麼一定是直線？
  • 到兩個中心一樣遠的點，全部落在兩個中心連線的垂直平分線上，這是國中幾何。
  • 這條線的一邊離中心 A 比較近，另一邊離中心 B 比較近，所以 A、B 兩群的分界就是它。
  • 每一塊都是好幾條這樣的直線圍出來的凸多邊形，合起來叫 Voronoi 圖。
  • 這是因為 K-Means 用一般的直線距離（歐氏距離）。第 7 篇的高斯混合模型會考慮每一群的形狀，邊界就變成曲線了。

一句話邊界上的點到兩個中心一樣遠，這些點剛好排成一條直線。

K-Means 演算法：標記和更新輪流做

投影片 7

如果知道中心在哪，把每筆資料分給最近的中心就好；如果知道每筆資料屬於哪一群，每群的中心就是那群資料的平均。麻煩的是兩個都不知道。K-Means 的做法是先隨便猜中心，再讓兩件事輪流做（投影片 7，課本圖 9-4）：

  1. 初始化：隨機選 筆資料，用它們的位置當作一開始的中心。
  2. 標記資料（label the instances）：每一筆資料分給最近的中心。第 筆資料的群編號 。
  3. 更新中心（update the centroids）：每個中心移到自己這群所有資料的平均位置。 是第 群的資料筆數：
  4. 重複第 2、3 步，直到中心不再移動。

按「下一步」，一次走半步：先標記、再更新，交替進行。

實驗裡的 inertia 是每一筆資料到它所屬中心的距離平方，全部加起來：

它衡量每一群有多緊：越小，代表資料越靠近自己的中心。多按幾次會發現，inertia 只會變小或不變，從來不會變大。兩個步驟都在讓它變小：

  • 標記時，每一點都換到最近的中心，距離只會變短。
  • 更新時，中心移到平均位置，而平均正是讓「到這群每一點的距離平方和」最小的位置。
補充筆記為什麼 K-Means 一定會停下來？
  • 上面說過，inertia 每一步都只會變小或不變。
  • 2,000 筆資料分成 5 群，分法雖然非常多，但個數是有限的。inertia 每輪都變小，同一種分法就不會出現第二次，所以不可能無限繞下去，最後一定停在某個分法。
  • 實際上通常很快就停：這份資料從示範起點只要 8 輪。scikit-learn 另外設了上限 max_iter=300⁠，以防萬一。
  • 「一定會停」不代表「停在最好的分法」。多按幾次「換一個隨機起點」，有時候會停在 inertia 比 211.6 大的分法，第 2 篇會說明怎麼避免。

一句話每一步都讓 inertia 變小，分法的種類有限，所以一定會停，但不保證停在最好的地方。

硬分群與軟分群

課本補充（Géron 第 9 章）

把每筆資料分給一群，叫做硬分群（hard clustering）。也可以給每筆資料一組分數，表示它和每一群的關係，叫做軟分群（soft clustering）。K-Means 的 transform() 會算出每筆資料到每個中心的距離，就是上面決策邊界實驗裡的 5 個數字：

print(kmeans.transform(X_new).round(2))
# [[1.49 2.81 0.33 2.9  2.89]
#  [4.48 5.81 2.8  5.85 5.84]
#  [1.69 1.21 3.29 0.29 1.71]
#  [1.55 0.73 3.22 0.36 1.22]]
  • 第一筆 (0, 2) 離第 2 群的中心只有 0.33，離其他中心都在 1.4 以上，明確屬於第 2 群。
  • 第四筆 (−3, 2.5) 離第 3 群 0.36、離第 1 群 0.73，比較模糊，它夾在兩群之間。

這些距離也可以當成新的特徵：原本每筆資料有 個特徵，轉換後變成 個（到每個中心的距離）。 比 小時，這就是一種降維，也就是投影片 2 說分群可以用來降維的意思。第 7 篇的高斯混合模型會給出更直接的軟分群：每筆資料屬於每一群的機率。

常見陷阱與自我檢查

以為群的編號代表什麼群的編號只是名字。重跑一次編號可能整個換掉，第 1 群不一定還是同一群。
沒有先縮放特徵K-Means 用距離分群，數值範圍大的特徵會主導距離。特徵的單位或範圍差很多時，通常要先用 StandardScaler 縮放（第 4 篇有例子）。
以為 K-Means 會自己決定分幾群群數 一定要事先指定。第 3 篇介紹怎麼選。
以為收斂了就是最好的分群K-Means 一定會停，但可能停在比較差的分法，結果要看一開始的中心選在哪（第 2 篇）。
（2023 期末考）參考投影片 7 的圖，說明 K-Means 演算法。

K-Means 要把資料分成 群（ 要事先指定），每群用一個中心點代表。① 初始化：隨機選 筆資料當作中心。② 標記資料：每筆資料分給最近的中心。③ 更新中心：每個中心移到它這群所有資料的平均位置。④ 重複 ②③，直到標記不再改變、中心不再移動。圖中左欄是更新、右欄是標記，中心一步步移到各團資料的中央。每一步都讓 inertia（到所屬中心的距離平方和）變小或不變，所以一定會收斂，但可能停在比較差的分法，所以實務上會用不同的初始中心跑好幾次，留下 inertia 最小的。

分類和分群最大的差別是什麼？

訓練資料有沒有答案（標籤）。分類的資料有標籤，模型學著預測新資料的類別；分群沒有標籤，演算法只看資料的位置，自己把相近的資料分成一群，分出來的群編號沒有預先定好的意義。

一筆新資料到 5 個中心的距離是 1.2、0.4、2.0、0.9、3.1。硬分群會把它分到哪一群？軟分群可以怎麼表示它和各群的關係？

硬分群：分到距離最小的那一群，也就是第 2 個中心（距離 0.4）。軟分群：直接用這 5 個距離（⁠transform() 的結果），可以看出它離第 2 群最近、第 4 群次之（0.9），不是非常明確地只屬於一群。

為什麼更新中心時用「平均」？

因為平均是讓「到這群每一點的距離平方和」最小的位置。標記完之後把中心移到平均，inertia 只會變小或不變，演算法才會一步步收斂。
