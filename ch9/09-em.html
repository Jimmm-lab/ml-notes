機率和概似

投影片 50

一個統計模型有一些參數 。日常用語裡「機率」和「概似」差不多，但在統計裡意思不同（投影片 50）：

  • 機率（probability）：參數 已知，問未來的結果 有多可能出現。
  • 概似（likelihood）：結果 已經看到了，問某一組參數 有多合理。

簡單說：pdf 是 的函數（ 固定），概似函數是 的函數（ 固定）。兩個是同一個式子 ，只是看的方向不同。手上有一份資料 時，常見的任務就是找出最可能的參數值。

import numpy as np
from scipy.stats import norm

def f(x, theta):                         # 投影片 51 的模型：兩個標準差都是 θ
    return norm.pdf(x, -4, theta) / 3 + 2 * norm.pdf(x, 1, theta) / 3

thetas = np.linspace(1, 2, 101)
L = f(2.5, thetas)                       # 看到 x = 2.5 之後，θ 的概似函數
print(thetas[L.argmax()], round(L.max(), 4))
# 1.5 0.1075

：2.5 離右邊的中心 1 剛好 1.5，標準差 1.5 時這筆資料「最不意外」。 太小，曲線太窄，2.5 落在尾巴；太大，曲線太扁，到處的密度都低。

投影片 52 問：「只有一筆 時找得到最好的 ，但如果有很多筆呢？」資料彼此獨立時，看到整份資料的可能性是每一筆的密度相乘：

實際上都改成最大化對數概似（log-likelihood），兩個理由（投影片 52）：

  1. 乘積的對數是對數的和：上千個小於 1 的數相乘會小到電腦存不下，加總就沒有這個問題，微分也容易得多。

補充筆記投影片 54 的 MAP 是什麼？和 MLE 差在哪？
  • MLE 把 當成一個固定、未知的值，只問「哪個 讓資料最可能出現」：。
  • MAP（最大後驗估計）把 當成隨機變數，先給它一個先驗分布 （看資料之前的看法），再用貝氏定理算後驗：。分母 和 無關，所以可以省略。
  • 先驗是均勻分布（每個 一樣可能）時， 是常數，MAP 就等於 MLE。所以 MLE 是 MAP 的特例。
  • 投影片 61 的貝氏估計更進一步：不只取後驗最大的那一點，而是保留整個後驗分布 ，預測時對所有 加權平均。第 10 篇的貝氏 GMM 就是這個想法。

一句話MLE 只看資料；MAP 再乘上先驗；先驗是均勻分布時兩者相同。

把上面的步驟直接寫成 NumPy 程式（示範起點和實驗一樣）：

rng = np.random.default_rng(42)
x = np.r_[rng.normal(0, 1, 140), rng.normal(4, 1.5, 60)]      # 200 筆一維資料

mu, sd, pi = np.array([1.0, 2.0]), np.array([1.0, 1.0]), np.array([0.5, 0.5])
history = []
for it in range(200):
    # E 步驟：每筆資料屬於兩群的機率（responsibility）
    p = np.array([pi[k] * norm.pdf(x, mu[k], sd[k]) for k in range(2)])
    history.append(np.log(p.sum(axis=0)).sum())               # 目前參數的對數概似
    r = p / p.sum(axis=0)
    # M 步驟：用 responsibility 當權重，更新平均、標準差和權重
    nk = r.sum(axis=1)
    mu = (r * x).sum(axis=1) / nk
    sd = np.sqrt((r * (x - mu[:, None]) ** 2).sum(axis=1) / nk)
    pi = nk / len(x)
print(np.round(history[:4], 1), round(history[-1], 2))
print(mu.round(3), sd.round(3), pi.round(3))
# [-578.1 -398.6 -390.8 -388.3] -386.86
# [-0.093  3.696] [0.79  1.597] [0.668 0.332]

對數概似從 −578.1 一路升到 −386.86，而且每一輪都只會變大或不變。資料其實來自 （140 筆）和 （60 筆），EM 估出的 、、 很接近。GaussianMixture 得到差不多的結果：

from sklearn.mixture import GaussianMixture

gm = GaussianMixture(n_components=2, n_init=10, random_state=42).fit(x.reshape(-1, 1))
print(gm.means_.ravel().round(3), np.sqrt(gm.covariances_.ravel()).round(3), gm.weights_.round(3))
# [-0.071  3.819] [0.807 1.511] [0.682 0.318]

數字略有不同，因為 GaussianMixture 在「平均每筆資料的對數概似」進步小於 tol=0.001 時就停了，我們的迴圈則跑滿 200 輪。投影片 56 的註解說明了 EM 的兩個重要性質：

  • 一定會收斂：對數概似有上限（真正的最大值），而每一輪 EM 都讓它變大，所以最後一定會停。
  • 不保證是最好的解：GMM 的對數概似不是凸函數，EM 在實務上幾乎都收斂到區域最佳解，而且結果很依賴初始值，這是它最大的缺點。所以 GaussianMixture 也有 n_init⁠，和 K-Means 一樣跑好幾次留最好的。

EM 和 K-Means 的對照

投影片 34、55–57

K-MeansEM（GMM）
第一步標記資料：每筆資料只屬於最近的中心（硬分派）E 步驟：每筆資料屬於每一群的機率（軟分派）

投影片 57 提到的 Hard EM（也叫 Viterbi EM）是 E 步驟改成硬分派的版本：每筆資料只算給機率最大的那一群。如果再限制每一群都是一樣大的圓形、權重也一樣，Hard EM 就變成 K-Means。所以 K-Means 可以看成 EM 的特例。

限制共變異數矩陣的形狀

投影片 45–46

特徵很多、群很多或資料很少時，EM 可能很難收斂到好的解（投影片 45）。一個辦法是減少要學的參數：限制每一群可以有的形狀和方向，也就是限制共變異數矩陣。GaussianMixture 的 covariance_type 參數有四種（第 6 篇看過這幾種矩陣的形狀）：

covariance_type限制共變異數的參數個數（ 個特徵、 群）
"full"（預設）沒有限制：每一群可以是任何大小、形狀、方向的橢圓。
"tied"所有群共用同一個橢圓的形狀、大小和方向（同一個共變異數矩陣）。
"diag"共變異數矩陣必須是對角矩陣：橢圓的軸和座標軸平行，各群可以不同。
"spherical"每一群都是圓（球），但各群的大小（變異數）可以不同。

用第 7 篇的三個橢圓比較四種設定：

from sklearn.datasets import make_blobs

X1, y1 = make_blobs(n_samples=1000, centers=((4, -4), (0, 0)), random_state=42)
X1 = X1.dot(np.array([[0.374, 0.95], [0.732, 0.598]]))
X2, y2 = make_blobs(n_samples=250, centers=1, random_state=42)
X2 = X2 + [6, -8]
X = np.r_[X1, X2]
for cov_type in ["full", "tied", "diag", "spherical"]:
    gm = GaussianMixture(n_components=3, covariance_type=cov_type,
                         n_init=10, random_state=42).fit(X)
    print(cov_type, gm.covariances_.shape, round(gm.score(X) * len(X), 1))
# full (3, 2, 2) -4034.3
# tied (2, 2) -4255.1
# diag (3, 2) -4446.0
# spherical (3,) -4449.4

常見陷阱與自我檢查

把概似函數當成 的機率分布概似函數是把資料固定、看不同參數的 ，對 積分不一定是 1，不是 的機率。
以為取對數會改變最佳解 是遞增函數，最大值的位置不變，只是讓計算和微分容易。
以為 EM 一定找到最好的參數EM 一定會收斂，但通常是區域最佳解，要用 n_init 跑好幾次。
以為 "tied" 是每群都是圓形"tied" 是所有群共用同一個（可以是斜的）橢圓；每群都是圓形的是 "spherical"⁠。
說明 EM 演算法的兩個步驟，以及它和 K-Means 的關係。

先初始化每一群的參數。E 步驟：用目前的參數和貝氏定理，算每筆資料屬於各群的機率（responsibility），對應 K-Means 的「標記資料」，但是軟分派。M 步驟：把 responsibility 當權重，更新每一群的平均（加權平均）、共變異數（加權變異數）和權重（分到的資料比例），對應 K-Means 的「更新中心」。重複直到對數概似不再變大。每一步都讓對數概似變大，所以一定會收斂，但可能停在區域最佳解。

最大化概似函數時，為什麼通常改成最大化對數概似？

很多筆獨立資料的概似是每筆密度的乘積，取對數後變成加總：不會因為很多小數相乘而小到電腦存不下，微分也容易。 是遞增函數，最大值的位置不變，所以得到的參數一樣。

3 個特徵、4 群時，"full"⁠、"tied"⁠、"diag"⁠、"spherical" 的共變異數各要學幾個參數？

每個 3 × 3 對稱矩陣有 6 個不同的數。full：；tied：只有一個矩陣，6；diag：每群 3 個，；spherical：每群 1 個，4。
