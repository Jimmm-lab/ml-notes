inertia 越分越小：手肘法

投影片 12

上一篇用 inertia 比較同一個 的不同結果。能不能也用它來選 ？投影片 12 說不行：群分得越多，inertia 一定越小。中心越多，每筆資料離最近的中心就越近；極端的情況，每筆資料自己一群，inertia 就是 0。

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

blob_centers = np.array([[ 0.2, 2.3], [-1.5, 2.3], [-2.8, 1.8],
                         [-2.8, 2.8], [-2.8, 1.3]])
blob_std = np.array([0.4, 0.3, 0.1, 0.1, 0.1])
X, y = make_blobs(n_samples=2000, centers=blob_centers,
                  cluster_std=blob_std, random_state=7)

inertias = [KMeans(n_clusters=k, n_init=10, random_state=0).fit(X).inertia_
            for k in range(1, 9)]
print(np.round(inertias, 1))
# [3534.8 1149.6  653.2  261.8  211.6  169.3  141.4  118.4]

把 inertia 對 畫成曲線（投影片 12，課本圖 9-8），通常會有一個轉折點，形狀像手臂的手肘（elbow）：在它之前，多分一群 inertia 降很多；在它之後，降得很少。選手肘那個 ，就是手肘法。換換看不同的 ：

實驗：分成 群，inertia 是多少

inertia 和群數 的關係

這條曲線的手肘在 ：從 3 群到 4 群，inertia 從 653.2 掉到 261.8；從 4 群到 5 群只再降到 211.6。可是資料明明是 5 團，為什麼是 4？因為左邊下面兩團靠得很近（中心只差 0.5），合成一群時 inertia 只多一點點。手肘法只能給一個大概的範圍，投影片說它「不是一個好的指標」，原因就在這裡：曲線的轉折常常不明顯，而且很依賴看圖的人怎麼判斷。

輪廓係數：每筆資料在自己的群裡有多穩

投影片 13–14

更精確（但計算量比較大）的方法是輪廓係數（silhouette coefficient）。它替每一筆資料算一個分數，看它和自己這群的距離，比起和隔壁那群的距離，近了多少（投影片 13、14）：

  • ：這筆資料到同一群其他資料的平均距離，也就是群內的平均距離。 小，代表和同伴很近（投影片 14 叫 cohesion，凝聚）。
  • ：這筆資料到最近的另一群所有資料的平均距離。對每一個別的群都算一次平均距離，取最小的那個；那一群就是「下一個最近的群」。 大，代表和別群分得很開（separation，分離）。

分母是 、 中比較大的那個，所以 一定介於 −1 和 +1 之間：

  • 接近 +1：。和同伴很近、離別群很遠，穩穩地在自己的群裡。
  • 接近 0：。到兩群差不多遠，靠近兩群的邊界。
  • 接近 −1：。離別群反而比離同伴還近，很可能被分錯群了。

大部分的點（87%）都在 0.5 以上。最高的是左上那團中間的點（0.872），那一團很緊、離其他群又遠；中間那團和右邊那團比較散，邊緣的點係數就低。整份資料只有 3 筆是負的，而且都只比 0 小一點（最低是 −0.046）：兩筆在右邊和中間那團之間，一筆在中間和左上那團之間。這份資料沒有真正「分錯」到接近 −1 的點。

補充筆記輪廓係數為什麼說「計算量比較大」？
  • 每一筆資料都要算它到所有其他資料的距離，才能得到 和 。 筆資料就要算大約 個距離。
  • 這份 2,000 筆的資料，要算大約 400 萬個距離，很快；但 100 萬筆資料就要 1 兆個，非常慢。
  • inertia 只要算每筆資料到 個中心的距離，訓練時就順便算好了，幾乎不花時間。
  • 資料很大時，可以先隨機抽一部分資料來算輪廓分數（⁠silhouette_score 有 sample_size 參數）。

一句話輪廓係數要算每兩筆資料之間的距離，資料一多就很慢；inertia 只看到中心的距離，便宜得多。

用輪廓分數選

投影片 13、15

把所有資料的輪廓係數取平均，就是輪廓分數（silhouette score）。分數越高，整體分得越好。scikit-learn 的 silhouette_score() 要給資料和每筆資料的群編號：

from sklearn.metrics import silhouette_score

for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    print(k, round(silhouette_score(X, km.labels_), 3))
# 2 0.597
# 3 0.572
# 4 0.689
# 5 0.656
# 6 0.602
# 7 0.607
# 8 0.562

結果和投影片 15（課本圖 9-9）一樣： 最高， 第二高，而且都明顯比其他的 好。比起只看手肘，輪廓分數多告訴我們 也不錯。注意 沒辦法算：只有一群時沒有「另一群」， 不存在。

輪廓圖：看每一群的大小和好壞

投影片 16

輪廓分數只是平均，把每一群的狀況都混在一起了。輪廓圖（silhouette diagram）把每一筆資料的係數都畫出來（投影片 16，課本圖 9-10）：

  • 每一群畫成一把「刀」：同一群的資料依係數由大到小排好，每一筆畫一條橫線，長度就是它的係數。
  • 刀的高度是這群有幾筆資料，寬度是係數的大小（越寬越好）。
  • 虛線是這個 的輪廓分數（全部資料的平均）。

如果一群裡大部分的資料都碰不到虛線，代表這群的資料離別群太近，是一個不好的群。換換看不同的 ：

四個 的差別：

  • 和 ：都有整把刀碰不到虛線的群（ 是中間和左上兩團被合成一群； 是右邊那團被切成兩群），是不好的分法。
  • ：輪廓分數最高（0.689），但有一把刀特別高：左邊下面兩團合成一群，有 802 筆，是其他群的兩倍。
  • ：分數稍低（0.656），但 5 把刀差不多高（每群大約 400 筆）。

投影片 16 的結論：雖然 的輪廓分數比 稍高，選 讓各群大小相近，看起來是比較好的選擇。為什麼合在一起的那群分數不低？那一群雖然包了兩團，但它離其他群都很遠， 很大，係數就不會太差。輪廓分數主要看群和群之間分得開不開，沒辦法發現「兩團靠得很近的資料被合成一群」，這時要靠輪廓圖。

from sklearn.metrics import silhouette_samples

kmeans = KMeans(n_clusters=5, n_init=10, random_state=0).fit(X)
s = silhouette_samples(X, kmeans.labels_)      # 每一筆資料的輪廓係數
for c in range(5):
    in_c = kmeans.labels_ == c
    print(c, in_c.sum(), round(s[in_c].mean(), 3))
# 0 396 0.578
# 1 402 0.638
# 2 397 0.593
# 3 405 0.812
# 4 400 0.654

silhouette_samples() 回傳每一筆資料的係數，輪廓圖就是把它們依群分開、排序後畫出來。第 3 群（左上那團）平均最高，第 0 群（中間那團）最低，和上面點選實驗看到的一樣。

常見陷阱與自我檢查

選 inertia 最小的 群數越多 inertia 一定越小，每筆資料自己一群時是 0。要看曲線的手肘，或改用輪廓分數。
以為輪廓分數最高的 一定最好分數只是平均。這份資料 分數最高，但輪廓圖看得出它把兩團合成一個特別大的群， 更合理。
把 當成「到所有其他資料」的平均距離 只看最近的那一個別的群：對每個別的群各算一次平均距離，取最小的。
大資料直接算輪廓分數要算每兩筆資料之間的距離，資料一多就非常慢。可以抽樣計算（⁠sample_size⁠）。
（2024 期末考）一筆資料的輪廓係數是 。說明係數接近 +1、0、−1 各代表什麼。

是它到同一群其他資料的平均距離， 是它到最近的另一群所有資料的平均距離。① 接近 +1：，分母是 ，：它和同一群的資料很近、離其他群很遠，穩穩地在自己的群裡。② 接近 0：，分子接近 0：它到自己這群和到隔壁那群差不多遠，位在兩群的邊界附近。③ 接近 −1：，分母是 ，：它離隔壁那群比離自己這群還近，很可能被分錯群，應該屬於隔壁那群。

為什麼 不能算輪廓分數？

只有一群時，沒有「另一群」可以算 ，輪廓係數沒有定義。所以 silhouette_score 至少要 2 群，上面的迴圈從 開始。

一筆資料的 、，它的輪廓係數是多少？代表什麼？

，也就是 。係數是正的，代表它比較靠近自己這群，但 0.2 不大：它到隔壁那群也沒有遠多少，在兩群的邊界附近。

手肘法和輪廓分數各有什麼優缺點？

手肘法：inertia 訓練時就算好了，幾乎不花時間；但轉折常常不明顯，要靠人判斷，這份資料的手肘還落在 4。輪廓分數：直接給一個可以比較的數字，搭配輪廓圖還能看出每群的大小和好壞；但要算每兩筆資料之間的距離，資料大時很慢。
