用 GMM 偵測異常，
以及其他異常偵測方法

上一篇的 GMM 能算出每個位置的密度：資料很多的地方密度高，很少的地方密度低。這篇用它來做第 1 篇提到的第二種非監督式任務：異常偵測。方法很簡單，難的是門檻怎麼定；期末考也連續兩年考了這一題。

什麼是異常偵測

投影片 42

異常偵測（anomaly detection），也叫離群值偵測（outlier detection），是找出明顯偏離常態的資料。這些資料叫做異常（anomalies）或離群值（outliers），正常的資料叫做 inliers（投影片 42）。用途很廣：

  • 偵測詐騙，例如信用卡被盜刷。
  • 找出製造過程中的瑕疵品。
  • 訓練另一個模型之前，先把資料裡的離群值拿掉，模型通常會表現得更好。

用 GMM 做異常偵測非常簡單：落在低密度區域的資料，就可以當作異常。唯一要決定的是：密度要低到多少才算異常，也就是密度門檻。

用百分位數設定密度門檻

投影片 43

投影片 43 的例子：假設這類資料大約有 4% 是異常，就把門檻設在密度的第 4 百分位數。用上一篇擬合好的 GMM：

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.mixture import GaussianMixture

X1, y1 = make_blobs(n_samples=1000, centers=((4, -4), (0, 0)), random_state=42)
X1 = X1.dot(np.array([[0.374, 0.95], [0.732, 0.598]]))
X2, y2 = make_blobs(n_samples=250, centers=1, random_state=42)
X2 = X2 + [6, -8]
X = np.r_[X1, X2]                                  # 第 7 篇的三個橢圓
gm = GaussianMixture(n_components=3, n_init=10, random_state=42).fit(X)

densities = gm.score_samples(X)                    # 每筆資料的對數密度
density_threshold = np.percentile(densities, 4)    # 第 4 百分位數
anomalies = X[densities < density_threshold]
print(round(density_threshold, 3), round(np.exp(density_threshold), 5), len(anomalies))
# -5.487 0.00414 50
  • np.percentile(densities, 4)⁠：把 1,250 筆資料的密度由小排到大，取排在第 4% 位置的那個值。所以剛好有 4%（50 筆）的資料低於門檻，被標成異常。
  • score_samples() 回傳的是對數密度，所以門檻也是對數密度 −5.487；換回密度是 。

紅色虛線外面的資料就是異常：它們不是在三群的外圍，就是夾在群和群之間的低密度地帶。課本用的是第 2 百分位數，門檻是 −5.937，只抓出 25 筆。

補充筆記投影片寫「Density p(x) < 0.04」，門檻是密度 0.04 嗎？
  • 不是。「第 4 百分位數」是把所有訓練資料的密度由小排到大，取第 4% 位置的那個密度值，意思是「把密度最低的 4% 標成異常」。這份資料的門檻是對數密度 −5.487，也就是密度 0.0041，不是 0.04。
  • 投影片旁邊的「0.04」是拿下一張投影片的例子對照：標準常態分布在 2.14 個標準差的地方，密度剛好是 0.04（見下一節）。兩個數字都有 4，但意義不同。
  • 也不能從圖上數等高線來推出門檻用第幾百分位數。門檻要看資料和需求來決定。
  • 2024 期末考的參考答案就犯了這個錯，批改註記特別指出來了。

一句話第 4 百分位數是「最低的 4% 剛好在它下面」的那個密度值，不是密度等於 0.04。

門檻怎麼取捨

課本提醒，這是常見的精確率／召回率取捨（第 3 章）：

  • 誤報太多（false positive，好好的產品被標成瑕疵）：門檻調低，只抓密度更低的。
  • 漏報太多（false negative，瑕疵品沒被抓到）：門檻調高，抓多一點。

如果有一些已知是正常或異常的資料，可以拿來調整門檻，就像調整分類器的決策門檻。

只有一個常態分布時：z 分數

投影片 44

投影片 44 用最簡單的情況說明這個想法：資料只有一群、而且是常態分布。z 分數（z-score）是一筆資料離平均幾個標準差：。離平均越遠，密度越低，所以「密度低於門檻」就等於「 大於某個值」。標準常態分布在不同 的密度：

密度 0.04 的地方在 2.14 個標準差，這就是投影片 43 旁邊那個 0.04 的來源。但要剛好標出 4% 的資料，門檻是 2.054 個標準差，那裡的密度是 0.048：

from scipy.stats import norm

z = norm.ppf(1 - 0.04 / 2)              # 兩邊各 2%，加起來 4%
print(round(z, 3), round(norm.pdf(z), 4))
print(round(2 * norm.sf(2.14), 4))      # 密度 0.04（|z| = 2.14）以外的比例
# 2.054 0.0484
# 0.0324

GMM 的做法是同一個想法的推廣：資料有好幾群、而且是多維的，沒辦法只看一個 ，所以直接用整個混合模型的密度來判斷。

異常偵測和新奇偵測

課本補充（Géron 第 9 章）

課本區分兩個很像的任務：

  • 異常偵測：訓練資料裡本身就混了異常，要把它們找出來。
  • 新奇偵測（novelty detection）：假設訓練資料是「乾淨的」，全部都正常，要判斷新的資料是不是和它們不一樣。

GMM 會盡量擬合所有的資料，包括異常。如果異常太多，模型對「正常」的看法會被帶偏，有些異常反而被當成正常。課本的建議是：先擬合一次，把最異常的資料拿掉，再用清理過的資料重新擬合：

is_anomaly = densities < density_threshold
gm_clean = GaussianMixture(n_components=3, n_init=10, random_state=42).fit(X[~is_anomaly])
print(gm_clean.weights_.round(3))
# [0.406 0.4   0.194]

拿掉 50 筆異常之後，權重更接近資料真正的比例（0.4、0.4、0.2）。

其他異常偵測方法

投影片 63

投影片 63 說，GMM 適合橢圓形的群，形狀更複雜時可以考慮 scikit-learn 裡其他專門做異常偵測或新奇偵測的演算法：

方法怎麼判斷異常
PCA（或其他降維方法）先降維再還原（第 8 章第 5 篇）。異常的資料不像其他資料，還原後的重建誤差通常大得多。
Fast-MCD
EllipticEnvelope		假設正常的資料來自單一個高斯分布，估計它的平均和共變異數時忽略最可能是離群值的資料，再把離這個分布太遠的資料標成異常。適合用來清理資料。
Isolation Forest
IsolationForest		建一片隨機的決策樹，每個節點隨機挑一個特徵和一個切點，一直切到每筆資料都被分開。異常的資料離其他資料很遠，通常幾刀就被隔離出來，平均深度比較淺。高維資料也很有效。
LOF
LocalOutlierFactor		比較一筆資料周圍的密度和它的鄰居周圍的密度。自己周圍比鄰居稀疏得多，就是異常。
One-class SVM
OneClassSVM		用核技巧（第 5 章）在高維空間裡把訓練資料包起來，新資料落在範圍外就是異常。適合新奇偵測，但資料多時很慢。

用同一份資料，讓每個方法都標出大約 4% 的異常（⁠contamination 或 nu 設成 0.04），再和 GMM 抓到的 50 筆比較：

from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.covariance import EllipticEnvelope
from sklearn.svm import OneClassSVM

models = {"Isolation Forest": IsolationForest(contamination=0.04, random_state=42),
          "LOF": LocalOutlierFactor(contamination=0.04),
          "Fast-MCD": EllipticEnvelope(contamination=0.04, random_state=42),
          "One-class SVM": OneClassSVM(nu=0.04)}
for name, model in models.items():
    flagged = model.fit_predict(X) == -1          # −1 代表異常
    print(name, flagged.sum(), (flagged & is_anomaly).sum())
# Isolation Forest 50 30
# LOF 50 29
# Fast-MCD 50 21
# One-class SVM 53 34

實驗：五種方法各抓出哪些異常

★ 這個方法抓到的異常GMM 抓到、這個方法沒抓到
抓到幾筆–
和 GMM 抓到的相同–

每個方法對「異常」的定義不同，抓到的資料只有一部分重疊。重疊最少的是 Fast-MCD：它假設所有正常資料是一個高斯分布，但這份資料有三群，所以它抓的是離「整體中心」最遠的點，而不是群和群之間的低密度地帶。選方法時要想清楚資料的樣子，以及你想抓的是哪一種「不正常」。

常見陷阱與自我檢查

把「第 4 百分位數」當成「密度 0.04」第 4 百分位數是一個門檻值（這份資料是密度 0.0041），意思是最低的 4% 在它下面。
忘了 score_samples() 是對數回傳的是對數密度，門檻也是對數密度。要和密度比，記得取指數。
以為 GMM 不會被異常影響GMM 也會擬合異常的資料。異常很多時，先拿掉最異常的再重新擬合。
以為門檻有標準答案門檻要依誤報和漏報的代價調整，和分類器的決策門檻一樣。
（2024、2023 期末考）GMM 怎麼用來做異常偵測？

先用訓練資料擬合 GMM，得到每一群的權重、平均和共變異數矩陣。對每筆資料算它所在位置的密度 （⁠score_samples() 回傳的是它的對數）。密度低於門檻的就是異常，因為它落在幾乎沒有資料的地方。門檻可以用百分位數設定：例如取所有訓練資料密度的第 4 百分位數，就是把密度最低的約 4% 標成異常。誤報太多就調低門檻，漏報太多就調高。

1,000 筆資料用第 2 百分位數當密度門檻，會標出幾筆異常？

大約 20 筆（1,000 的 2%）。百分位數門檻的意思就是讓這個比例的訓練資料落在門檻下面。

資料只有一群、而且是常態分布時，「密度低於門檻」和 z 分數有什麼關係？

常態分布的密度隨著 變大而變小，所以「密度低於某個門檻」等於「 大於某個值」。例如要標出 4% 的資料，門檻是 （那裡的密度是 0.048）。

異常偵測和新奇偵測差在哪？

異常偵測的訓練資料裡就混了異常，要把它們找出來；新奇偵測假設訓練資料都是正常的，要判斷新的資料和它們是否不一樣。One-class SVM 適合新奇偵測。
