機率密度與共變異數矩陣

從這篇開始的五篇講高斯混合模型（GMM）。GMM 假設資料來自好幾個高斯分布的混合，所以要先弄清楚高斯分布本身：一維的常態分布長什麼樣子、機率密度和機率差在哪裡，以及多維的高斯分布怎麼用平均向量和共變異數矩陣描述一團橢圓形的資料。

這篇讀完你會知道

一維的高斯分布

投影片 26、28

高斯分布（Gaussian distribution）也叫常態分布（normal distribution），記成 。它只有兩個參數：

  • 平均 ：曲線的中心在哪裡（位置）。
  • 變異數 （標準差 的平方）：資料散得多開（尺度）。 越大，曲線越矮越寬。

密度不是機率

投影片 26、41

在實驗裡把 調到 0.15 以下（比 小），最高點會超過 1。這不是錯誤：pdf 的值是機率密度，不是機率，所以可以大於 1。

import numpy as np
from scipy.stats import norm

print(round(norm.pdf(0), 4), round(norm.pdf(2), 4))       # 標準常態 N(0, 1)
print(round(norm.pdf(0, loc=0, scale=np.sqrt(0.05)), 4))   # scale 是標準差 σ，不是變異數
# 0.3989 0.054
# 1.7841
  • 連續的資料剛好等於某一個值（例如剛好是 0）的機率是 0，所以「單一點的機率」沒有意義。
  • 密度要乘上一小段寬度才是機率： 落在 0 附近寬 0.01 的範圍內的機率，大約是 。
  • 要算 落在某個範圍的機率，要把那一段曲線下的面積積分出來。整條曲線下的面積是 1。

第 7 篇的 score_samples() 回傳的就是密度（取對數），投影片 41 也特別強調它們「不是機率，而是機率密度」。

「 小於等於 」的機率，是 pdf 從 積分到 的面積，叫做累積分布函數（cumulative distribution function，CDF），記成 （投影片 27）：

print(norm.cdf(0), round(norm.cdf(1.5), 4))
for k in [1, 2, 3]:
    print(k, round(norm.cdf(k) - norm.cdf(-k), 4))
# 0.5 0.9332
# 1 0.6827
# 2 0.9545
# 3 0.9973

這就是投影片 28 的 68–95–99.7 法則：常態分布的資料，大約 68.27% 落在平均的 1 個標準差以內，95.45% 在 2 個以內，99.73% 在 3 個以內。離平均超過 3 個標準差的資料只有 0.27%，非常少見，這正是第 8 篇用來判斷異常的根據。

補充筆記投影片 27 把 CDF 叫做「Probability Distribution Function」，和 pdf 有什麼不同？
  • 容易混淆的是大小寫：小寫的 pdf 是機率密度函數（probability density function），就是那條鐘形曲線 。
  • 投影片 27、28 寫的「PDF：Probability Distribution Function」指的是機率分布函數，也就是 CDF（累積分布函數），是 S 形的那條。有些書會這樣叫，所以投影片在括號裡補上了 CDF。
  • 本站一律用「pdf」稱呼密度、用「CDF」稱呼累積分布函數，避免混淆。

一句話pdf 是密度（鐘形），CDF 是累積機率（S 形），兩者的關係是 CDF 等於 pdf 的積分。

pdf 的形狀和一維的很像，只是把「除以變異數」換成「乘上共變異數矩陣的反矩陣」：

是行列式。指數裡的 是「考慮了每個方向散開程度的距離平方」（叫做馬氏距離的平方）。這個值相同的點，密度也相同，連起來是一個橢圓（3 維以上是橢球）。投影片 30 的例子是 、，圖上的綠色橢圓是距離平方等於 的「3 個標準差」橢圓：

from scipy.stats import multivariate_normal

mu = np.array([0, 0])
Sigma = np.array([[1, 3/5], [3/5, 2]])                 # 投影片 30 的例子
print(round(multivariate_normal(mu, Sigma).pdf([0, 0]), 4), np.linalg.det(Sigma).round(2))
rng = np.random.default_rng(42)
X = rng.multivariate_normal(mu, Sigma, size=1000)      # 抽 1,000 筆資料
print(X.mean(axis=0).round(2))
print(np.cov(X.T).round(2))                             # 樣本的共變異數矩陣，很接近 Σ
# 0.1243 1.64
# [-0.08 -0.08]
# [[1.06 0.62]
#  [0.62 1.91]]

補充筆記為什麼二維的 1σ 橢圓只包住大約 39% 的資料，不是 68%？
  • 68–95–99.7 是一維的結果。二維時，資料可以往兩個方向偏離，要「兩個方向都不太偏」才會落在橢圓裡，所以比例變小了。
  • 二維高斯分布落在 個標準差橢圓內的機率是 ：1σ 是 39.3%，2σ 是 86.5%，3σ 是 98.9%。
  • 上面程式抽的 1,000 筆資料也是這樣：用 ((X - mu) @ np.linalg.inv(Sigma) * (X - mu)).sum(axis=1) 算出每一筆的距離平方，小於 1、4、9 的比例分別是 40.1%、86.0%、98.6%。
  • 維度越高，這個比例掉得越多，這和第 8 章「高維空間很空曠」是同一件事。

一句話維度越多，資料越容易在某個方向偏離，同樣幾個標準差的範圍包住的資料就越少。

共變異數矩陣的三種形狀

投影片 47

投影片 47 用三個矩陣比較共變異數矩陣和等高線形狀的關係，就是實驗上面的三個按鈕：

形式例子等高線
一般形式斜的橢圓：兩個特徵有相關，橢圓的軸不在座標軸方向上。
對角矩陣正的橢圓：兩個特徵沒有相關（共變異數 0），橢圓的軸和座標軸平行，各方向散開的程度可以不同。
單位矩陣的倍數圓：各方向散開的程度都一樣（球形，spherical）。

限制越多，要學的參數越少：二維的一般形式有 3 個數（兩個變異數、一個共變異數），對角矩陣有 2 個，圓形只有 1 個。第 9 篇會看到，GMM 的 covariance_type 參數就是在選這幾種形狀。

常見陷阱與自我檢查

把 pdf 的值當成機率pdf 是密度，可以大於 1。機率是曲線下的面積。
把 scale 當成變異數norm.pdf(x, loc, scale) 的 scale 是標準差 ，不是變異數 。 時要寫 scale=np.sqrt(0.2)⁠。
以為共變異數矩陣的非對角線是相關係數非對角線是共變異數 ，要除以兩個標準差才是相關係數 。
把一維的 68–95–99.7 用在多維二維時，1、2、3 個標準差的橢圓分別只包住 39%、86%、99% 的資料。
一份資料有 3 個特徵，它的平均向量和共變異數矩陣各是什麼形狀？共變異數矩陣裡有幾個不同的數？

平均向量是 3 × 1（每個特徵一個平均）。共變異數矩陣是 3 × 3：對角線 3 個是各特徵的變異數，非對角線是兩兩特徵的共變異數。因為它是對稱的（），不同的數只有 3 個變異數加 3 個共變異數，共 6 個。

標準常態分布在 0 的 pdf 是 0.3989，這代表 的機率是 39.89% 嗎？

不是。0.3989 是密度，連續的資料剛好等於 0 的機率是 0。密度乘上一小段寬度才是機率，例如落在 −0.005 到 0.005 之間的機率大約是 。

共變異數矩陣是對角矩陣時，等高線是什麼形狀？

軸和座標軸平行的橢圓（兩個變異數相等時是圓）。非對角線是 0 代表兩個特徵沒有相關，所以橢圓不會傾斜。
