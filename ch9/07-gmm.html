高斯混合模型（GMM）：
軟分群與密度估計

第 4 篇看到，K-Means 分不好大小、方向不同的橢圓形的群，投影片說這種資料要用高斯混合模型（Gaussian mixture model，GMM）。它把資料看成好幾個高斯分布混合在一起，不只找出每一群的中心，還找出每一群的大小、形狀、方向和所佔的比例。這篇是 GMM 的核心，期末考連續兩年都考。

什麼是高斯混合模型

投影片 25

投影片 25 的重點：

  • GMM 可以用來做密度估計、分群和異常偵測，第 1 篇的三種非監督式任務都包了。
  • 它是一個機率模型，假設所有資料是由幾個參數未知的高斯分布混合產生的。從同一個高斯分布產生的資料形成一群，通常長得像一個橢圓（橢球）。
  • 最簡單的版本是 scikit-learn 的 GaussianMixture⁠，要事先知道群數 （第 10 篇會看到怎麼選，以及不用指定 的版本）。

資料是怎麼產生的

投影片 31–32

GMM 假設資料 是這樣一筆一筆產生的（投影片 31）：

  2. 再抽位置：如果 ，第 筆資料的位置 從平均 、共變異數矩陣 的高斯分布隨機抽出，記成 。

用 GaussianMixture 擬合

投影片 33

實際上我們只看得到資料，看不到每筆資料來自哪一群，也不知道參數。GMM 要做的是反過來：從資料推回權重、平均和共變異數矩陣（投影片 33）。用第 4 篇那三個橢圓試試：

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.mixture import GaussianMixture

X1, y1 = make_blobs(n_samples=1000, centers=((4, -4), (0, 0)), random_state=42)
X1 = X1.dot(np.array([[0.374, 0.95], [0.732, 0.598]]))
X2, y2 = make_blobs(n_samples=250, centers=1, random_state=42)
X2 = X2 + [6, -8]
X = np.r_[X1, X2]                         # 第 4 篇的三個橢圓

gm = GaussianMixture(n_components=3, n_init=10, random_state=42)
gm.fit(X)
print(gm.weights_.round(3))
print(gm.means_.round(3))
# [0.4  0.21 0.39]
# [[-1.408  1.427]
#  [ 3.399  1.059]
#  [ 0.051  0.075]]
  • n_components=3⁠：群數 。
  • n_init=10⁠：和 K-Means 一樣跑 10 次留最好的（GMM 也可能停在區域最佳解）。它的預設值是 1，所以要自己設。
  • weights_⁠：0.4、0.21、0.39。資料其實是兩個橢圓各 500 筆、圓的那群 250 筆，比例是 0.4、0.4、0.2，估得很準。
  • means_⁠：三群的中心。
print(gm.covariances_.round(3))
print(gm.converged_, gm.n_iter_)
# [[[ 0.635  0.73 ]
#   [ 0.73   1.161]]
#
#  [[ 1.147 -0.033]
#   [-0.033  0.955]]
#
#  [[ 0.688  0.796]
#   [ 0.796  1.212]]]
# True 4

第 0、2 群的共變異數是正的（0.73、0.796），所以是往右上傾斜的橢圓；第 1 群的共變異數幾乎是 0、兩個變異數接近，所以接近一個圓。converged_ 是 True，表示演算法收斂了，只用了 4 輪。

EM 演算法：像 K-Means，但是軟分派

投影片 34

GaussianMixture 用的是期望最大化（Expectation-Maximization，EM）演算法，它和 K-Means 很像（投影片 34）：

  • 先初始化每一群的參數（投影片說是隨機；scikit-learn 預設是先跑一次 K-Means，用它的結果初始化，init_params="kmeans"⁠），再重複兩個步驟直到收斂：
  • E 步驟（expectation）：把資料分派給各群，對應 K-Means 的「標記資料」。
  • M 步驟（maximization）：更新每一群的參數，對應 K-Means 的「更新中心」。

可以把 EM 看成 K-Means 的推廣：它不只找每一群的中心，還找出每一群的大小、形狀、方向和相對的權重。另一個差別是 EM 用軟分派：E 步驟不是把每筆資料硬分給一群，而是算出它屬於每一群的機率（叫做 responsibility），M 步驟再用這些機率當權重來更新參數。詳細的步驟在第 9 篇。

硬分群與軟分群

投影片 35

知道了每一群的位置、大小、形狀、方向和權重，就能把每筆資料分給最可能的那一群（硬分群，predict()⁠），或估計它屬於每一群的機率（軟分群，predict_proba()⁠）：

print(gm.predict(X)[:6])
print(gm.predict_proba(X)[:3].round(3))
# [2 2 0 2 0 0]
# [[0.    0.023 0.977]
#  [0.001 0.016 0.983]
#  [1.    0.    0.   ]]

第一筆資料屬於第 2 群的機率是 97.7%，屬於第 1 群 2.3%，所以 predict() 把它分到第 2 群。和資料真正來自的群比較，GMM 只有 19 筆不一致（1.5%）；第 4 篇的 K-Means，就算給了好的起點也有 56 筆。

後驗機率與分群邊界

投影片 36–39

個成分的 GMM，用下面這個式子近似資料真正的分布（投影片 37）：

  • 是代表「屬於哪一群」的隱藏變數， 是第 群的權重，也就是前面的 ，叫做先驗機率（prior）。
  • ：已知是第 群時，資料的分布就是那一群的高斯分布。
  • 是把各群的高斯分布乘上權重再加起來，叫做混合模型。

投影片 38 用一維的例子說明：第 1 群是 、權重 0.7，第 2 群是 、權重 0.3。在 的密度是兩群各自的密度乘上權重再相加。知道 之後，它屬於各群的機率用貝氏定理算（投影片 39）：

from scipy.stats import norm

p1 = norm.pdf(2, loc=0, scale=1)         # p(x=2 | z=1)
p2 = norm.pdf(2, loc=4, scale=1.5)       # p(x=2 | z=2)
px = 0.7 * p1 + 0.3 * p2                 # p(x=2)
print(round(p1, 4), round(p2, 4), round(px, 4))
print(round(0.7 * p1 / px, 4), round(0.3 * p2 / px, 4))   # 後驗機率 p(z | x=2)
# 0.054 0.1093 0.0706
# 0.5354 0.4646

本身離第 2 群的中心比較近（ 比較大），但第 1 群的權重大得多，乘上權重之後反而第 1 群稍微勝出（53.5%）。這就是 predict_proba() 算的東西。移動 看看：

邊界是曲線，不是 K-Means 的直線：兩群的共變異數矩陣不一樣時，「乘上權重後的密度相等」的地方是一條二次曲線。投影片 36 的圖中， 的點落在 、 的邊界上；三個後驗機率都相等的點，是三群邊界的交會點。

補充筆記一維的例子裡，為什麼左邊很遠的地方還有一條邊界？
  • 兩群的變異數不同：第 1 群 ，第 2 群 。離中心越遠，窄的分布掉得越快。
  • 所以在左邊很遠的地方，雖然離第 1 群的中心比較近，寬的第 2 群的密度反而比較大，後驗機率又換成第 2 群勝出。
  • 時，兩條邊界在 和 。實驗的範圍沒畫到左邊那一條，把 調小，它就會往右移進來。
  • 二維的邊界是二次曲線（橢圓、拋物線或雙曲線），也是同一個原因。

一句話變異數比較大的那群，在很遠的地方密度掉得比較慢，所以兩邊都可能「贏回來」。

產生新資料

投影片 40

GMM 是生成模型（generative model）：照前面「先抽群、再抽位置」的過程，就能產生新的資料。sample() 回傳新的資料和它們來自哪一群：

X_new, y_new = gm.sample(6)
print(X_new.round(2))
print(y_new)
# [[-2.32  1.05]
#  [-1.17  1.63]
#  [ 1.85  2.07]
#  [ 3.98  1.5 ]
#  [ 3.82  0.53]
#  [ 0.38 -0.56]]
# [0 0 1 1 1 2]

注意產生出來的資料是依群的編號排好的（投影片 40）：先是第 0 群的 2 筆，再來第 1 群 3 筆、第 2 群 1 筆。要拿來用時，通常要自己打亂順序。

估計密度

投影片 41

score_samples() 估計每筆資料所在位置的對數機率密度 ，分數越高，密度越高（投影片 41）。取指數就是密度本身：

log_densities = gm.score_samples(X)
print(log_densities[:5].round(2))
print(np.exp(log_densities[:5]).round(4))
# [-2.61 -3.57 -3.33 -2.56 -3.39]
# [0.0737 0.0281 0.0358 0.0776 0.0336]

第 6 篇說過，這些是機率密度，不是機率。要算資料落在某個區域的機率，要把密度在那個區域上積分；在整個平面上積分，結果是 1。用很細的格子加總，就能驗證：

xs = np.linspace(-10, 15, 1001)
ys = np.linspace(-10, 12, 1001)
grid = np.array(np.meshgrid(xs, ys)).reshape(2, -1).T     # 一百萬個格點
cell = (xs[1] - xs[0]) * (ys[1] - ys[0])                   # 每一格的面積
print(round(np.exp(gm.score_samples(grid)).sum() * cell, 4))
# 1.0

為什麼回傳對數？密度常常非常小（例如 ），直接相乘或相加很容易超出浮點數能表示的範圍；取對數之後相乘變相加，數值也比較穩定。第 8 篇會用這些密度來找異常的資料。

常見陷阱與自我檢查

把 score_samples() 當成機率它回傳的是對數密度，取指數之後也只是密度，可以大於 1。
以為 是模型的參數 是每筆資料屬於哪一群的隱藏變數。參數只有權重、平均向量和共變異數矩陣。
以為分群邊界只看離哪個中心近GMM 的邊界是「乘上權重之後的密度相等」的地方，會受各群的大小、形狀和權重影響，是曲線。
忘了 n_init 的預設是 1GaussianMixture 預設只跑一次，結果可能停在區域最佳解。
（2024 期末考）用 GMM 擬合 3 個特徵的資料，列出 GMM 的參數，說明意義並寫出維度。

設有 群。① 權重 ：選到第 群的機率（約等於這群佔資料的比例）， 個純量，都在 0 和 1 之間、加起來是 1。② 平均向量 ：第 群的中心，維度 3 × 1， 個。③ 共變異數矩陣 ：第 群的大小、形狀和方向，維度 3 × 3、對稱， 個；對角線是各特徵在這群裡的變異數，非對角線是兩個特徵的共變異數。總共要學 個參數。 是隱藏變數，不是參數。

（2024、2023 期末考）GMM 怎麼決定群的邊界？

用貝氏定理算每筆資料屬於各群的後驗機率 ，分給後驗機率最大的那一群。兩群的後驗機率相等的地方就是它們的邊界，也就是 （乘上權重之後的密度相等，而且比其他群都大）。因為各群的共變異數不同，邊界是曲線。

硬分群和軟分群在 GMM 裡各用哪個方法？差在哪？

硬分群用 predict()⁠，每筆資料只給一個群編號（後驗機率最大的那群）；軟分群用 predict_proba()⁠，給每筆資料屬於每一群的機率，例如 97.7% 第 2 群、2.3% 第 1 群，能看出它有多確定。

EM 和 K-Means 有什麼相同、什麼不同？

相同：都先隨機初始化，再重複「分派資料」和「更新參數」兩個步驟直到收斂，也都可能停在區域最佳解。不同：K-Means 硬分派、只更新中心；EM 軟分派（每筆資料屬於各群的機率），除了中心，還更新每一群的共變異數矩陣（大小、形狀、方向）和權重。
