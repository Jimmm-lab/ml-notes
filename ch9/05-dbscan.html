DBSCAN：
用密度找出任意形狀的群

K-Means 找的是圍繞著中心、大致是圓形的群，遇到彎曲的形狀就沒辦法了。DBSCAN 換了一個角度：資料密集、連成一片的區域就是一群，不用管它長什麼形狀；落在稀疏地方的資料則當作雜訊。這篇看它怎麼運作、兩個超參數怎麼選，以及它的優缺點。

DBSCAN 的想法：群是連成一片的高密度區域

投影片 18

DBSCAN 是 Density-Based Spatial Clustering of Applications with Noise 的縮寫，意思是「以密度為基礎、能處理雜訊的分群」。它把群定義成連續的高密度區域（投影片 18）。做法是：

  1. 對每一筆資料，數一數離它距離 （epsilon）以內有幾筆資料。這個範圍叫做它的 ε 鄰域（ε-neighborhood）。
  2. 如果 ε 鄰域裡（包含它自己）至少有 min_samples 筆資料，它就是核心點（core instance）。核心點就是位在密集區域裡的點。
  3. 核心點的 ε 鄰域裡的所有資料，都屬於同一群。鄰域裡可能還有別的核心點，它們的鄰居又屬於同一群……所以一長串相鄰的核心點，會連成同一群。
  4. 不是核心點、鄰域裡也沒有任何核心點的資料，就是雜訊（異常），不屬於任何一群。

只有兩個超參數：鄰域的半徑 eps（），和成為核心點需要的資料筆數 min_samples⁠。注意 DBSCAN 不用事先指定群數，群數是算出來的。

核心點、邊界點和雜訊

投影片 19

投影片 19 用一個小例子（⁠min_samples = 4）說明三種點：

  • 核心點（紅色）：ε 鄰域裡至少有 4 筆資料（包含自己）。
  • 邊界點（border，黃色）：自己的鄰居不夠多，不是核心點；但它在某個核心點的 ε 鄰域裡，所以還是屬於那一群。
  • 雜訊（noise，藍色）：不是核心點，附近也沒有核心點，不屬於任何一群。

右下角那 3 個點彼此很近，但 min_samples = 4 時，每個點的鄰域裡只有 3 筆，都不是核心點，所以整組都是雜訊。把 min_samples 降到 3，它們就變成一個小群了。min_samples 可以想成「最少要多少筆資料，才算一個群」。

用 scikit-learn 跑 DBSCAN

投影片 20

投影片 20 用兩個交錯的半月形（moons）資料示範。K-Means 只會畫直線邊界，分不開這種形狀；DBSCAN 可以：

import numpy as np
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.05, random_state=42)
dbscan = DBSCAN(eps=0.05, min_samples=5)
dbscan.fit(X)
print(dbscan.labels_[:10])
print(len(dbscan.core_sample_indices_), dbscan.components_.shape)
# [ 0  2 -1 -1  1  0  0  0  2  5]
# 808 (808, 2)
  • labels_ 是每筆資料的群編號，−1 代表雜訊。
  • core_sample_indices_ 是核心點的索引，components_ 是核心點本身的座標。這裡 1,000 筆裡有 808 筆是核心點。
print(dbscan.labels_.max() + 1, (dbscan.labels_ == -1).sum())
dbscan = DBSCAN(eps=0.2, min_samples=5).fit(X)
print(dbscan.labels_.max() + 1, (dbscan.labels_ == -1).sum())
# 7 77
# 2 0

eps=0.05 時分出 7 群、77 筆雜訊（投影片 20 左圖：「很多異常，加上 7 個不同的群」）。鄰域太小，很多點湊不到 5 個鄰居，月亮被切成好幾段。eps=0.2 時剛好分成兩個月亮，沒有雜訊，是完美的分群（右圖）。自己調調看：

DBSCAN 的優點和限制

投影片 21

投影片 21 的整理：

  • 什麼時候好用：每一群都夠密集，而且群和群之間被低密度的區域隔開。
  • 優點：很簡單，卻能找出任意數量、任意形狀的群；不怕離群值（它們會被當成雜訊，不會把群拉歪）；只有 eps 和 min_samples 兩個超參數，也不用事先指定群數。
  • 限制：如果不同群的密度差很多，可能沒辦法同時抓好所有的群。eps 小到能分開密集的群時，稀疏的群會散成雜訊；eps 大到能抓住稀疏的群時，密集而靠近的群又會黏在一起。
補充筆記密度不同的群，有沒有別的演算法可以處理？
  • 有。scikit-learn 1.3 之後內建 HDBSCAN（Hierarchical DBSCAN）。它等於把所有 eps 都試過一遍，再挑出在一大段 eps 範圍內都很穩定的群，所以密集和稀疏的群可以同時抓到。
  • 它不用指定 eps⁠，主要的超參數是 min_cluster_size（最小群的大小），比 DBSCAN 好調。
  • 代價是計算比較慢，結果也比較難直觀解釋。

一句話HDBSCAN 不用選 eps，能處理密度不同的群，是 DBSCAN 的進階版。

怎麼選 eps 和 min_samples

投影片 22–24

最好的情況是用領域知識決定：eps 是問題本身有意義的距離（例如實際的公尺數），min_samples 是你希望一個群最少有幾筆資料（投影片 22）。沒有這種知識時，可以用下面的經驗法則。

min_samples（MinPts）

  • 至少要比特徵數 多 1：，而且最少是 3。
  • 資料有雜訊時，大一點通常比較好，能得到比較有意義的群。常用的起點是 ；資料很大、雜訊很多或有很多重複資料時，還要更大。

eps：看 k-距離圖的轉折

投影片 23–24 的方法：

  1. 對每一筆資料，算它到第 近的鄰居的距離，。
  2. 把這 個距離由小排到大畫成曲線，叫做 k-距離圖。
  3. 找曲線開始急遽上升的轉折點（knee），它的高度就是適合的 eps⁠。

為什麼是 ？scikit-learn 的 min_samples 包含資料自己，所以「鄰域裡（含自己）有 5 筆」等於「第 4 近的鄰居在 以內」。也就是說，一筆資料是核心點，若且唯若它的 4-距離 ≤ eps。k-距離圖上，在 eps 那條線以下的點，就是核心點。

from sklearn.neighbors import NearestNeighbors

nn = NearestNeighbors(n_neighbors=5).fit(X)      # 5 = min_samples，第一個鄰居是自己
distances, _ = nn.kneighbors(X)
k_dist = np.sort(distances[:, 4])                # 到第 4 個鄰居（不算自己）的距離
print(np.percentile(k_dist, [50, 90, 95, 99]).round(3))
# [0.037 0.062 0.074 0.097]

這份資料的曲線，前 95% 都在 0.074 以下，之後才急遽上升，轉折點大約在 0.08～0.1。eps 取在這附近（例如 0.1），兩個月亮就分得很乾淨，只剩 1 筆雜訊。投影片 24 的提醒：

  • eps 太小：很多資料湊不到足夠的鄰居，沒辦法分群（變成雜訊，或被切成很多小群）。
  • eps 太大：群和群會黏在一起，大部分的資料都在同一群。
  • 通常偏好小一點的 eps：只有一小部分的資料，彼此的距離在 eps 以內。

新資料怎麼分群

課本補充（Géron 第 9 章）

DBSCAN 有 fit_predict()⁠，但沒有 predict()：它不能直接判斷一筆新資料屬於哪一群。課本的做法是另外訓練一個分類器，例如 KNN，只用核心點當訓練資料：

from sklearn.neighbors import KNeighborsClassifier

knn = KNeighborsClassifier(n_neighbors=50)
knn.fit(dbscan.components_, dbscan.labels_[dbscan.core_sample_indices_])
X_new = np.array([[-0.5, 0], [0, 0.5], [1, -0.1], [2, 1]])
print(knn.predict(X_new))
print(knn.predict_proba(X_new))
# [1 0 1 0]
# [[0.18 0.82]
#  [1.   0.  ]
#  [0.12 0.88]
#  [1.   0.  ]]

這裡的 dbscan 是 eps=0.2 的那個。只用核心點訓練，是因為邊界點和雜訊不夠有代表性。但 KNN 一定會把新資料分給某一群，就算它離所有的群都很遠。想保留「雜訊」這個答案，可以加一個距離門檻，離最近的核心點太遠就當作異常：

y_dist, y_pred_idx = knn.kneighbors(X_new, n_neighbors=1)
y_pred = dbscan.labels_[dbscan.core_sample_indices_][y_pred_idx]
y_pred[y_dist > 0.2] = -1
print(y_pred.ravel())
# [-1  0  1 -1]

(−0.5, 0) 和 (2, 1) 離最近的核心點都超過 0.2，被判成異常（−1）；另外兩筆分別分到兩個月亮。

其他分群演算法

課本補充（Géron 第 9 章）

scikit-learn 還有很多分群演算法，課本簡單介紹了這幾個：

演算法做法特點
凝聚式分群
AgglomerativeClustering		一開始每筆資料自己一群，每一步把最近的兩群合併，最後得到一棵合併的樹。可以抓到各種形狀的群，也能看出群的階層關係。資料多時要搭配連通矩陣才不會太慢。
BIRCH
Birch		先把資料壓縮成一棵摘要樹，只保留足夠的統計量，再分群。專為非常大的資料設計，特徵不多時比批次 K-Means 快。
均值漂移
MeanShift		每一點周圍放一個圓，不斷把圓心移到圓內資料的平均位置，最後停在密度的高峰。和 DBSCAN 一樣能找任意形狀、自動決定群數；但一群內部的密度不均勻時，容易把它切成好幾塊，計算量也和資料筆數的平方成正比，不適合大資料。
近鄰傳播
AffinityPropagation		資料之間互相「投票」，選出代表（類似選舉），每個代表和投給它的資料組成一群。群可以大小不同，但計算量和資料筆數的平方成正比，不適合大資料。
譜分群
SpectralClustering		用資料之間的相似度矩陣做降維，再在低維空間用另一個分群演算法（通常是 K-Means）。能抓到複雜的形狀，但不適合資料很多、群的大小又差很多的情況。

常見陷阱與自我檢查

以為 DBSCAN 要指定群數DBSCAN 只要 eps 和 min_samples⁠，群數是算出來的。
把 −1 當成一個群labels_ 裡的 −1 代表雜訊，不是第「−1」群。算群數時要排除它。
以為 min_samples 不包含自己scikit-learn 的 min_samples 包含資料本身，所以 k-距離圖要用第 min_samples − 1 個鄰居。
直接對新資料呼叫 predict()DBSCAN 沒有這個方法。要另外用核心點訓練一個分類器（例如 KNN）。
說明 DBSCAN 怎麼分群。核心點、邊界點和雜訊有什麼不同？

DBSCAN 把群定義成連續的高密度區域。對每筆資料數它的 ε 鄰域裡有幾筆資料（含自己），至少 min_samples 筆的是核心點；核心點的鄰域裡的資料都屬於同一群，相鄰的核心點連成一串就是一整群。邊界點自己的鄰居不夠多、不是核心點，但落在某個核心點的鄰域裡，所以仍屬於那一群；雜訊既不是核心點，鄰域裡也沒有核心點，不屬於任何群。

月亮形資料用 eps=0.05 分出 7 群和很多雜訊，怎麼調整？

把 eps 加大。eps 太小時很多點湊不到 min_samples 個鄰居，月亮會被切成好幾段，或變成雜訊。看 k-距離圖，轉折點大約在 0.08～0.1，取 0.1 或課本的 0.2 都能剛好分成兩個月亮。

什麼樣的資料不適合用 DBSCAN？

不同群的密度差很多時。單一的 eps 沒辦法同時適合密集和稀疏的群：太小，稀疏的群散成雜訊；太大，靠近的密集群會黏在一起。這時可以考慮 HDBSCAN 或高斯混合模型。

資料有 4 個特徵，min_samples 至少要設多少？雜訊很多時呢？

至少 （而且不能小於 3）。雜訊很多時大一點比較好，可以從 開始試。
