用 BIC 和 AIC 選群數

投影片 48–49

K-Means 用 inertia 和輪廓分數選群數，但這兩個指標都假設群是圓的、大小差不多，用在大小、形狀、方向都不同的 GMM 上不可靠。GMM 改用理論資訊準則，選讓它最小的模型（投影片 48）：

  • 是資料筆數。
  • 是模型要學的參數個數（第 7 篇算過：3 群、2 個特徵時是 17 個）。
  • 是概似函數的最大值，也就是訓練好的模型的概似（第 9 篇）。

兩個準則都是兩項相加： 衡量擬合得多好（概似越大，這項越小）， 那一項衡量模型有多複雜（參數越多，這項越大）。群分得越多，概似一定越大，但參數也越多，所以兩者會在某個群數取得平衡。BIC 叫做貝氏資訊準則（Bayesian information criterion），AIC 叫做赤池資訊準則（Akaike information criterion）。

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.mixture import GaussianMixture

X1, y1 = make_blobs(n_samples=1000, centers=((4, -4), (0, 0)), random_state=42)
X1 = X1.dot(np.array([[0.374, 0.95], [0.732, 0.598]]))
X2, y2 = make_blobs(n_samples=250, centers=1, random_state=42)
X2 = X2 + [6, -8]
X = np.r_[X1, X2]                                  # 第 7 篇的三個橢圓
gm = GaussianMixture(n_components=3, n_init=10, random_state=42).fit(X)
print(round(gm.bic(X), 1), round(gm.aic(X), 1))
# 8189.7 8102.5

自己照公式算一次，結果一樣：

m, p = len(X), 17                     # 權重 2 + 平均 6 + 共變異數 9
log_L = gm.score(X) * m               # score() 是平均每筆的對數概似
print(round(np.log(m) * p - 2 * log_L, 1), round(2 * p - 2 * log_L, 1))
# 8189.7 8102.5

對不同的群數各算一次（投影片 49，課本圖 9-21）：

for k in range(1, 9):
    gm_k = GaussianMixture(n_components=k, n_init=10, random_state=42).fit(X)
    print(k, round(gm_k.bic(X), 1), round(gm_k.aic(X), 1))
# 1 9330.4 9304.8
# 2 8971.2 8914.8
# 3 8189.7 8102.5
# 4 8229.6 8111.6
# 5 8273.9 8125.1
# 6 8312.0 8132.4
# 7 8350.2 8139.8
# 8 8391.0 8149.9

BIC 和 AIC 都在 最小，正是資料真正的群數。 從 3 增加到 4，對數概似只多了一點，但參數多了 6 個，兩個準則就都變大了。實務上也會把 covariance_type 一起試：在這份資料上，四種形狀各自最好的 BIC 是 full（）8189.7、tied（）8290.7、spherical（）8572.2、diag（）8572.4，最好的組合還是 full、3 群。

補充筆記BIC 和 AIC 要用哪一個？
  • 兩者只差在懲罰參數的係數：AIC 是 2，BIC 是 。資料超過 7 筆時 ，所以 BIC 對參數的懲罰比較重，傾向選比較簡單的模型。
  • 課本的說法：BIC 選的模型通常比 AIC 簡單（參數少），但擬合得沒那麼好，資料大時尤其明顯。
  • 兩者常常選到同一個模型，像這份資料都選 3 群。選得不一樣時，可以兩個都看，再配合實際用途決定。
  • 它們只能比較同一份資料上的不同模型，數字本身沒有絕對的意義。

一句話BIC 懲罰參數比較重、偏好簡單的模型；兩者都是越小越好。

貝氏高斯混合模型

投影片 60–61

與其一個一個群數試，也可以用 BayesianGaussianMixture⁠：群數給一個比需要的還大的數，它會把用不到的群的權重壓到 0 或接近 0（投影片 60）：

from sklearn.mixture import BayesianGaussianMixture

bgm = BayesianGaussianMixture(n_components=10, n_init=10, max_iter=500,
                              random_state=42).fit(X)
print(np.round(bgm.weights_, 2))
# [0.4  0.21 0.39 0.   0.   0.   0.   0.   0.   0.  ]

給了 10 個成分，它自己判斷只需要 3 個，而且權重 0.4、0.21、0.39 和第 7 篇的結果一樣。（⁠max_iter 的預設值 100 在這份資料上還沒收斂，scikit-learn 會發出警告，所以設成 500。）

它是 GMM 加上變分推論（variational inference）的版本，可以看成 EM 的延伸（投影片 60）：

  • 一般的 GMM 用 MLE，把參數當成固定的未知值。貝氏 GMM 把參數也當成隨機變數，先給它們先驗分布（第 9 篇的 MAP 和貝氏估計），例如「大部分的群權重應該很小」。
  • 它最大化的不是資料的概似，而是證據的下界（evidence lower bound，ELBO），這個下界把先驗也考慮進去了。
  • 權重的先驗由 weight_concentration_prior 控制：越小，越傾向只用少數幾群；越大，越願意用很多群。資料夠多時，它的影響不大。

用 GMM 產生新的手寫數字

投影片 59

GMM 是生成模型，第 7 篇用它在平面上抽樣。投影片 59 引用了一個更有趣的例子：學會手寫數字的分布，再抽樣產生「新的」手寫數字。手寫數字有 64 個像素，直接擬合要學的參數太多，所以先用 PCA 降維：

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA

digits = load_digits()                          # 1,797 張 8 × 8 的手寫數字
pca = PCA(0.99, whiten=True)                    # 保留 99% 的變異，並把各方向的變異數調成 1
data = pca.fit_transform(digits.data)
print(data.shape)
# (1797, 41)

64 維降到 41 維。用 AIC 選群數（這段要跑大約 20 秒）：

n_components = range(50, 210, 10)
aics = [GaussianMixture(n, covariance_type="full", random_state=0).fit(data).aic(data)
        for n in n_components]
print(n_components[int(np.argmin(aics))])
# 150

AIC 在 150 群最小（投影片的結果是 110 群左右，是較舊版本的 scikit-learn 算的；這段範圍內 AIC 的變化本來就很平緩）。用 150 群擬合，抽 100 筆新的 41 維資料，再用 PCA 還原成 64 個像素：

gmm = GaussianMixture(150, covariance_type="full", random_state=0).fit(data)
data_new, _ = gmm.sample(100)
digits_new = pca.inverse_transform(data_new)       # 41 維還原成 64 個像素
print(digits_new.shape)
# (100, 64)

實驗：真的手寫數字，和 GMM 產生的數字

產生出來的大部分看得出是數字，但它們不是資料裡任何一張圖的複製品，而是從學到的分布裡抽出來的新樣本。這就是「生成模型」的意思。

GMM 的限制

投影片 62

GMM 很適合橢圓形的群，但用在其他形狀的資料上，可能會有意想不到的結果（投影片 62，課本圖 9-24）。用第 5 篇的月亮形資料試試：

from sklearn.datasets import make_moons

X_moons, y_moons = make_moons(n_samples=1000, noise=0.05, random_state=42)
bgm = BayesianGaussianMixture(n_components=10, n_init=10, max_iter=500,
                              random_state=42).fit(X_moons)
print(np.round(bgm.weights_, 2))
# [0.07 0.15 0.13 0.12 0.14 0.16 0.   0.11 0.11 0.  ]

實驗：用 GMM 擬合月亮形的資料

用到的成分–
和兩個月亮不一致–

  • 只給 2 群：GMM 只能用兩個橢圓去套兩個彎彎的月亮，每個月亮的尾端都被分給另一群，146 筆分錯。
  • 貝氏 GMM：它用了 8 個成分，沿著月亮排成一串。每個成分都只在一個月亮裡（和兩個月亮都一致），所以當作密度估計很好用，例如拿來偵測異常；但當作分群，它說有 8 群，不是我們要的 2 群。

形狀不規則的群，第 5 篇的 DBSCAN 比較適合；異常偵測也可以考慮第 8 篇的其他方法（投影片 63）。

第 9 章整理

投影片 2–63

第 9 章學了非監督式學習的三種任務，和處理它們的幾個演算法：

演算法找出什麼樣的群要決定什麼怎麼選
K-Means（第 1～4 篇）圍繞中心、大致是圓形、大小差不多的群；直線邊界群數 ；初始化手肘法、輪廓分數和輪廓圖；K-Means++ 加上 n_init
DBSCAN（第 5 篇）任意形狀、連成一片的高密度區域；會標出雜訊eps⁠、min_samples領域知識、MinPts ≥ D + 1、k-距離圖的轉折
GMM（第 6～10 篇）大小、形狀、方向不同的橢圓形群；軟分群、密度估計群數、covariance_typeBIC、AIC；或用貝氏 GMM 自動決定
  • 分群沒有標準答案，「群」的定義依演算法而不同。分群的結果也可以拿來做影像分割、當作前處理產生新特徵，或在半監督式學習裡減少要人工標記的資料（第 4 篇）。
  • K-Means 輪流「標記資料」和「更新中心」，EM 輪流「E 步驟」和「M 步驟」；兩者都一定會收斂，但可能停在區域最佳解，所以都要跑好幾次。
  • GMM 假設資料是「先依權重抽群，再從那群的高斯分布抽位置」產生的；參數是權重、平均向量和共變異數矩陣，用最大概似估計，由 EM 演算法求出。用貝氏定理算後驗機率來分群，邊界在後驗機率相等的地方。
  • 異常偵測：密度低於門檻的就是異常，門檻常用百分位數設定（第 4 百分位數不是密度 0.04）；其他方法有 PCA 重建誤差、Fast-MCD、Isolation Forest、LOF、One-class SVM（第 8 篇）。

常見陷阱與自我檢查

用 inertia 或輪廓分數選 GMM 的群數這兩個指標假設群是圓的，不適合 GMM。用 BIC 或 AIC。
選 BIC 最大的模型BIC 和 AIC 都是越小越好。
以為貝氏 GMM 一定給出「正確」的群數它會關掉用不到的群，但群不是橢圓形時（例如月亮），它可能用很多個成分去拼一個群。
以為 GMM 產生的資料是從訓練資料挑出來的產生的是從學到的分布裡抽出的新樣本，不是原本資料的複製。
寫出 BIC 和 AIC 的公式，說明每一項的意義。為什麼加群數不一定比較好？

，。 是資料筆數， 是要學的參數個數， 是概似的最大值。 衡量擬合程度， 那項衡量模型複雜度。加群數會讓概似變大，但參數也變多，懲罰項變大；超過真正的群數之後，概似增加得很少，懲罰卻持續增加，所以 BIC、AIC 反而變大。選兩者最小的模型。

貝氏 GMM 怎麼決定群數？

把群數設得比需要的大（例如 10），它會把用不到的群的權重壓到 0 或接近 0，剩下權重明顯大於 0 的群數就是它判斷的群數。它把參數當成隨機變數、加上先驗分布，用變分推論最大化證據的下界（ELBO），權重的先驗傾向讓大部分的群權重很小。

3 群、2 個特徵、covariance_type="full" 的 GMM 有 17 個參數，怎麼算出來的？

權重 3 個但加起來是 1，所以 2 個；平均向量每群 2 個，共 6 個；共變異數矩陣每群是 2 × 2 對稱矩陣，有 3 個不同的數，共 9 個。。
