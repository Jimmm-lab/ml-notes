8. Dimensionality Reduction，第 7 篇／共 9 篇（投影片 16–20）

Kernel PCA：
用核技巧做非線性投影

PCA 是線性的投影，攤不開瑞士捲。把第 5 章 SVM 的核技巧用在 PCA 上，就得到 Kernel PCA：它可以做非線性的投影，常常能把群聚分得更開，有時還能把捲起來的資料攤開。這篇看它怎麼用、不同的核差在哪裡，以及沒有標準答案時怎麼選核。

這篇讀完你會知道

  • 同心圓的例子：PCA 分不開的兩類，Kernel PCA 投影後用一個門檻就能分開。
  • 怎麼選核和超參數：用後面的監督式任務評分，或看 pre-image 誤差；兩者可能選出不同的答案。

線性投影攤不開瑞士捲

投影片 16

第 2 篇看過：瑞士捲要用「捲上的位置」和「高度」兩個數字才能描述。直接投影到 平面，不同圈的點會疊在一起（投影片 16）；換成投影到捲的截面，各圈雖然分開了，看到的卻是一個螺旋，而且不同高度的點疊在一起。PCA 做的事就是投影，它找的是最好的那個平面，但終究還是一個平面，攤不開捲。要處理彎曲的資料，需要非線性的方法。

核技巧回顧

投影片 17

第 5 章學 SVM 時用過核技巧（kernel trick，投影片 17 的回顧）：它在數學上把資料「隱性地」映射到一個維度非常高的空間（特徵空間），卻不必真的算出那些新特徵。在特徵空間裡的一個超平面，回到原本的空間就是一條彎曲的決策邊界（見第 5 章的 RBF 核）。

同樣的技巧也能用在 PCA 上：在特徵空間裡做 PCA（線性的投影），回到原本的空間看，就是一個複雜的非線性投影。這就是 Kernel PCA（kPCA）。投影片 17 說，它常常能在投影後保留資料的群聚，有時甚至能攤開靠近一個捲曲流形的資料。

補充筆記Kernel PCA 實際上怎麼算？為什麼不適合很大的資料？
  • PCA 要找共變異數矩陣的特徵向量，但特徵空間的維度可能是無限大，沒辦法直接算。
  • Kernel PCA 改算一個 的核矩陣：第 列第 行是 ，也就是兩筆資料在特徵空間裡的內積。例如 RBF 核是 。
  • 把核矩陣置中之後求它的特徵向量，就能得到每筆資料在特徵空間的主成分上的座標，完全不需要真的算出特徵空間的座標。
  • 代價是核矩陣有 個數字，求特徵向量大約要 的計算量。資料有 10 萬筆時，核矩陣就有 100 億個數字，放不進記憶體。所以 Kernel PCA 適合中小型的資料。
  • 線性核 的特徵空間就是原本的空間，這時 Kernel PCA 和一般的 PCA 結果一樣。

一句話Kernel PCA 用 m × m 的核矩陣代替共變異數矩陣，不必算出高維的特徵，但資料一多就很吃記憶體。

用 KernelPCA 降維

投影片 18

scikit-learn 的 KernelPCA 用法和 PCA 一樣，多了核的種類和核的超參數。例如用 RBF 核、，把瑞士捲降到 2 維：

from sklearn.decomposition import KernelPCA

rbf_pca = KernelPCA(n_components=2, kernel="rbf", gamma=0.04)
X_reduced = rbf_pca.fit_transform(X)

同心圓：投影後一刀就分開

投影片 19–20

投影片 19、20 是兩個參考例子。投影片 20 來自 scikit-learn 的範例：兩個同心圓，外圈和內圈各是一類，任何一條直線都分不開。PCA 只是把資料轉個方向，投影後還是同心圓；Kernel PCA 卻能把兩類分到兩邊。這也是投影片 19 那張手繪圖的意思：一般的 PCA 能降維，但不會讓資料變得線性可分；Kernel PCA 降維的同時，還可能讓資料變得線性可分。

分類器是邏輯迴歸（線性模型），所以準確率高就表示投影後的資料線性可分。一般的 PCA 只有 50% 左右，和亂猜一樣；RBF 核 或 5 時，只用第 1 個主成分、一個門檻就能 100% 分開。這裡同樣看得到 的影響：太小像 PCA，太大反而分不好。

怎麼選核和超參數

投影片 18

投影片 18 提醒：kPCA 是非監督式學習，沒有明顯的「好壞分數」可以拿來選核和超參數。常見的做法有兩種：

做法一：看後面的監督式任務

降維通常是為了接下來的分類或迴歸。這時可以把 kPCA 和後面的模型放進同一個 pipeline，用格狀搜尋（第 2 章）選出讓最後的模型表現最好的核和超參數。課本把瑞士捲分成兩類（⁠t > 6.9⁠），後面接邏輯迴歸，在 RBF 和 sigmoid 兩種核、 從 0.03 到 0.05 之間搜尋，選出的是 RBF 核、。實驗裡的「分類分數」就是這個任務的 3 折交叉驗證準確率。

做法二：看 pre-image 誤差（完全非監督）

PCA 可以用 inverse_transform() 解壓縮，看重建誤差（第 5 篇）。kPCA 的投影發生在特徵空間，沒辦法直接反過來；但可以訓練一個迴歸模型，從投影後的座標預測原本的點，預測出來的點叫做 pre-image（原像）。原本的點和 pre-image 的平方誤差越小，表示投影保留的資訊越多。scikit-learn 設定 fit_inverse_transform=True⁠，就會自動訓練這個迴歸模型。RBF 核、 的 pre-image 誤差是 32.79，和課本一樣。

補充筆記為什麼 pre-image 要另外訓練一個模型，不能直接反過來算？
  • kPCA 先把每一點映射到特徵空間（可能是無限多維），再投影到前幾個主成分上。
  • 反過來時，從投影後的座標可以回到特徵空間裡的一點，但這一點通常不對應原本空間裡的任何一點：特徵空間比原本的空間大太多，大部分的位置都沒有「原像」。
  • 所以只能找一個近似的答案：原本空間裡，映射後最接近那個位置的點。scikit-learn 的做法是用投影後的座標當輸入、原本的點當答案，訓練一個核脊迴歸（kernel ridge regression），用它的預測當 pre-image。

一句話特徵空間裡的點不一定有原像，只能用迴歸模型估一個最接近的。

要注意的是，兩種做法不一定選出一樣的答案。上面的實驗裡，分類分數最高的是 （93.1%），pre-image 誤差最小的卻是 （18.52）。這並不矛盾：前者在乎「投影後分不分得出 t > 6.9⁠」，後者在乎「能不能還原原本的點」。所以要依照降維的目的，選擇評分的方式。

Python 實作

瑞士捲降到 2 維（課本的設定）：

import numpy as np
from sklearn.datasets import make_swiss_roll
from sklearn.decomposition import KernelPCA

X, t = make_swiss_roll(n_samples=1000, noise=0.2, random_state=42)
rbf_pca = KernelPCA(n_components=2, kernel="rbf", gamma=0.04)
X_reduced = rbf_pca.fit_transform(X)
print(X_reduced.shape)
# (1000, 2)

做法一：kPCA 接邏輯迴歸，用格狀搜尋選核和 （課本的例子）。NumPy 2 會把 γ 印成 np.float64(...)⁠：

from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import Pipeline

y = t > 6.9                                     # 把瑞士捲分成兩類
clf = Pipeline([
    ("kpca", KernelPCA(n_components=2)),
    ("log_reg", LogisticRegression())
])
param_grid = [{
    "kpca__gamma": np.linspace(0.03, 0.05, 10),
    "kpca__kernel": ["rbf", "sigmoid"]
}]
grid_search = GridSearchCV(clf, param_grid, cv=3)
grid_search.fit(X, y)
print(grid_search.best_params_)
# {'kpca__gamma': np.float64(0.043333333333333335), 'kpca__kernel': 'rbf'}

做法二：設 fit_inverse_transform=True⁠，算 pre-image 誤差：

from sklearn.metrics import mean_squared_error

rbf_pca = KernelPCA(n_components=2, kernel="rbf", gamma=0.0433,
                    fit_inverse_transform=True)
X_reduced = rbf_pca.fit_transform(X)
X_preimage = rbf_pca.inverse_transform(X_reduced)
print(round(mean_squared_error(X, X_preimage), 4))
# 32.7863

同心圓：比較 PCA 和 RBF 核的 kPCA，只用第 1 個主成分訓練邏輯迴歸：

from sklearn.datasets import make_circles
from sklearn.decomposition import PCA

X_c, y_c = make_circles(n_samples=1000, factor=0.3, noise=0.05, random_state=0)
for reducer in [PCA(n_components=2), KernelPCA(n_components=2, kernel="rbf", gamma=2)]:
    Z = reducer.fit_transform(X_c)
    acc = LogisticRegression().fit(Z[:, :1], y_c).score(Z[:, :1], y_c)
    print(type(reducer).__name__, acc)
# PCA 0.507
# KernelPCA 1.0

常見陷阱與自我檢查

以為 γ 越大越好γ 太大時，每一點只受很近的鄰居影響，整體結構會散掉。同心圓在 γ = 50 時，反而分不好了。
忘了設 fit_inverse_transform=True 就呼叫 inverse_transform()kPCA 預設不會訓練回推用的迴歸模型，這時呼叫 inverse_transform() 會出錯。
在很大的資料上直接用 Kernel PCA核矩陣有 個數字，資料一多就放不進記憶體，也算得很慢。
以為選核有唯一的正確答案非監督式學習沒有標準答案。用分類分數和用 pre-image 誤差，可能選出不同的 γ，要看降維的目的。
線性核的 Kernel PCA，和一般的 PCA 有什麼關係？

結果一樣。線性核 的特徵空間就是原本的空間，所以在特徵空間做 PCA，就是一般的 PCA。實驗裡的線性核，就是把瑞士捲投影到捲的截面，看到一個螺旋，攤不開。

同心圓的資料，為什麼一般的 PCA 降到 1 維一定分不開？

PCA 是把資料投影到一條直線上。內圈的點投影後會落在中間，外圈的點落在兩側，而且外圈的投影範圍把內圈整個包住，所以不管選哪個方向，兩類都會重疊，一個門檻分不開。Kernel PCA 的投影是非線性的，才能把內圈和外圈分到兩邊。

想用 kPCA 當分類前的前處理，該怎麼選核和 γ？

把 KernelPCA 和分類器放進同一個 Pipeline⁠，用 GridSearchCV 搜尋 kpca__kernel 和 kpca__gamma⁠，選交叉驗證分數最高的組合。因為目的是分類，就用分類的表現來評分。
