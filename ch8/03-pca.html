8. Dimensionality Reduction，第 3 篇／共 9 篇（投影片 7–9）

PCA：
找出保留最多變異的軸

上一篇把 3D 資料投影到一個平面上，但沒說這個平面是怎麼選的。主成分分析（PCA）是最常用的降維演算法，它的想法很簡單：選擇讓投影之後「保留最多變異」的方向。這篇用實驗看這個想法，再看什麼是主成分，以及怎麼用 SVD 把它們算出來。

這篇讀完你會知道
  • PCA 的兩個步驟：先找出最貼近資料的超平面，再把資料投影上去。

  • 主成分：第一條軸保留最多變異，之後每一條都和前面的垂直，保留剩下最多的變異。
  • 怎麼用 SVD 一次算出所有的主成分，以及為什麼要先把資料減掉平均。

PCA 的兩個步驟

投影片 7

主成分分析（Principal Component Analysis，PCA）是目前最常用的降維演算法（投影片 7）。它做兩件事：

  1. 找出最貼近資料的超平面（hyperplane）。這裡的超平面泛指任何維度的「平面」：降到 1 維時是一條直線，降到 2 維時是一個平面。
  2. 把資料投影到這個超平面上。

第 2 步上一篇已經看過了，關鍵在第 1 步：投影之前，要先選對超平面。下面從最簡單的情況看起：把 2 維的資料投影到一條軸上，變成 1 維。

選哪一條軸？保留最多的變異

投影片 7–8

投影片 8（課本圖 8-7）左邊是一份 2 維的資料，沿著斜線方向拉得很長。右邊是把資料投影到三條不同的軸上的結果：

  • 投影到實線 ：點分得最開，變異最大。
  • 投影到虛線：點擠在一起一些。
  • 投影到點線 ：點全擠成一團，變異最小。

變異（variance）衡量資料散開的程度：每一點離平均值的距離，平方之後取平均。投影之後的變異越大，點和點之間的差異就保留得越多。所以投影片 7 說，選擇保留最多變異的軸看起來最合理，因為它最可能損失最少的資訊。自己轉轉看：

投影片 7 還給了第二個理由：這條軸也是讓原始資料和它的投影之間，平均平方距離最小的軸。實驗裡兩個數字一個變大、另一個就變小，加起來永遠是 0.254。原因是畢氏定理：每一點到平均值 的距離平方，等於它投影後的座標 的平方，加上它到軸的距離 的平方：

對所有的點取平均，就得到：總變異 = 投影後的變異 + 平均平方距離。總變異由資料本身決定，和軸怎麼選無關，所以讓投影後的變異最大，就等於讓平均平方距離最小。投影片 7 的兩種說法，選出的是同一條軸。

補充筆記為什麼說變異越大，保留的「資訊」越多？
  • 極端的例子：如果所有點投影後都落在同一個位置，變異是 0，你再也分不出哪一點是哪一點，資訊全部不見了。
  • 投影後的點分得越開，原本點和點之間的差異（誰在左、誰在右、差多少）就保留得越多。
  • 從另一個角度看：平均平方距離就是投影時「被丟掉」的部分。實驗裡橘色那一段越短，丟掉的就越少。
  • 「資訊」其實有很多種定義，PCA 選擇用變異來衡量。這個選擇很實用，因為它剛好對應到「投影誤差的平方平均」，第 5 篇的重建誤差就是它。

一句話變異大，表示投影後點還分得開，彼此的差異沒有被壓掉。

主成分：一條接一條的軸

投影片 9

PCA 不只找一條軸（投影片 9）：

  1. 第一條軸：保留最多變異的方向。
  2. 第二條軸：和第一條垂直，在這個條件下保留剩下最多變異的方向。
  3. 第三條軸：和前兩條都垂直……依此類推， 維的資料總共有 條軸。

第 條軸叫做第 個主成分（principal component，PC），寫成 。2 維的資料只有兩條軸， 就是和 垂直的那一條（投影片 8 的點線）。3 維的情況比較有意思：

還有一個細節：主成分只決定一條「軸」，方向的正負號沒有意義，把 換成 還是同一條軸。課本提醒，資料稍微變動、或換一套程式重算，算出來的方向可能剛好相反（下面的 Python 實作就會遇到）。

用 SVD 找出主成分

投影片 9

怎麼算出這些主成分？投影片 9 說，用一種叫做奇異值分解（Singular Value Decomposition，SVD）的矩陣分解。把訓練資料寫成一個 的矩陣 （每一列是一筆資料），SVD 可以把它拆成三個矩陣相乘：

其中 是 的矩陣，它的每一行（column）都是長度為 1 的向量，彼此互相垂直（投影片 9 的 orthogonal unit vectors），而且依序就是所有的主成分：

對角線上的奇異值告訴我們每個主成分有多重要：第 個奇異值平方、再除以 ，就是資料沿著 的變異。

要先把資料置中。PCA 假設資料的平均在原點，所以算 SVD 之前，要先把每個特徵減掉它的平均（centering）。scikit-learn 的 PCA 會自動做；自己用 NumPy 算時別忘了，不然第一個方向會指向資料的平均位置，而不是資料散開的方向。

補充筆記為什麼 V 的每一行剛好就是主成分？
  • 資料沿著一個單位向量 投影後的變異，可以寫成 （ 已經置中）。PCA 要找讓它最大的 。
  • 把 SVD 代進去：（因為 ）。所以 的每一行都是 的特徵向量，對應的特徵值是奇異值的平方 （特徵向量見第 4 章的補充筆記）。
  • 單位向量 能讓 達到的最大值，就是最大的特徵值 ，發生在 的時候：所以 ，變異是 。
  • 限定和 垂直之後，最大值換成下一個特徵值 ，發生在 ……依此類推。

一句話主成分就是 XᵀX 的特徵向量，按特徵值（奇異值的平方）由大到小排，SVD 一次把它們全部算出來。

Python 實作

先做出投影片 8（課本圖 8-7）的資料，把它投影到圖中的三條軸上，看投影後的變異、平均平方距離，以及兩者的和：

import numpy as np

np.random.seed(3)                               # 課本圖 8-7 的資料
m = 200
angle = np.pi / 5                               # 36 度
X = np.random.randn(m, 2) / 10
X = X @ np.array([[5, 0], [0, 1]])              # 橫向拉長 5 倍
X = X @ np.array([[np.cos(angle), np.sin(angle)],
                  [-np.sin(angle), np.cos(angle)]])   # 再轉 36 度

u1 = np.array([np.cos(angle), np.sin(angle)])                          # 實線
u2 = np.array([np.cos(angle - np.pi / 3), np.sin(angle - np.pi / 3)])  # 虛線
u3 = np.array([np.cos(angle - np.pi / 2), np.sin(angle - np.pi / 2)])  # 點線
X_centered = X - X.mean(axis=0)
for u in [u1, u2, u3]:
    z = X_centered @ u                          # 投影後的 1 維座標
    d2 = ((X_centered - np.outer(z, u)) ** 2).sum(axis=1)   # 到軸的距離平方
    print(z.var().round(4), d2.mean().round(4), (z.var() + d2.mean()).round(4))
# 0.2423 0.0119 0.2542
# 0.0653 0.1889 0.2542
# 0.0119 0.2423 0.2542

用 NumPy 的 svd() 算出所有主成分。注意 s 只是一個向量，放著 對角線上的奇異值；傳回的是 （Vt），所以它的每一列才是一個主成分：

U, s, Vt = np.linalg.svd(X_centered)
print(U.shape, s.shape, Vt.shape)
c1, c2 = Vt
print(c1.round(3), c2.round(3))
# (200, 200) (2,) (2, 2)
# [-0.796 -0.605] [-0.605  0.796]

把 補回 的矩陣，三個矩陣乘回去，就是原本（置中後）的資料：

S = np.zeros(X_centered.shape)                  # 200 × 2，只有對角線放奇異值
S[:2, :2] = np.diag(s)
print(np.allclose(X_centered, U @ S @ Vt))
# True

scikit-learn 的 PCA 會自己減掉平均，components_ 的每一列是一個主成分；explained_variance_ 是沿著每個主成分的變異，等於奇異值平方除以 ：

from sklearn.decomposition import PCA

pca = PCA().fit(X)
print(pca.components_.round(3))
print(pca.explained_variance_.round(4), (s ** 2 / (m - 1)).round(4))
# [[ 0.796  0.605]
#  [-0.605  0.796]]
# [0.2436 0.0118] [0.2436 0.0118]

NumPy 給的 是 ，scikit-learn 給的是 ：方向相反，但是同一條軸（scikit-learn 會用固定的規則統一正負號）。這條軸的角度大約是 37.2°，很接近資料被拉長的 36°。

常見陷阱與自我檢查

自己算 SVD 前忘了把資料置中PCA 假設平均在原點。沒有先減掉平均，第一個方向會指向資料的平均位置，而不是資料散開最多的方向。
以為主成分是原本的某幾個特徵主成分是新的方向，通常每一個都混合了所有原本的特徵，例如 3D 資料的 是 。
以為主成分的正負號有意義 和 是同一條軸。不同的程式、或資料稍微變動，都可能算出相反的方向。
把「變異最大」和「距離最小」當成兩種不同的選法總變異固定，投影後的變異加上平均平方距離等於總變異，所以兩者選出的是同一條軸。
（2024、2023 期末考）參考投影片 8 的圖，說明 PCA 用來降維的想法。

圖左是一份沿著斜線拉長的 2 維資料，右邊是把它投影到三條不同的軸上。投影到 時點分得最開，變異最大；投影到中間的虛線時變異變小；投影到和 垂直的 時點擠成一團，變異最小。PCA 選擇保留最多變異的軸當第一主成分 ，再找和它垂直、保留剩下最多變異的軸當 ，依此類推；降到 維時，就把資料投影到前 個主成分上。保留最多變異，等於讓原始資料和投影之間的平均平方距離最小，也就是損失最少的資訊。實務上用 SVD 算出主成分。

3 維的資料，PCA 最多能找出幾個主成分？它們之間有什麼關係？

3 個。它們都是長度為 1 的向量，兩兩互相垂直，保留的變異依序由大到小。例如這篇的 3D 資料，三個主成分分別保留了 84.2%、14.6%、1.1% 的變異。

投影到某條軸之後，變異是 0.20；資料的總變異是 0.25。原始資料到這條軸的平均平方距離是多少？

0.25 − 0.20 = 0.05。總變異 = 投影後的變異 + 平均平方距離（畢氏定理）。
