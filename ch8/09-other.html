MDS、Isomap、t-SNE

投影片 29

投影片 29（課本圖 8-13）用另外三種方法，把瑞士捲降到 2 維：

  • MDS（多維標度，Multidimensional Scaling）：降維時盡量保留所有點兩兩之間的距離。
  • Isomap：先把每一點和最近的幾個鄰居連起來，組成一張圖；再盡量保留點之間的測地距離（geodesic distance）：沿著這張圖走，從一點到另一點的最短路徑。在瑞士捲上，這就是沿著捲面走的距離，而不是穿過空氣的直線距離。
  • t-SNE（t-distributed Stochastic Neighbor Embedding）：讓原本相近的點留在一起，原本不相近的點分開。它主要用在視覺化，特別是把高維資料畫成 2D 或 3D 來看群聚，例如把 MNIST 畫在平面上。

下面的實驗把這幾種方法和 PCA、LLE 放在一起比較。兩個數字分別看「局部」和「整體」：

補充筆記「鄰居保留程度」和「一致程度」是怎麼算的？
  • 鄰居保留程度是 scikit-learn 的 trustworthiness()⁠：在降維後的結果裡，找出每一點最近的 10 個鄰居，檢查它們在原本的資料裡是不是也很近；如果有「降維後才變成鄰居」的點，就依照它原本排第幾近扣分。1 表示降維後的鄰居全都是真的鄰居。
  • 一致程度是第 8 篇用過的 Spearman 等級相關係數（取絕對值）：比較 由小到大的順序，和每一點在流形上的位置（瑞士捲上的 t⁠）的順序。1 表示 剛好照著流形上的位置排，也就是流形被攤開了。
  • 第一個數字看局部（附近的點有沒有留在附近），第二個看整體（大範圍的順序對不對）。t-SNE 常常第一個很高、第二個較低。

一句話一個問「鄰居還是鄰居嗎」，一個問「整條流形的順序對不對」。

在瑞士捲上，Isomap 和 LLE 都把捲攤開了（一致程度 0.999 和 0.998）。MDS 想保留所有的距離，包括內外圈之間穿過空氣的直線距離，所以攤不開；PCA 是線性的，也攤不開。t-SNE 的鄰居保留程度最高（0.9995），但它只在乎近的點，整體的形狀和順序就不一定保留：結果是一條彎來彎去的帶子。

LDA：用到類別的降維

LDA（線性判別分析，Linear Discriminant Analysis）其實是一個分類演算法，但訓練時它會找出最能區分各個類別的軸，這些軸也可以拿來投影降維（課本的介紹）。投影之後各個類別會盡量分開，所以很適合在另一個分類演算法（例如 SVM）之前先用它降維。

和這一章的其他方法不同，LDA 是監督式的：它需要類別標籤 y⁠。另外，類別有 個時，最多只能降到 維。後面葡萄酒的實驗會用到它。

PCA 還是流形學習？

投影片 30–32

投影片 30 的回答是：資料落在（或很靠近）一個線性的子空間時，PCA 最有用：它會找出這個子空間的一組基底，讓我們丟掉不重要的特徵。流形學習則可以看成 PCA 的非線性版本，適合彎曲的資料。

投影片 31、32 用一份 S 形的資料（一張彎成 S 形的寬紙，3D 裡的 2D 流形）比較兩者。把上面實驗的資料換成「S 形」看看：

  • PCA：投影到前兩個主成分，等於沿著某個方向把 S 壓扁，S 的兩個彎疊在一起，那些地方不同位置的點混在一起（投影片 31）。
  • LLE 和 Isomap：保留了局部的結構，把 S 攤成一張平的紙，顏色沒有混在一起（投影片 32）。

所以選擇的依據是資料的形狀：資料大致是「平的」，用 PCA 又快又好解釋；資料是彎曲的流形，才需要流形學習。實務上可以先試 PCA，看解釋變異比和降維後的結果，再決定要不要換成非線性的方法。

先標準化，再降維

投影片 33

投影片 33 只有一句話：做 PCA 或 LLE 之前，先把資料標準化。原因是 PCA 找的是變異最大的方向，而變異會受到單位影響：一個以「公尺」為單位的特徵，改成「公分」之後，變異就變成一萬倍。

用葡萄酒資料（⁠load_wine()⁠，178 瓶酒、13 個化學成分、3 個產區）看看：其中脯胺酸（proline）的數值從幾百到一千多，標準差 314；其他 12 個特徵的標準差都不到 15，大多在 1 左右。

  • 直接做 PCA：第一個主成分保留了 99.8% 的變異，看起來很棒，但它幾乎就是 proline 一個特徵：PCA 只是找到了「數字最大的那一欄」，其他 12 個特徵幾乎被忽略。用這 2 維分類，準確率只有 69.8%。
  • 先標準化（每個特徵減掉平均、除以標準差）：前兩個主成分保留 55.4% 的變異，比例變低了，但每個特徵都有機會發揮，分類準確率是 95.5%。
  • LDA：用到產區的資訊，專門找把三個產區分開的軸，2 維就有 98.3%。

這個例子也提醒我們：特徵的單位不一致時，「保留了多少變異」這個數字會誤導人。LLE、MDS、Isomap 這些靠距離的方法也一樣：不標準化，距離就被數值大的特徵主導。

第 8 章整理

投影片 1–33

降維是在盡量保留資訊的前提下減少特徵，讓訓練變快、資料可以畫成圖（第 1 篇）。兩種思路是投影和流形學習（第 2 篇）。這一章的方法：

PCA線性・第 3–5 篇

投影到保留最多變異的主成分上；用 SVD 計算，看解釋變異比選維度，也能用來壓縮。最常用，記得先標準化。

隨機 PCA／增量 PCA線性・第 6 篇

特徵很多時用隨機 PCA 只求前幾個主成分；資料太大或不斷進來時，用增量 PCA 一批一批訓練。

隨機投影線性・第 6 篇

不看資料，直接乘上隨機矩陣，距離大致保留。特徵非常多時很快。

Kernel PCA非線性・第 7 篇

用核技巧在特徵空間做 PCA，能讓同心圓這類資料變得線性可分。要選核和 γ。

LLE非線性・第 8 篇

保留每一點和鄰居的線性關係，擅長攤開捲曲的流形；鄰居數 k 要選好，資料太大時很慢。

MDS／Isomap非線性・本篇

保留點之間的距離；Isomap 用沿著鄰居圖走的測地距離，能攤開瑞士捲。

t-SNE非線性・本篇

讓相近的點留在一起，主要用來視覺化群聚。

LDA線性、監督式・本篇

用類別標籤找出最能分開類別的軸，最多 C − 1 維，適合分類前的降維。

選方法的順序：先用原始資料訓練（第 1 篇）；需要降維時先試 PCA（標準化之後）；資料明顯彎曲才換流形學習；只是想畫圖看群聚，可以用 t-SNE。

Python 實作

投影片 29 的三種方法（課本的程式，MDS 明確寫出 init="random"⁠，避免新版 scikit-learn 提醒預設值即將改變），並算出鄰居保留程度：

from sklearn.datasets import make_swiss_roll
from sklearn.manifold import MDS, Isomap, TSNE, trustworthiness

X, t = make_swiss_roll(n_samples=1000, noise=0.2, random_state=42)
for reducer in [MDS(n_components=2, init="random", random_state=42),
                Isomap(n_components=2),
                TSNE(n_components=2, random_state=42)]:
    Z = reducer.fit_transform(X)
    print(type(reducer).__name__, round(trustworthiness(X, Z, n_neighbors=10), 4))
# MDS 0.9086
# Isomap 0.998
# TSNE 0.9995

葡萄酒資料：13 個特徵的標準差差很多；直接做 PCA 和先標準化，前兩個主成分的解釋變異比完全不同：

from sklearn.datasets import load_wine
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X_wine, y_wine = load_wine(return_X_y=True)
print(X_wine.std(axis=0).round(1).tolist())
pca_raw = PCA(n_components=2).fit(X_wine)
pca_std = make_pipeline(StandardScaler(), PCA(n_components=2)).fit(X_wine)
print(pca_raw.explained_variance_ratio_.round(3), pca_std[-1].explained_variance_ratio_.round(3))
# [0.8, 1.1, 0.3, 3.3, 14.2, 0.6, 1.0, 0.1, 0.6, 2.3, 0.2, 0.7, 314.0]
# [0.998 0.002] [0.362 0.192]

降到 2 維之後接邏輯迴歸，用 5 折交叉驗證比較三種做法：

from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

for reducer in [[PCA(n_components=2)],
                [StandardScaler(), PCA(n_components=2)],
                [StandardScaler(), LinearDiscriminantAnalysis(n_components=2)]]:
    model = make_pipeline(*reducer, LogisticRegression(max_iter=5000))
    print(cross_val_score(model, X_wine, y_wine, cv=5).mean().round(4))
# 0.6975
# 0.9551
# 0.9832

常見陷阱與自我檢查

用 t-SNE 降維後再訓練模型t-SNE 主要用來視覺化。scikit-learn 的 TSNE 沒有 transform()⁠，不能把新資料放進同一個 2D 圖裡，也不保證整體的距離和形狀。
以為保留所有距離的 MDS 一定最好它保留的是直線距離，包括捲曲的流形上「穿過空氣」的距離，所以攤不開瑞士捲。Isomap 改用沿著鄰居圖走的距離才攤得開。
做 PCA 前忘了標準化單位最大的特徵會主導主成分，解釋變異比看起來很高，其實只是抓到了數字最大的那一欄。
以為 LDA 和 PCA 一樣是非監督式的LDA 需要類別標籤，而且最多只能降到「類別數 − 1」維。
Isomap 和 MDS 都想保留點之間的距離，差在哪裡？

MDS 保留的是兩點之間的直線距離。Isomap 先把每一點和鄰居連成一張圖，保留沿著這張圖走的最短距離（測地距離），也就是沿著流形量的距離。所以在瑞士捲上，Isomap 能攤開，MDS 不能。

（投影片 33）為什麼做 PCA 之前要先標準化？

PCA 找的是變異最大的方向，而變異受單位影響。沒有標準化時，數值範圍最大的特徵會主導第一個主成分，其他特徵幾乎被忽略。葡萄酒資料直接做 PCA，第一個主成分保留 99.8% 的變異，卻幾乎只有 proline 一個特徵，降到 2 維後分類準確率只有 69.8%；標準化之後是 95.5%。

葡萄酒資料有 3 個產區，用 LDA 最多能降到幾維？

2 維。LDA 最多能降到「類別數 − 1」維，所以 3 類是 2 維。
