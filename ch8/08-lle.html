8. Dimensionality Reduction，第 8 篇／共 9 篇（投影片 24–28）

LLE：
保留每一點和鄰居的關係

Kernel PCA 攤不太開瑞士捲。LLE（局部線性嵌入）換一個想法：不管資料整體長什麼樣子，只記住每一點和它的鄰居之間的關係，再到低維空間裡排出一個保留這些關係的版本。這篇一步一步看它怎麼做，以及鄰居數 怎麼選。

這篇讀完你會知道
  • LLE 的想法：先用鄰居的線性組合重建每一點，再在低維空間保留同樣的組合。
  • 投影片 27、28 的兩個最佳化問題各在做什麼，以及權重的兩個限制。
  • 用 LocallyLinearEmbedding 攤開瑞士捲：局部的距離保留得很好，大範圍的距離則不然。
  • 鄰居數 太少或太多會怎樣，以及 LLE 為什麼不適合很大的資料。

LLE 的想法

投影片 24、26

局部線性嵌入（Locally Linear Embedding，LLE）是一種強大的非線性降維（nonlinear dimensionality reduction，NLDR）方法，屬於第 2 篇的流形學習（投影片 24）。它的出發點是流形的定義：流形在每一個小區域裡，看起來都像平的。所以在一小塊範圍內，每一點都可以用它的鄰居「線性地」表示出來。LLE 分三步（投影片 26）：

  1. 選鄰居：對每一點 ，找出離它最近的 個點。
  2. 用鄰居重建：找出一組權重 ，讓鄰居的加權總和最接近 。這組權重記錄了「這一點和鄰居的相對位置」。
  3. 在低維空間排位置：權重固定不動，在低維空間裡找每一點的新座標 ，讓同樣的權重在這裡也成立。

投影片 24 說，這個做法特別擅長攤開捲曲的流形，尤其在雜訊不太多的時候。

步驟二的結果：每一點在 1 維裡的位置

重建誤差非常小，鄰居的加權總和幾乎就落在選取的點上：在一小塊範圍內，曲線真的「幾乎是直的」。權重可以是負的，只要加起來是 1 就好；選取的點落在鄰居圍起來的範圍之外時，就會出現負的權重。

補充筆記權重怎麼算出來？為什麼要「正則化」？
  • 每一點的權重可以分開算。把 個鄰居都減掉 ，排成 列的矩陣 ，算出 的矩陣 。
  • 在「權重加起來是 1」的限制下讓重建誤差最小，答案是解 ，再把 除以它的總和（拉格朗日乘數法，見第 5 章的補充筆記）。
  • 問題是：鄰居數 比資料的維度 多時（例如 2 維的螺旋、）， 不可逆，權重有無限多組解。所以先在 的對角線上加一個很小的數（scikit-learn 預設是 的跡乘上 0.001），讓答案唯一，這就是正則化。實驗裡的權重就是這樣算的。

一句話每一點各自解一個 k × k 的小方程組，加一點正則化讓答案唯一，再把權重調成加起來是 1。

第二步把權重 固定不動，改找每一點在 維空間（）的新座標 ，讓同樣的權重在低維空間裡也成立（課本式 8-5）：

這個式子和步驟一長得幾乎一樣，差別在於誰是未知數：步驟一的資料 固定，找最好的權重；步驟二的權重固定，找最好的低維座標 。投影片 28 的箭頭就是在說這件事：把 換成 ，權重照抄。

因為權重只描述「每一點和鄰居的相對位置」，低維空間裡只要保留這些局部的關係，捲起來的部分自然就被攤開了。上面實驗的最後一列就是步驟二的結果： 在 8 以上時，150 個點在 1 維裡的順序，和它們在螺旋上的順序完全一致（顏色從左到右平順地變化）。

補充筆記步驟二為什麼不會得到「全部的 z 都是 0」這種沒用的答案？
  • 如果所有的 都是 0，式 8-5 的每一項都是 0，看起來是「最佳解」，但完全沒用。
  • 所以 LLE 多加了限制：新座標的平均要是 0、大小固定（scikit-learn 讓每一個座標的平方和是 1），而且不同的座標彼此不相關。這樣就不能把所有的點縮成一點。
  • 加了限制之後，答案剛好是矩陣 特徵值最小的幾個特徵向量（跳過最小的那一個，它對應所有點擠在一起的解）。這也是 LLE 的座標數值都很小（例如 ±0.06）的原因：1,000 個點的平方和是 1，每個數字自然就很小。

一句話限制新座標的大小，才不會被「全部縮成一點」的答案騙過。

用 LLE 攤開瑞士捲

投影片 25

scikit-learn 的 LocallyLinearEmbedding 用法和 PCA 一樣（投影片 25）：

from sklearn.manifold import LocallyLinearEmbedding

lle = LocallyLinearEmbedding(n_components=2, n_neighbors=10, random_state=42)
X_unrolled = lle.fit_transform(X)

投影片 25 的結果：瑞士捲被完全攤開了，局部的距離保留得很好；但大範圍的距離沒有保留：攤開的結果不是一個長方形，而是一個被扭曲的形狀（投影片的圖像一個三角形，下面實驗裡 的結果像一個 V 字）。拉動滑桿，看鄰居數 的影響：

Python 實作

攤開瑞士捲（投影片 25 的程式，加上 random_state⁠），再用 SciPy 的 spearmanr() 看 的順序和捲上的位置 t 有多一致：

import numpy as np
from scipy.stats import spearmanr
from sklearn.datasets import make_swiss_roll
from sklearn.manifold import LocallyLinearEmbedding

X, t = make_swiss_roll(n_samples=1000, noise=0.2, random_state=42)
lle = LocallyLinearEmbedding(n_components=2, n_neighbors=10, random_state=42)
X_unrolled = lle.fit_transform(X)
print(X_unrolled.shape)
print(abs(spearmanr(X_unrolled[:, 0], t).statistic).round(3))
# (1000, 2)
# 0.998

自己做一次步驟一：找出第 0 筆資料的 10 個鄰居，用和 scikit-learn 一樣的方法算權重：

from sklearn.neighbors import NearestNeighbors

nn = NearestNeighbors(n_neighbors=11).fit(X)    # 11 個：自己加上 10 個鄰居
dist, idx = nn.kneighbors(X[:1])
nbrs = idx[0, 1:]                               # x(0) 的 10 個最近鄰居
G = X[nbrs] - X[0]
C = G @ G.T                                     # 10 × 10
C += np.eye(10) * 1e-3 * np.trace(C)            # 正則化（scikit-learn 預設 reg=1e-3）
w = np.linalg.solve(C, np.ones(10))
w /= w.sum()                                    # 權重加起來是 1
print(w.round(3))
print(dist[0, 1:].round(2))                     # 到 10 個鄰居的距離
print(np.linalg.norm(X[0] - w @ X[nbrs]).round(4))   # 用鄰居重建 x(0) 的誤差
# [ 0.285  0.111  0.169  0.185 -0.001  0.111  0.112  0.069 -0.106  0.065]
# [0.78 0.81 1.57 1.61 1.7  1.96 2.16 2.2  2.3  2.48]
# 0.0143

鄰居離它 0.78 到 2.48，用權重組合出來的點離它卻只有 0.014；有兩個權重是負的。最後比較不同的 ：

for k in [5, 10, 30]:
    Z = LocallyLinearEmbedding(n_components=2, n_neighbors=k,
                               random_state=42).fit_transform(X)
    rho = max(abs(spearmanr(Z[:, j], t).statistic) for j in range(2))
    print(k, round(rho, 3))
# 5 0.808
# 10 0.998
# 30 0.058

常見陷阱與自我檢查

以為 k 越大越好鄰居太多時，鄰居會跨到相鄰的另一圈，或範圍大到不再「局部線性」，結果反而攤不開。瑞士捲在 時就完全失敗了。
以為 LLE 保留了所有的距離它只保留每一點和鄰居之間的局部關係。攤開後，相隔很遠的兩點之間的距離，不一定和原本沿著捲量的距離成比例。
在很大的資料上用 LLE找低維座標的計算量有 ，資料一多就很慢。
以為權重一定是正的只限制加起來是 1，所以可以是負的；點落在鄰居圍起來的範圍外時就會出現負的權重。
步驟一的權重有哪兩個限制？各是為了什麼？

一、不是 個最近鄰居的點，權重是 0：每一點只能用鄰居來重建，只記錄局部的關係。二、每一點的權重加起來是 1：權重只描述相對位置，資料整體平移、旋轉、縮放時權重不變，所以才能「照抄」到低維空間。

步驟一和步驟二的式子幾乎一樣，差在哪裡？

未知數不同。步驟一的資料 是固定的，找最好的權重 ；步驟二把權重固定，找最好的低維座標 ，讓每一點仍然約等於鄰居用同樣權重的加權總和。

用 LLE 攤開瑞士捲時， 太小和太大各會怎樣？

太小：每一點只連到附近很少幾個點，整個捲斷成好幾塊，各自排列，攤不平順。太大：鄰居跨到相鄰的另一圈（抄捷徑），或鄰居的範圍大到不再接近平面，流形的形狀被破壞，也攤不開。
