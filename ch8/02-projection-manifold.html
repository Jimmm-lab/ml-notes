8. Dimensionality Reduction，第 2 篇／共 9 篇（投影片 5–6、16、21–23）

兩種降維的思路：
投影與流形學習

上一篇說，高維空間大得可怕。好在真實的資料通常不會散滿整個空間，而是集中在一個維度低得多的區域附近。這篇看降維的兩種主要思路：把資料「投影」到一個平面上，以及把彎曲的資料「攤開」的流形學習，還有它們各自適合什麼樣的資料。

這篇讀完你會知道
  • 為什麼真實的資料通常集中在一個低維的子空間附近。
  • 投影：把 3D 的資料垂直投影到一個平面上，得到 2 個新的座標（期末考題）。
  • 投影的問題：遇到瑞士捲這種捲起來的資料，投影會把不同層壓在一起。
  • 流形與流形假設，以及為什麼資料攤開之後，問題不一定變簡單。

資料其實只占一小塊空間

投影片 5

上一篇的實驗把資料均勻地撒滿整個超立方體，維度一高，資料就稀疏得可怕。真實的資料不是這樣。投影片 5 說，真實問題裡的訓練資料，通常不會均勻地分布在所有維度上：

  • 很多特徵幾乎是常數，例如 MNIST 邊緣的像素幾乎永遠是白色。
  • 很多特徵高度相關，例如相鄰的像素，知道一個就大概知道另一個。

結果是，所有的訓練資料都落在（或很靠近）一個維度低得多的子空間（subspace）裡。可以想像房間裡斜放著一塊大木板，灰塵都落在木板上或木板附近：它們雖然在 3 維空間裡，但只要說出每粒灰塵在木板上的位置（2 個數字），就幾乎知道它在哪裡了。

投影：從 3D 到 2D

投影片 5–6

投影片 6 的例子就是這種情況：60 筆 3 維的資料，都很靠近一個斜斜的平面。把每一筆資料垂直投影到這個平面上，就得到一份 2 維的新資料。新的兩個座標軸 、，是平面上兩個互相垂直、長度為 1 的方向（投影片 6 圖中的 unit vector，單位向量）。

投影片 5 特別強調：投影是一種線性轉換（Projection is Linear Transformation）。新的座標，就是原本的座標乘上固定的權重再加起來。先把每個特徵減掉它的平均（因為平面通過資料的中心），記成 ：

權重就是那兩個單位向量的座標。哪一個平面最好、權重怎麼找，是下一篇 PCA 的主題。

補充筆記投影為什麼叫「線性」轉換？它有什麼限制？
  • 上面兩個式子，每個新座標都是舊座標的加權總和，權重是固定的數字，沒有平方、沒有乘在一起的項，這就是「線性」。寫成矩陣就是一次矩陣乘法（第 4 篇會用到）。
  • 線性轉換有幾個固定的特性：直線轉換之後還是直線（或縮成一點）、平行線還是平行、等距的點還是等距。
  • 所以它可以把資料壓扁，卻沒辦法把彎曲的東西拉直。下一節的瑞士捲，正好就是這個限制的例子。

一句話線性就是「加權總和」，它能把資料壓平，不能把資料攤開。

投影的問題：瑞士捲

投影片 16

投影很好用，但不是萬能。投影片 16 說，很多時候資料所在的子空間是彎曲、扭轉的。最有名的例子是瑞士捲（Swiss roll）資料集：一張 2 維的紙，捲成 3 維的蛋糕捲。下面的顏色代表每一點在捲上的位置，從內圈（黃）到外圈（紫）：

實驗：瑞士捲要壓扁，還是攤開？

在捲上的位置：內圈 → 外圈

直接投影到 平面（等於把 丟掉），不同圈的資料會疊在一起，內圈和外圈的顏色全部混在一起，這是投影片 16 打叉的那張圖。我們真正想要的是把捲攤開：同一圈的點留在一起，顏色從左到右平順地變化，這才保留了資料原本的 2 維結構（投影片 16 打勾的圖）。

不管把投影平面轉到哪個角度，都攤不開這個捲：投影是線性的，只能把捲壓扁，不能把它拉直。要攤開，需要非線性的方法。

實驗裡的「攤開」是作弊的。我們知道每一點是用捲上的哪個位置產生的（⁠make_swiss_roll 傳回的 t⁠），所以能直接攤開。真正的演算法不知道 t⁠，要自己從資料中學出來，這是第 7 篇 Kernel PCA 和第 8 篇 LLE 要做的事。

流形與流形學習

投影片 21–22

瑞士捲是一個 2 維流形（2D manifold）的例子。投影片 21 的說法：2 維流形就是一個在更高維的空間裡彎曲、扭轉的 2 維形狀。更一般地說， 維流形是 維空間（）的一部分，在每一個小區域裡，看起來都像一個 維的超平面。瑞士捲上任何一小塊，看起來都像一小片平面，但整體是捲起來的。

很多降維演算法的做法，是去找出訓練資料所在的流形，這叫做流形學習（Manifold Learning）。它依靠的是流形假設（manifold assumption）：大部分真實世界的高維資料，都很靠近一個維度低得多的流形。投影片 21 說，這個假設在實務上經常成立。

課本用 MNIST 說明：如果隨機產生 784 個像素，得到的幾乎都是雜訊，像手寫數字的圖只占極小的一部分。手寫數字有很多限制：筆畫是連起來的線、背景是白的、數字大致在中間……這些限制，讓所有「像數字的圖」擠在 784 維空間裡一個維度低得多的流形附近。

補充筆記「流形」到底是什麼？有沒有生活中的例子？
  • 地球的表面就是一個 2 維流形：它在 3 維空間裡，整體是個球；但你在城市裡走動時，地面看起來是平的，一張平面的地圖就夠用。這就是「每個小區域看起來都像平面」。
  • 一條在空中彎來彎去的毛線是 1 維流形：任何一小段都像一小段直線，只需要 1 個數字（從線頭量起的長度）就能說出位置。
  • 瑞士捲也是 2 維流形：每一點用 2 個數字就能描述（在捲上的位置、高度），雖然它放在 3 維空間裡。
  • 流形的維度，就是「描述上面的一點需要幾個數字」；它所在空間的維度可以更高。流形學習想做的，就是找出這幾個數字。

一句話流形是「局部看是平的，整體可以是彎的」形狀，它的維度是描述上面一點所需的數字個數。

攤開之後，問題一定比較簡單嗎？

投影片 23

流形假設常常伴隨著另一個想法：把資料攤開到流形的低維空間之後，手上的任務（分類或迴歸）會變得比較簡單。投影片 23 說，不一定。下面是兩種把瑞士捲分成兩類的方式（方塊是類別 1，三角形是類別 0）：

  • 情況一：在 3D 裡，兩類的邊界是一個捲起來的曲面，很複雜；攤開之後，變成一條斜直線，用一條直線就能分開。用邏輯迴歸（線性模型）分類，訓練準確率從 76.9% 變成 99.4%。
  • 情況二：在 3D 裡，邊界就是平面 ，非常簡單；攤開之後，類別 1 被切成好幾段，邊界反而變複雜了，準確率從 99.6% 掉到 79.4%。

所以投影片 23 的結論是：訓練前先降維，通常會讓訓練變快，但不一定得到更好或更簡單的模型，要看資料而定。

Python 實作

先做出投影片 6 的 3D 資料（課本第 2 版的程式），再用 scikit-learn 的 PCA 找出最貼近資料的平面、把資料投影上去。PCA 的細節下一篇才講，這裡先看結果：

import numpy as np
from sklearn.decomposition import PCA

np.random.seed(4)                               # 課本第 2 版的 3D 資料（60 筆）
m = 60
angles = np.random.rand(m) * 3 * np.pi / 2 - 0.5
X = np.empty((m, 3))
X[:, 0] = np.cos(angles) + np.sin(angles) / 2 + 0.1 * np.random.randn(m) / 2
X[:, 1] = np.sin(angles) * 0.7 + 0.1 * np.random.randn(m) / 2
X[:, 2] = X[:, 0] * 0.1 + X[:, 1] * 0.3 + 0.1 * np.random.randn(m)

pca = PCA(n_components=2)                       # 找出最貼近資料的平面
X2D = pca.fit_transform(X)                      # 投影上去，得到新座標 z1、z2
print(X.shape, "→", X2D.shape)
print(pca.components_.round(2))                 # 平面上的兩個單位向量
print(X2D[:3].round(2))
# (60, 3) → (60, 2)
# [[ 0.94  0.3   0.18]
#  [-0.34  0.9   0.27]]
# [[-1.26 -0.42]
#  [ 0.08  0.35]
#  [-1.18 -0.36]]

投影就是一個線性轉換：減掉平均，再乘上權重。自己算一次，結果完全一樣：

X2D_manual = (X - pca.mean_) @ pca.components_.T
print(np.allclose(X2D, X2D_manual))
# True

瑞士捲：直接丟掉 是投影；攤開則要用到捲上的位置 t（只有自己產生資料時才知道）：

from sklearn.datasets import make_swiss_roll

X_roll, t = make_swiss_roll(n_samples=1000, noise=0.2, random_state=42)
X_squash = X_roll[:, :2]                        # 丟掉 x3：投影到 x1x2 平面
X_unroll = np.column_stack([t, X_roll[:, 1]])   # 攤開：用 t 當第一個座標
print(X_roll.shape, X_squash.shape, X_unroll.shape)
# (1000, 3) (1000, 2) (1000, 2)

投影片 23 的兩種分類方式，各用邏輯迴歸在 3D 和攤開後的資料上訓練，比較訓練準確率：

from sklearn.linear_model import LogisticRegression

y_1 = 2 * (t - 4) > X_roll[:, 1]                # 情況一：攤開後是一條斜線
y_2 = X_roll[:, 0] > 5                          # 情況二：3D 裡是平面 x1 = 5
for y in [y_1, y_2]:
    acc_3d = LogisticRegression(max_iter=5000).fit(X_roll, y).score(X_roll, y)
    acc_2d = LogisticRegression(max_iter=5000).fit(X_unroll, y).score(X_unroll, y)
    print(round(acc_3d, 3), round(acc_2d, 3))
# 0.769 0.994
# 0.996 0.794

常見陷阱與自我檢查

以為投影就是刪掉幾個特徵刪掉 只是一種特別的投影（投影到 平面）。一般的投影平面可以是斜的，每個新座標都混合了所有原本的特徵，例如 同時用到 、、。
以為換個角度投影，就能攤開瑞士捲投影是線性轉換，只能壓扁，不能拉直彎曲的資料。要攤開，需要 Kernel PCA、LLE 這類非線性的方法。
以為降維之後，問題一定比較簡單要看資料。投影片 23 的情況二，攤開之後的邊界反而比 3D 裡複雜。
（2024、2023 期末考的觀念）把 3D 資料投影到 2D 平面是什麼意思？新的兩個座標怎麼來？

把每一筆資料沿著和平面垂直的方向，移到平面上最近的那一點。平面上取兩個互相垂直、長度為 1 的方向當新的座標軸，每一點的新座標，就是它（減掉平均之後）在這兩個方向上的長度，也就是原本座標的加權總和。如果資料都很靠近這個平面，投影只會丟掉很少的資訊。

瑞士捲為什麼不適合用投影降維？

瑞士捲是一張捲起來的 2 維面。投影會把不同圈的資料壓在一起，原本在捲上離很遠的點（內圈和外圈）會變成鄰居。投影是線性的，換任何角度都攤不開，要用流形學習這類非線性的方法。

什麼是流形假設？

大部分真實世界的高維資料，都很靠近一個維度低得多的流形（局部看起來像低維平面、整體可以彎曲的形狀）。例如所有「像手寫數字的圖」，只占 784 維空間裡很小的一部分。流形學習就是根據這個假設，去找出資料所在的流形。
