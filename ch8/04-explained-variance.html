用 scikit-learn 做 PCA

投影片 10

scikit-learn 的 PCA 用 SVD 實作，而且會自動把資料置中。投影片 10 的程式只有三行：

from sklearn.decomposition import PCA

pca = PCA(n_components=2)                       # 降到 2 維
X2D = pca.fit_transform(X)                      # 找主成分，再投影
  • fit_transform() 一次做完兩件事：找出主成分（fit），再把資料投影上去（transform）。之後遇到新的資料，用 transform() 投影，它會用訓練資料的平均和主成分，和第 2 章的特徵縮放一樣。
  • 主成分放在 components_⁠，它的每一列是一個主成分（形狀和 一樣）。所以投影片 10 寫成 pca.components_.T[:, 0]⁠：先轉置，再取第 0 行，就是 ；直接寫 pca.components_[0] 也一樣。
  • 訓練資料的平均放在 mean_⁠。

解釋變異比：每個主成分保留了多少

投影片 10–11

訓練完的 PCA 有一個很有用的屬性：explained_variance_ratio_⁠，解釋變異比。投影片 10 說，它表示資料的變異有多少比例落在每個主成分上。3D 資料的結果是：

>>> pca.explained_variance_ratio_
array([0.84248607, 0.14631839])

84.2% 的變異在 上，14.6% 在 上，兩個加起來是 98.9%，剩下的 1.1% 在被丟掉的 上。也就是說，降到 2 維只損失了大約 1.1% 的變異。（投影片 10 把總和寫成 0.99880446，應該是 0.98880446。）

這個比例怎麼算？投影片 11 的做法是：先把資料投影到全部 個主成分上，得到 （）。 的每一行是一個新特徵，算出每一行的變異 ，全部加起來是總變異，第 個主成分的解釋變異比就是：

實驗：一步一步算出解釋變異比

從表格可以看到兩件事：

  • 主成分的變異由大到小排（投影片 11 的 High Var → Low Var），這是主成分的定義保證的。
  • 總變異不變：主成分的變異加起來，和原本 3 個特徵的變異加起來完全一樣（0.9238）。投影到全部的主成分只是轉個方向。PCA 做的事，是把變異盡量集中到前面幾個方向：原本變異最大的特徵 只占 75.6%，第一個主成分就占了 84.2%。後面的方向變異很小，丟掉也損失不多。

樣本變異數：為什麼除以 m − 1

投影片 11

投影片 11 特別標出：算變異時有兩種公式，這裡用的是樣本變異數：

母體變異數

樣本變異數（投影片 11 打勾的）

母體變異數：手上有所有可能的資料（ 筆），而且知道真正的平均 。樣本變異數：手上只有其中 筆（樣本），平均 也是從這 筆算出來的，這時要除以 。訓練資料就是一份樣本，所以 scikit-learn 的 explained_variance_ 用的是 。

好消息是，解釋變異比不受影響：每一行的變異和總變異都除以同一個數，比例完全一樣。上面的實驗切換看看，變異那一列會變，比例那一列不會。

補充筆記樣本變異數為什麼要除以 m − 1，不是 m？
  • 樣本的平均 是用同一批資料算的，它會「靠向」這批資料。所以資料到 的距離，平均來說比到真正平均 的距離小一些，平方加總會偏小。
  • 最極端的例子是 ： 剛好在兩點正中間，兩個距離平方加起來是 。平均來說 是 ，所以這個加總平均只有 。除以 會得到 ，少了一半；除以 才剛好是 。
  • 一般來說，平方加總的平均是 而不是 ，所以除以 才不會系統性地低估，這叫做「不偏」（unbiased）的估計。
  • 資料很多時， 和 幾乎沒差別。

一句話平均是從同一批資料算的，距離會偏小，除以 m − 1 剛好把它補回來。

Python 實作

先做出 3D 資料，用 NumPy 的 SVD 自己投影到 2 維：

import numpy as np

np.random.seed(4)                               # 課本第 2 版的 3D 資料（60 筆）
m = 60
angles = np.random.rand(m) * 3 * np.pi / 2 - 0.5
X = np.empty((m, 3))
X[:, 0] = np.cos(angles) + np.sin(angles) / 2 + 0.1 * np.random.randn(m) / 2
X[:, 1] = np.sin(angles) * 0.7 + 0.1 * np.random.randn(m) / 2
X[:, 2] = X[:, 0] * 0.1 + X[:, 1] * 0.3 + 0.1 * np.random.randn(m)

X_centered = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(X_centered)
W2 = Vt[:2].T                                   # V 的前 2 行：3 × 2
X2D = X_centered @ W2                           # (60, 3) @ (3, 2) → (60, 2)
print(W2.shape, X2D.shape)
# (3, 2) (60, 2)

用 scikit-learn 做一樣的事，再看解釋變異比：

from sklearn.decomposition import PCA

pca = PCA(n_components=2)
X2D_sk = pca.fit_transform(X)
print(pca.components_.T[:, 0].round(4))         # 投影片 10 的寫法：c1
print(pca.explained_variance_ratio_)
print(pca.explained_variance_ratio_.sum())
print(np.allclose(np.abs(X2D), np.abs(X2D_sk))) # 和自己算的一樣（正負號可能相反）
# [0.9364 0.2985 0.1847]
# [0.84248607 0.14631839]
# 0.988804464429311
# True

照投影片 11 的步驟自己算：投影到全部 3 個主成分，算每一行的樣本變異數（⁠ddof=1 就是除以 ），再除以總和：

pca_all = PCA().fit(X)                          # 不指定 n_components：保留全部
X_new = pca_all.transform(X)                    # X' = XV，60 × 3
var = X_new.var(axis=0, ddof=1)                 # 每一行的樣本變異數
print(var.round(4), var.sum().round(4))
print((var / var.sum()).round(4))
print(X.var(axis=0, ddof=1).round(4), X.var(axis=0, ddof=1).sum().round(4))  # 原本的 3 個特徵
# [0.7783 0.1352 0.0103] 0.9238
# [0.8425 0.1463 0.0112]
# [0.6981 0.1802 0.0455] 0.9238

改成除以 （⁠var() 預設的 ddof=0⁠），變異變小一點，比例完全一樣；scikit-learn 的 explained_variance_ 用的是 ：

var_pop = X_new.var(axis=0)                     # 除以 m
print(var_pop.round(4), (var_pop / var_pop.sum()).round(4))
print(pca_all.explained_variance_.round(4))
# [0.7653 0.1329 0.0102] [0.8425 0.1463 0.0112]
# [0.7783 0.1352 0.0103]

常見陷阱與自我檢查

把 components_ 的每一行當成主成分components_ 的每一列才是一個主成分（形狀是 ）。要「行」的話先轉置，就是投影片 10 的 components_.T⁠。
以為 explained_variance_ratio_ 加起來一定是 1只有保留全部 個主成分時才是 1。降到 2 維時加起來是 0.9888，差的 0.0112 就是丟掉的部分。
對測試資料又呼叫一次 fit_transform()這會用測試資料重新找主成分。測試資料和新資料要用 transform()⁠，沿用訓練資料的平均和主成分。
以為除以 m 或 m − 1 會改變解釋變異比分子分母都除以同一個數，比例不變。
資料有 筆、 個特徵，用 PCA 降到 維。 和投影後的資料是什麼形狀？

是 （前 10 個主成分當作 10 行）；投影後的資料是 乘上 ，得到 。

解釋變異比是 [0.60, 0.25, 0.10, 0.05]。要保留至少 90% 的變異，需要幾個主成分？

3 個。前兩個加起來是 0.85，還不到 0.9；加上第三個是 0.95。

為什麼 explained_variance_ratio_ 一定由大到小排？

因為主成分就是這樣定義的：第一個主成分保留最多變異，之後每一個都是在和前面垂直的條件下，保留剩下最多的變異，所以每一個的變異都不會比前一個大。
