怎麼讀

  • 每一篇開頭有「這篇讀完你會知道」和目錄，結尾有常見陷阱與自我檢查題。
  • 灰框是互動實驗：拖動滑桿、點選按鈕，看模型怎麼反應；淺色底的是推導，一步一步寫出來。
  • 所有數字與程式輸出都用 NumPy 2.4 與 scikit-learn 1.8 實際執行過；複製程式碼就能在自己的電腦重現。
  • 建議依序閱讀；每篇底部有上一篇／下一篇，章與章之間也接起來了。手機、平板、深色模式都可以看。

第 2 章　完整的機器學習專案End-to-End Machine Learning Project・6 篇

用加州房價資料走完一個 ML 專案：定義問題、切測試集、探索與準備資料、訓練、微調到上線。

  1. 1先看清全局：這個模型要替誰做什麼？投影片 1–6
  2. 2取得資料，然後立刻把一部分鎖起來投影片 7–14
  3. 3探索資料：先用眼睛，再用相關係數投影片 15–21
  4. 4準備資料：把資料整理成模型吃得下的樣子投影片 22–26
  5. 5選模型與訓練：別被訓練集的分數騙了投影片 27–31
  6. 6微調、測試、上線：最後一哩路投影片 32–38

第 3 章　分類Classification・6 篇

用 MNIST 手寫數字學分類：混淆矩陣、Precision／Recall、門檻、ROC、多類別與多標籤。

  1. 1MNIST 與 5 偵測器：準確率 95%，真的很厲害嗎？投影片 1–6
  2. 2混淆矩陣：把「猜對幾張」拆成四個格子投影片 7–9
  3. 3門檻與 PR 曲線：魚與熊掌怎麼選投影片 10–16
  4. 4ROC 曲線：AUC 0.96 為什麼還不夠好投影片 17–24
  5. 5多類別分類：十個數字，怎麼用二元分類器來分？投影片 25–31
  6. 6多類別指標與多標籤：一個分數，三種平均法投影片 32–34

第 4 章　訓練模型Training Models・7 篇

從正規方程式、梯度下降到正則化、邏輯迴歸與 Softmax，看懂模型到底怎麼被訓練出來。

  1. 1線性迴歸與正規方程式：一個公式直接算出最佳直線投影片 1–8
  2. 2梯度下降：蒙著眼睛，一步一步走下山投影片 9–19
  3. 3隨機與小批次梯度下降：每次只看一部分資料投影片 20–25
  4. 4多項式迴歸與學習曲線：模型太簡單，還是太複雜？投影片 26–33
  5. 5正則化：替模型的權重加上限制投影片 34–44
  6. 6邏輯迴歸：用迴歸來做分類投影片 45–53
  7. 7Softmax 迴歸：一次分好幾類投影片 54–63
