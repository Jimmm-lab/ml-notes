Gini 不純度與熵：
一個節點有多「純」？

上一篇的樹上，每個節點都寫著一個 gini 值。它衡量節點裡的資料有多混雜：全部是同一類時是 0，各類混得越平均越大。決策樹訓練時，就是靠這個數字決定要問什麼問題。這篇把 Gini 不純度算清楚，再認識另一個常用的指標：熵。

兩條曲線的形狀很像：都在 和 1 時是 0，都在 時最大。把 Gini 乘以 2 之後，兩條曲線的最高點一樣高（都是 1），形狀也很接近。所以投影片 14 說：

  • 大部分時候，兩者會長出差不多的樹。上一篇的鳶尾花，用 Gini 和用熵長出的整棵樹完全一樣（Python 實作）。
  • Gini 不純度算起來稍快一點，因為不用算對數，所以是不錯的預設值。不過在 scikit-learn 1.9 實測（2 萬筆、20 個特徵），兩者的訓練時間只差幾個百分點，而且互有快慢，速度不是選擇的關鍵。
  • 兩者不同時：Gini 傾向把最多的那一類單獨切到一邊，熵傾向切出比較平衡的兩邊。
補充筆記Gini 和熵選不同切法的例子

四類資料沿著一個特徵依序排好：A 類 40 筆、B 類 20 筆、C 類 20 筆、D 類 30 筆，共 110 筆。有三個切法可選：

切法左／右筆數加權 Gini加權熵
A｜BCD40／700.4160.991
AB｜CD60／500.4610.942
ABC｜D80／300.4551.091
  • Gini 選 A｜BCD：把最多的 A 類單獨切出來，左邊變成純的節點。
  • 熵選 AB｜CD：兩邊的筆數比較接近（60 對 50）。
  • 用 scikit-learn 驗證：criterion="gini" 的根節點切在第 40 筆和第 41 筆之間，criterion="entropy" 切在第 60 筆和第 61 筆之間（Python 實作）。

一句話差異通常很小，但真的不同時，Gini 偏好「先把大類切乾淨」，熵偏好「兩邊切得平均」。

實務上，criterion 是一個可以和其他超參數一起用交叉驗證試試看的選項，但通常不是影響最大的那一個。

Python 實作

自己算 Gini 不純度和熵，對照上一篇那棵樹的五個節點：

import numpy as np

def gini(counts):
    p = np.array(counts) / np.sum(counts)
    return 1 - np.sum(p ** 2)

def entropy(counts):
    p = np.array(counts) / np.sum(counts)
    p = p[p > 0]                          # 比例是 0 的類別不算
    return np.sum(p * np.log2(1 / p))     # 等於 -Σ p log₂ p

for counts in [[50, 50, 50], [0, 50, 50], [50, 0, 0], [0, 49, 5], [0, 1, 45]]:
    print(counts, round(gini(counts), 3), round(entropy(counts), 3))
# [50, 50, 50] 0.667 1.585
# [0, 50, 50] 0.5 1.0
# [50, 0, 0] 0.0 0.0
# [0, 49, 5] 0.168 0.445
# [0, 1, 45] 0.043 0.151

scikit-learn 把每個節點的不純度存在 tree_.impurity（節點的順序是：根、左邊的葉、右邊的節點、它的兩片葉子）：

from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier

iris = load_iris(as_frame=True)
X_iris = iris.data[["petal length (cm)", "petal width (cm)"]].values
y_iris = iris.target

tree_gini = DecisionTreeClassifier(max_depth=2, random_state=42).fit(X_iris, y_iris)
tree_entropy = DecisionTreeClassifier(criterion="entropy", max_depth=2, random_state=42).fit(X_iris, y_iris)
tree_gini.tree_.impurity.round(3)      # array([0.667, 0.   , 0.5  , 0.168, 0.043])
tree_entropy.tree_.impurity.round(3)   # array([1.585, 0.   , 1.   , 0.445, 0.151])
tree_entropy.tree_.threshold.round(2)  # array([ 2.45, -2.  ,  1.75, -2.  , -2.  ])：切法和 Gini 一樣

threshold 裡的 −2 代表葉節點（沒有門檻）。不限制深度時，兩棵樹也一模一樣：

from sklearn.tree import export_text

full_gini = DecisionTreeClassifier(random_state=42).fit(X_iris, y_iris)
full_entropy = DecisionTreeClassifier(criterion="entropy", random_state=42).fit(X_iris, y_iris)
export_text(full_gini) == export_text(full_entropy)   # True

Gini 和熵選不同切法的例子（補充筆記裡的四類資料）：

X4 = np.arange(110).reshape(-1, 1)                   # 一個特徵：0, 1, …, 109
y4 = np.array([0] * 40 + [1] * 20 + [2] * 20 + [3] * 30)
for crit in ["gini", "entropy"]:
    stump = DecisionTreeClassifier(criterion=crit, max_depth=1).fit(X4, y4)
    print(crit, stump.tree_.threshold[0], stump.tree_.n_node_samples[1:])
# gini 39.5 [40 70]
# entropy 59.5 [60 50]

常見陷阱與自我檢查

代入數量，而不是比例公式裡的 是比例。[0, 49, 5] 要先除以 54，不能直接平方 49。
以為 Gini 不純度最大是 1最大值是 ：兩類 0.5、三類 0.667。只有類別無限多時才會接近 1。
熵的公式忘了負號，或把 0 的類別也代進去 是負的，前面要加負號；比例 0 的類別跳過（當成 0）。
以為換成熵，模型會好很多大部分時候兩者長出差不多的樹；真的要比較，就用交叉驗證試。
