迴歸樹：
用一段一段的平均值做預測

決策樹不只能分類，也能預測一個數字。做法幾乎一樣：一路回答是非題走到葉節點，只是葉節點不再投票選類別，而是給出落在這裡的訓練資料的平均值。這篇看懂迴歸樹的節點、它畫出來的階梯形預測，以及 CART 怎麼改用 MSE 找切法。

這篇讀完你會知道
  • 迴歸樹每個節點上的 mse、samples、value 代表什麼，以及怎麼用它做預測。
  • 迴歸樹的預測為什麼是一段一段的階梯，而且不會超出訓練資料的範圍。
  • CART 做迴歸時把 Gini 換成 MSE：切開之後，兩邊的 越接近各自的平均越好。
  • 不加限制的迴歸樹會怎麼過擬合，以及怎麼用 min_samples_leaf 等超參數改善。

迴歸樹長什麼樣子

投影片 18

投影片 18 的資料是一條加了雜訊的二次曲線：200 筆資料，每筆只有一個特徵 （0 到 1 之間），目標值是 再加上一點雜訊。用 scikit-learn 的 DecisionTreeRegressor 訓練一棵深度 2 的樹，用法和分類樹一模一樣：

import numpy as np
from sklearn.tree import DecisionTreeRegressor

np.random.seed(42)
m = 200
X = np.random.rand(m, 1)                                  # 200 筆，x1 在 0～1 之間
y = 4 * (X[:, 0] - 0.5) ** 2 + np.random.randn(m) / 10   # 二次曲線加雜訊

tree_reg = DecisionTreeRegressor(max_depth=2, random_state=42)
tree_reg.fit(X, y)

畫出來是這樣（顏色越深，value 越大）：

和第 1 篇的分類樹比，節點上少了 class 那一行，gini 換成了 mse，value 的意思也不一樣了：

value這個節點裡訓練資料的 的平均值，走到葉節點時就是預測值。例如根節點 value = 0.354，是全部 200 筆 的平均。
mse這些 離平均值有多遠：每一筆和 value 的差距平方，再取平均（均方誤差）。越小，代表這個節點裡的 越接近，用平均來預測越準。它取代了分類樹的 gini。
samples和分類樹一樣：有幾筆訓練資料落在這個節點。
補充筆記為什麼我跑出來的圖寫的是 squared_error？
  • scikit-learn 從 1.0 版起，把迴歸樹的 criterion="mse" 改名為 criterion="squared_error"，畫出來的節點也跟著寫成 squared_error = 0.098。
  • 只是名字不同，算法完全一樣。投影片是用舊版畫的，所以寫 mse。

一句話squared_error 就是 mse，數字會一模一樣。

預測的方法也和分類樹一樣：從根節點開始回答問題，走到葉節點，葉節點的 value 就是預測值。例如 ：0.6 ≤ 0.197 嗎？否，往右；0.6 ≤ 0.772 嗎？是，往左，到達 value = 0.111 的葉節點，所以預測 。這片葉子裡有 110 筆訓練資料，0.111 就是它們 的平均。

補充筆記為什麼葉子要用平均值當預測？
  • 迴歸樹用平方誤差評分。一片葉子只能給一個數字 ，那麼 選多少，葉子裡的平方誤差總和 最小？
  • 對 微分並設為 0：，得到 ，正好是平均值。
  • 所以平均值是「一個數字代表一群數字」時，平方誤差最小的選擇。這時的平方誤差平均，就是節點上的 mse。

一句話在平方誤差下，最好的單一預測就是平均值。

預測是一段一段的平均值

投影片 19

把每個 的預測畫出來，就是投影片 19 的紅線。深度 2 的樹有 4 片葉子，把 軸切成 4 段，每一段的預測都是一個固定的數字：這一段裡訓練資料的平均。

  • 深度 2（4 片葉子）：四段的值 0.854、0.552、0.111、0.615，正是上面那棵樹四片葉子的 value。
  • 深度 3（8 片葉子）：每一段再各切一刀，階梯變細，更貼近曲線。

迴歸樹的預測永遠是這種階梯：同一片葉子裡，不管 是多少，預測都一樣。這也帶來一個重要的性質：

迴歸樹沒辦法往外延伸

每片葉子的預測是一群訓練資料的平均，所以預測永遠落在訓練資料 的最小值和最大值之間。超出訓練範圍的 只會走到最左邊或最右邊的葉子：深度 2 的樹預測 是 0.615、 是 0.854，但真正的曲線在 是 。多項式迴歸（第 4 章）可以順著曲線往外延伸，迴歸樹做不到。

和 Gini 一樣，兩邊用資料筆數加權：資料多的那一邊比較重要。直覺是：切開之後，每一邊的 越接近各自的平均越好，因為每一邊都要用平均來預測。

補充筆記投影片上的 MSE 公式為什麼沒有除以 ？
  • 投影片（課本的式子 6-4）把 寫成 ，少了前面的 ，那其實是平方誤差的總和。
  • MSE 是平均平方誤差，要除以節點裡的資料筆數。scikit-learn 印出來的 mse 也是平均：根節點 mse = 0.098，200 筆的平方誤差總和約 19.6。
  • 前面已經乘上 當權重；如果 MSE 用總和，等於又多乘了一次筆數，資料多的那一邊會被算得太重。

一句話這篇用除以 的版本，和 scikit-learn 一致。

迴歸樹也會過擬合

投影片 21

迴歸樹和分類樹一樣容易過擬合（第 5 篇）。不加任何限制時，CART 會一直切到每片葉子只剩 1 筆資料：200 筆資料長出 200 片葉子，預測線穿過每一個訓練資料，訓練資料的 MSE 是 0。投影片 21 左圖那條上下亂跳的紅線就是這樣來的。加上 min_samples_leaf=10（每片葉子至少 10 筆）之後，預測線平滑得多。用另外產生的 1,000 筆新資料來比：

結果和第 5 篇的分類樹一樣：限制太鬆，訓練 MSE 很小、新資料的 MSE 偏大（過擬合）；限制太緊，兩個都大（欠擬合）。這份資料上，min_samples_leaf 在 5～9 之間時，新資料的 MSE 最低（約 0.0125～0.0129）。

Python 實作

接著最上面的程式（同一個執行環境），印出樹的規則，並預測三個新的 ，其中 1.5 和 −0.3 在訓練資料的範圍外：

from sklearn.tree import export_text

print(export_text(tree_reg, feature_names=["x1"], decimals=3))
# |--- x1 <= 0.197
# |   |--- x1 <= 0.092
# |   |   |--- value: [0.854]
# |   |--- x1 >  0.092
# |   |   |--- value: [0.552]
# |--- x1 >  0.197
# |   |--- x1 <= 0.772
# |   |   |--- value: [0.111]
# |   |--- x1 >  0.772
# |   |   |--- value: [0.615]

print(tree_reg.predict([[0.6], [1.5], [-0.3]]).round(3))
# [0.111 0.615 0.854]

自己算根節點那一刀的 J，和不切時的 MSE 比較：

def mse(v):
    return ((v - v.mean()) ** 2).mean()

x1 = X[:, 0]
t = tree_reg.tree_.threshold[0]                # 根節點的門檻
left, right = y[x1 <= t], y[x1 > t]
J = len(left) / m * mse(left) + len(right) / m * mse(right)
print(round(t, 3), len(left), len(right), round(J, 4), round(mse(y), 4))
# 0.197 44 156 0.066 0.0978

手算例子的 3 筆資料，交給 scikit-learn 驗算：

X3 = np.array([[1], [2], [3]])
y3 = np.array([2, 6, 7])
stump = DecisionTreeRegressor(max_depth=1, random_state=42).fit(X3, y3)
print(stump.tree_.threshold[0], stump.predict([[1], [3]]))
# 1.5 [2.  6.5]

不加限制和 min_samples_leaf=10 比一比。新資料是接著用 NumPy 的全域亂數產生器產生的。前面每棵樹都設了 random_state，因為沒設的話，scikit-learn 訓練時也會從這個產生器抽亂數，接下來產生的新資料就會和本篇不同：

X_new = np.random.rand(1000, 1)
y_new = 4 * (X_new[:, 0] - 0.5) ** 2 + np.random.randn(1000) / 10

for leaf in [1, 10]:
    t = DecisionTreeRegressor(min_samples_leaf=leaf, random_state=42).fit(X, y)
    train_mse = ((t.predict(X) - y) ** 2).mean()
    new_mse = ((t.predict(X_new) - y_new) ** 2).mean()
    print(leaf, t.get_n_leaves(), round(train_mse, 4), round(new_mse, 4))
# 1 200 0.0 0.0182
# 10 15 0.0077 0.0135

常見陷阱與自我檢查

以為葉子會給一條斜線每片葉子只給一個數字（平均值），所以預測是階梯，同一片葉子裡的預測都一樣。
以為迴歸樹可以往外延伸預測永遠在訓練資料 的範圍內；超出訓練範圍的 只會得到最邊邊那片葉子的值。
把節點上的 mse 當成整棵樹的成績它只是「這個節點裡的資料」離它們自己的平均有多遠。
以為訓練 MSE 是 0 最好不加限制時每片葉子只有 1 筆，訓練 MSE 是 0，但連雜訊都記住了，新資料的 MSE 反而比較大。
用投影片 18 那棵深度 2 的樹，預測 。會經過哪些節點？預測多少？

0.05 ≤ 0.197，往左；0.05 ≤ 0.092，往左，到達 value = 0.854 的葉節點（20 筆訓練資料）。預測 。

迴歸樹的 CART 和分類樹的 CART 差在哪裡？

只差在怎麼量一個節點「好不好」：分類用 Gini（或熵），迴歸用 MSE；葉子的預測也從多數決變成平均值。其他都一樣：每次只切成兩邊、貪婪地找成本最低的切法、用同樣的超參數決定什麼時候停。

3 筆資料 ，訓練只切一刀的迴歸樹。CART 會切在哪裡？兩邊各預測多少？

切在 ：左邊 {3}，MSE 0；右邊 {4, 8}，平均 6，MSE = 4。。切在 ：左邊 {3, 4}，平均 3.5，MSE = 0.25；右邊 {8}，MSE 0。。J 比較小的是 ： 預測 3.5， 預測 8。

為什麼不加限制的迴歸樹，訓練資料的 MSE 會是 0？這是好事嗎？

這份資料的 都不一樣，CART 可以一直切到每片葉子只剩 1 筆，葉子的平均就是那一筆自己的 ，誤差是 0。這不是好事：樹把雜訊也記住了，新資料的 MSE（0.0182）比 min_samples_leaf=10 的樹（0.0135）還差，這就是過擬合。
