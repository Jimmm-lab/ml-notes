決策樹：
訓練、視覺化與預測

決策樹做預測的方式很像玩「猜猜我是誰」：一次問一個是非題，依照答案往左或往右，問到最後就得到答案。這篇用鳶尾花訓練一棵小小的決策樹，學會看懂樹上的每個節點、跟著樹走一遍做出預測，並看看它在圖上把平面切成什麼樣子。

這篇讀完你會知道
  • 決策樹能做哪些事，以及它和隨機森林的關係。
  • 怎麼用 scikit-learn 訓練一棵決策樹，並把它畫成一張圖。
  • 每個節點上的 samples、value、class 代表什麼。
  • 怎麼從根節點一路走到葉節點做出預測，以及怎麼估計每一類的機率。

決策樹能做什麼

投影片 2

決策樹（Decision Tree）和上一章的 SVM 一樣，是用途很廣的模型：

  • 分類：例如判斷一朵花是哪一種鳶尾花（本篇）。
  • 迴歸：預測一個數值（第 6 篇）。
  • 多輸出（multioutput）：一次預測好幾個目標。
補充筆記多輸出是什麼意思？
  • 一般的模型一次只預測一個目標，例如「這朵花是哪一種」。多輸出是一次預測好幾個目標，例如同時預測一個人的身高和體重。
  • 決策樹做這件事很自然：每片葉子把落在這裡的訓練資料，每個目標各算一個答案（分類取多數、迴歸取平均）就好。DecisionTreeClassifier 和 DecisionTreeRegressor 的 y 都可以有好幾欄。
  • 第 3 章第 6 篇的多標籤分類就是多輸出的一種：每個標籤都是一個「是或否」的輸出。

決策樹也是隨機森林（Random Forest）的基本零件。隨機森林把很多棵決策樹的預測平均起來，是目前最強大的機器學習模型之一，第 7 章會介紹。

決策樹的想法很直覺：一次問一個是非題，例如「花瓣長度 ≤ 2.45 cm 嗎？」，依照答案走到下一個問題，問到最後就給出預測。這一章先看一棵訓練好的樹怎麼做預測（本篇），再看電腦怎麼決定要問哪些問題（第 2、3 篇），最後談怎麼控制樹的大小、怎麼用樹做迴歸，以及決策樹的弱點。

訓練一棵決策樹

投影片 3

投影片 3 用第 4 章看過的鳶尾花資料，只取花瓣長度和花瓣寬度兩個特徵，訓練一棵最多兩層的決策樹：

from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier

iris = load_iris(as_frame=True)
X_iris = iris.data[["petal length (cm)", "petal width (cm)"]].values
y_iris = iris.target

tree_clf = DecisionTreeClassifier(max_depth=2, random_state=42)
tree_clf.fit(X_iris, y_iris)
  • max_depth=2：從第一個問題往下，最多再問一層，也就是最多問兩個問題就要給答案。
  • random_state=42：讓結果每次都一樣。決策樹的訓練有一點隨機性，第 7 篇會再談。
補充筆記為什麼要設 random_state？決策樹的訓練哪裡有隨機性？
  • 這份資料裡，「花瓣長度 ≤ 2.45」和「花瓣寬度 ≤ 0.8」都能把 50 朵 setosa 完美地分出來，兩個問題一樣好。
  • scikit-learn 在每個節點會用隨機的順序檢查特徵；兩個問題一樣好時，先檢查到的那一個勝出。所以不設 random_state，有時根節點會問花瓣長度，有時會問花瓣寬度。
  • 設成 42 會得到和投影片 3 相同的樹。換成其他值（例如 40），根節點就變成問花瓣寬度，這是第 7 篇「決策樹的變異很大」的例子。

一句話兩個切法一樣好時，誰先被檢查到誰就勝出；固定 random_state，結果才會固定。

訓練好的樹可以用 export_graphviz() 畫出來（投影片 3 左邊的程式，Python 實作有完整寫法）。下圖就是這棵樹：

看懂一個節點

投影片 3–5

先認識幾個名詞。樹是倒過來畫的：最上面是根，越往下越深。

根節點最上面的節點（root node），深度是 0。所有資料都從這裡開始。
子節點一個節點問完問題後，答「是」往左邊的子節點走，答「否」往右邊走。
葉節點沒有子節點的節點（leaf node）。它不再問問題，直接給出預測。
深度從根節點往下走了幾步。根的深度是 0，它的子節點深度是 1，以此類推。

每個節點上有好幾行字（投影片 5）。以最下排左邊的葉節點為例：

  • samples = 54：訓練資料裡有 54 朵花走到這個節點。根節點的 samples 是全部的 150 朵，每往下一層，資料就被分到左右兩邊。
  • value = [0, 49, 5]：這 54 朵花裡，三種花各有幾朵（setosa、versicolor、virginica 的順序）。
  • class = versicolor：這個節點裡最多的類別。走到這片葉子的花，就預測是 versicolor。
  • gini = 0.168：這個節點有多「不純」。全部都是同一種花時是 0，三種花混得越平均越大，下一篇會詳細算。

同一層的子節點，samples 加起來會等於父節點：根節點的 150 朵，被第一個問題分成左邊 50 朵、右邊 100 朵；右邊的 100 朵再被分成 54 朵和 46 朵。

還有一個細節：左邊的節點已經全部是 setosa（gini = 0），再問下去也沒有意義，所以它直接變成葉節點。這就是為什麼 max_depth=2 的樹只有 3 片葉子，而不是 4 片。

做預測：從根走到葉

投影片 4

撿到一朵新的鳶尾花，要預測它是哪一種，就從根節點開始，一路回答問題（投影片 4）：

  1. 從根節點開始（深度 0）：花瓣長度 ≤ 2.45 cm 嗎？
  2. 答「是」：走到左邊的子節點。它是葉節點，不再問問題，預測是 setosa。
  3. 答「否」：走到右邊的子節點。它不是葉節點，繼續問：花瓣寬度 ≤ 1.75 cm 嗎？
    • 是：走到左下的葉節點，預測 versicolor。
    • 否：走到右下的葉節點，預測 virginica。

拖動圖上的星號（或點圖上任何位置）放一朵新的花，看看它在樹上走哪一條路：

估計每一類的機率

課本補充（Géron 第 6 章）

決策樹也能估計一朵花屬於每一類的機率：先走到它所在的葉節點，再看這片葉子的訓練資料裡，每一類各佔多少比例。

例如花瓣長 5 cm、寬 1.5 cm 的花，會走到 value = [0, 49, 5] 的葉節點，所以：

機率最高的是 versicolor，所以預測 versicolor。scikit-learn 的 predict_proba() 和 predict() 就是這樣算的。

同一片葉子，機率都一樣

花瓣長 6 cm、寬 1.5 cm 的花也會走到同一片葉子，得到一模一樣的機率 [0, 0.907, 0.093]。但從散佈圖看，長 6 cm 的花明顯比較像 virginica。決策樹只看「落在哪個格子」，不管在格子裡的哪個位置，所以它給的機率是一格一格、不會平滑變化的。在上面的實驗按「長 6、寬 1.5」試試看。

決策邊界：一刀一刀切出來的格子

投影片 7

把這棵樹的每個問題畫在散佈圖上，就是它的決策邊界（投影片 7）：

  • 深度 0（根節點）：花瓣長度 = 2.45 的那條實線。左邊全部是 setosa，是一塊純的區域，不用再切。
  • 深度 1：右邊的區域不純，再用花瓣寬度 = 1.75 的虛線切一刀，只切右半邊。
  • 如果把 max_depth 設成 3，深度 2 的兩個節點會各自再切一刀（點線）：下面那塊在花瓣長度 4.95 切，上面那塊在 4.85 切。

每個問題只看一個特徵，所以每一刀都是一條和座標軸平行的直線，整個平面被切成一塊一塊的長方形。換一下 max_depth 看看：

白箱模型與黑箱模型

  
投影片 8

  
決策樹最大的優點之一，是它的判斷過程很容易懂：

  

    

      
白箱模型（white box）

      
決策樹很直覺，每個預測都能用幾條簡單的規則解釋，必要時甚至可以用手算。

    

    

      
黑箱模型（black box）

      
隨機森林、神經網路通常被當成黑箱：預測很準，但很難用簡單的話說明它為什麼這樣預測。

    

  

  
例如這棵深度 2 的樹，整個模型就是三條規則：


如果 花瓣長度 ≤ 2.45：            setosa
否則，如果 花瓣寬度 ≤ 1.75：      versicolor
否則：                            virginica

  
醫療、金融這類需要解釋「為什麼」的應用（例如為什麼拒絕一筆貸款），白箱模型特別有價值。






  
Python 實作

  
投影片 3 用 export_graphviz() 把樹存成 .dot 檔：


from sklearn.tree import export_graphviz

export_graphviz(
    tree_clf,
    out_file="iris_tree.dot",
    feature_names=["petal length (cm)", "petal width (cm)"],
    class_names=iris.target_names,
    rounded=True,
    filled=True
)

  
再在終端機執行 dot -Tpng iris_tree.dot -o iris_tree.png 轉成圖片。這需要另外安裝 Graphviz；沒有安裝的話，可以用 sklearn.tree.plot_tree()（需要 Matplotlib），或直接印出文字版：


from sklearn.tree import export_text

預測與估計機率：


tree_clf.predict_proba([[5, 1.5]]).round(3)   # array([[0.   , 0.907, 0.093]])
tree_clf.predict([[5, 1.5]])                   # array([1])：1 是 versicolor
tree_clf.predict_proba([[6, 1.5]]).round(3)   # array([[0.   , 0.907, 0.093]])：同一片葉子

  
樹的大小和訓練準確率：


print(tree_clf.get_depth(), tree_clf.get_n_leaves())   # 2 3
tree_clf.score(X_iris, y_iris)                          # 0.96

for depth in [1, 2, 3, 4, None]:
    clf = DecisionTreeClassifier(max_depth=depth, random_state=42).fit(X_iris, y_iris)
    print(depth, clf.get_n_leaves(), round(clf.score(X_iris, y_iris), 4))
# 1 2 0.6667
# 2 3 0.96
# 3 5 0.9733
# 4 7 0.9867
# None 8 0.9933

  
max_depth=None（預設）表示不限制深度。最後一行沒有到 1.0，原因是那三朵花瓣長寬相同、種類卻不同的花。






  
常見陷阱與自我檢查

  
以為根節點的深度是 1根節點的深度是 0。max_depth=2 代表從根往下最多走兩步，最多問兩個問題。

  
把 value 當成預測值value 是走到這個節點的訓練資料裡，每一類各有幾朵；預測的類別是 value 最大的那一類（class）。

  
以為機率會隨位置平滑變化同一片葉子裡的每個位置，predict_proba() 都一樣。決策樹的機率是一格一格的。

  
沒設 random_state 就比較結果兩個切法一樣好時，scikit-learn 會隨機挑一個，同樣的程式可能長出不同的樹。要重現結果，固定 random_state。


  

    一朵花的花瓣長 2 cm、寬 0.5 cm。它在深度 2 的樹上怎麼走？預測和機率是多少？
    
2 ≤ 2.45，答「是」，走到左邊的葉節點（value = [50, 0, 0]），預測 setosa，機率 [1, 0, 0]。只問了一個問題。

  

  

    花瓣長 4 cm、寬 2 cm 的花呢？
    
4 > 2.45 往右；2 > 1.75 往右，走到 value = [0, 1, 45] 的葉節點。預測 virginica，機率 。

  

  

    深度 2 的樹在訓練資料上分錯幾朵？準確率多少？
    
左邊的葉子全對；中間的葉子 [0, 49, 5] 有 5 朵 virginica 被當成 versicolor；右邊的葉子 [0, 1, 45] 有 1 朵 versicolor 被當成 virginica。共錯 6 朵，準確率 。

  

  

    為什麼決策樹的決策邊界都和座標軸平行？
    
每個節點只問一個特徵的問題（例如「花瓣長度 ≤ 2.45」），在圖上就是一條垂直或水平的直線。很多條這樣的直線組合起來，把平面切成一塊塊長方形。第 7 篇會看到這個特性帶來的問題。
